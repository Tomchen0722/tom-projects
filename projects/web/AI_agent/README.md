# 🦞 自動的小龍蝦 — AI 指揮室（本機自行運行版）

10 部門 38 角色的多 Agent 自動化公司系統。所有資料存在本機（SQLite + config.json），不上傳任何內容。

## 啟動方式

1. 電腦需安裝 Python 3（https://www.python.org/downloads/ ，安裝時勾選 Add to PATH）
2. 雙擊 `start.bat` — 會自動安裝 Flask、開啟瀏覽器到 http://localhost:5566
3. 右上按「▶ 啟動自動工作」，Autopilot 每 8 秒撿一次待處理任務，最多 3 個並行

## 接上真模型（可選）

到「⚙️ 設定」頁填入 Gemini API Key（免費額度：https://aistudio.google.com/apikey ）或 Anthropic API Key。
沒填 key 時全系統以「模擬模式」運行，流程照跑但內容是示意文字。
每次真實 API 呼叫的費用會自動換算 TWD 記入帳本，本月超過預算（預設 US$90）自動停止呼叫。

| Agent 會議室 | 會議室頁 | 議程＋會議總結 |
| 產品開發部 | 產品開發頁 | A 穩健 / B 創意 / C 快速 MVP 三提案＋總經理講評 |
| 設計部 | 設計部頁 | 視覺設計＋配色方案報告 |

| 社群推廣部 | 社群頁 | 文案草稿→審批中心（絕不自動發布） |
| SEO 分析部 | SEO 頁 | 爬蟲→SEO→趨勢→機會清單四段流水線 |

## 三條紅線（寫死在程式裡）

不自動發布社群貼文、不連真實券商下單、不自動寄送開發信 — 一律只產草稿進審批中心。

## 檔案結構

- `app.py` 伺服器與 API　`engine.py` 工作流＋Autopilot　`roles.py` 38 角色定義
- `llm.py` Gemini/Claude/模擬 介接　`db.py` 資料層　`static/index.html` 介面
- `xiaolongxia.db` 資料庫（首次啟動自動建立）　`config.json` 金鑰與設定（自動建立）
