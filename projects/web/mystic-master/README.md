# 天機玄學閣（Mystic Master）

> **和風簡約 ｜ 紫微斗數・相術乾坤・易道變易・流年十年 現代青年白話典藏館**  
> 暖色系日式簡約風（和風侘寂・暖和紙木質調）打造。融匯千年正統玄學精髓，以高中生易懂的現代生活與大考譬喻深入解析，兼備圖文並茂的視覺美學、流年精算與未來十年運勢動態圖譜。

## 🍵 視覺設計：暖色系日式簡約風（Wabi-Sabi & Japandi）

- **底色與質感**：以溫潤和紙米白（`#fbf9f4`）與柔白紙質卡片為基底，佐以若竹抹茶綠（`#5b7052`）、暖檜木柿色（`#b4532a`）與山吹琥珀（`#c88a35`）。
- **禪意微動效**：背景流動著柔和悠緩的暖陽金塵浮動微粒，營造寧靜致遠的修心氛圍。
- **極簡排版**：細緻線條、日式朱印標籤、清晰留白與優雅宋體/明朝體襯線標題。

## 🌟 核心理念與降維解讀

1. **紫微斗數（Zi Wei Dou Shu）** = **大型開放世界 RPG 角色天賦卡**
   - **命宮**：初始核心素質、三觀與底層人格。
   - **官祿宮**：主線學業專注度、段考攻堅能力、選組與大學志願方向。
   - **生年四化**：祿（幸運資源）、權（強勢掌控）、科（大考功名）、忌（修煉關卡）。
   - **十四主星校園人格光譜**：紫微（自治會長）、天機（競賽大腦）、太陽（熱血隊長）、武曲（刷題戰神）、天同（福氣團寵）等。

2. **📅 流年精算（Annual Fortune Engine）**
   - **自由切換年份**（2024 ～ 2035 年，預設 2026 丙午年）。
   - **流年命宮與流年四化**：自動推導當年歲次干支（如 2026 丙午年：天同祿、天機權、文昌科、廉貞忌），並尋找出流年四化落入本命盤的宮位。
   - **高中生四維度年度指南**：
     - 📚 **大考與學業考運**：專注力週期、模考突破點與文昌星庇佑分析。
     - 🤝 **同儕社團與貴人**：班級人際磁場、貴人助力與合作指南。
     - 🩺 **身心機能與作息**：換季防護、神經疲勞預防與精力管理。
     - 🎯 **年度核心心法**：當年專屬的高維度破局指南。

3. **📈 未來 10 年運勢動態圖譜（10-Year Decadal Roadmap）**
   - 橫向滑動時間軸，涵蓋高中衝刺、大學聯考、大學四年乃至碩班或初入職場黃金十年。
   - 逐年提供**歲次干支、實歲/虛歲、年度綜合運勢指數（65~98分雷達）、命運關鍵字與升學階段里程碑**（如「潛龍蓄勢」、「大考突圍」、「大學初啼」、「羽翼漸豐」、「專業深耕」）。
   - 點擊任意年份卡片，立即展開詳細的學業大考與人生決策預測。

4. **相術乾坤（Palmistry & Physiognomy）** = **身體與神經狀態生物儀表板**
   - **手相透視鏡**：高解析向量 SVG 手掌，可點選高亮三大主線與副線，解析八大掌丘與五行掌型。
   - **面相三停五官法鏡**：解析天庭（15~30 歲學運）、中停與地閣，結合現代神經可塑性（Neuroplasticity）闡釋「相由心生」。

5. **易道變易（I Ching & Bagua）** = **二進制動態演算法與決策樹**
   - **文王金錢課六爻擲卦機**：3D 物理翻轉銅錢，合成清脆金屬落地聲，自動演繹本卦、變卦與互卦。
   - **64 卦白話決策手冊**：針對段考衝刺、選系志願、同儕溝通給予最高策略解。
