# 天機玄學閣（Mystic Master）

> **紫微斗數・相術乾坤・易道變易 ｜ 現代青年白話精修旗艦館**  
> 融匯千年正統玄學精髓，以高中生易懂的現代生活與大考譬喻深入解析，兼備圖文並茂的視覺美學與多元互動模擬工具。

---

## 🌟 核心理念與降維解讀

古老東方玄學絕非迷信與消極宿命論，而是前人探索宇宙法則、自我認知與動態博弈的高維智慧模型：

1. **紫微斗數（Zi Wei Dou Shu）** = **大型開放世界 RPG 角色天賦卡**
   - **命宮**：初始核心素質、三觀與底層人格。
   - **官祿宮**：主線學業專注度、段考攻堅能力、選組與大學志願方向。
   - **生年四化**：
     - **化祿**：賽季幸運 Buff，資源湧現與貴人相助。
     - **化權**：狂暴加速形態，自驅力與競爭力拉滿。
     - **化科**：大考功名金榜、文章名聲與榮譽光環。
     - **化忌**：命運設定的 Boss 關卡與執念考驗，跨過即是傳奇。
   - **十四正星人格光譜**：紫微（自治會長）、天機（競賽大腦）、太陽（熱血隊長）、武曲（刷題戰神）、天同（福氣團寵）、廉貞（傲骨極客）、天府（靠譜總督）、太陰（深邃智者）、貪狼（魅力斜槓）、巨門（辯證先鋒）、天相（完美協調）、天梁（老靈魂引路人）、七殺（孤膽先鋒）、破軍（顛覆拓荒者）。

2. **相術乾坤（Palmistry & Physiognomy）** = **身體與神經狀態生物儀表板**
   - **手相篇**：三大主線（生命線＝HP上限與體能恢復力；智慧線＝大腦演算法架構；感情線＝情商與心理防火牆）＋ 八大掌丘 ＋ 五行掌形。
   - **面相篇**：三停六府（上停天庭主 15~30 歲學運記憶；中停主自尊奮鬥意志；下停地閣主晚運長跑後勁）＋ 五官微表情心理學。
   - **相由心生**：結合現代神經可塑性（Neuroplasticity），揭示作息、挺拔身姿與豁達心態如何真實重塑面相氣色與眼神定力。

3. **易道變易（I Ching & Bagua）** = **宇宙運行的動態二進制演算法與決策樹**
   - **二進制之源**：陰爻（0）與陽爻（1）演繹 $2^3=8$ 卦、$2^6=64$ 種全局動態矩陣（與萊布尼茲二進制原理深度呼應）。
   - **文王金錢課六爻卜筮**：3D 物理質感旋轉拋擲三枚古銅錢，連續 6 次自下而上生成本卦（事態現狀）、變卦（未來走勢）與互卦（內部隱藏機緣）。
   - **64 卦高中實戰指南**：包含大考瓶頸、選填志願、社團交友、逆境自處等生活情境的最高策略啟發。

## 🛠️ 互動功能清單

- **紫微排盤算命器**：輸入西元年月日時辰，自動排定天干地支、五行局、安命宮身宮、排布十四正星與四化星，並附高中生生活天賦詳解。
- **掌紋掌丘透視鏡**：高解析向量 SVG 手掌，支援點選高亮三大主線與副線，即時展開診斷報告。
- **面相三停五官法鏡**：向量面相圖解析額頭天庭、印堂氣色、眼神定力與準頭意志。
- **文王金錢課擲卦模擬器**：真實物理翻滾 3 枚古銅錢，支援 Web Audio API 清脆碰撞金屬聲，記錄老陽老陰變爻，一鍵生成卦象報告。
- **64 卦速查手冊**：上下卦隨選，快速查閱經典卦爻辭與高中策略。
- **天機大會考**：10 道融會貫通的情境互動題，通關即頒發玄門通儒國師封號。
- **今日靈光籤**：每日隨機抽取易理靈光指引與開運生活微行動。

## 💻 技術架構

- **純前端靜態架構**（Vanilla HTML5 / CSS3 / ES6+ JavaScript），無龐大框架依賴，零配置即開即用。
- **聲音合成**：基於 Web Audio API 實時程序化合成銅錢碰撞聲與青銅磬音，無需外部音訊資源。
- **視覺系統**：深邃星空墨藍、鎏金琉璃光感、毛玻璃擬態、Canvas 動態星宿連線、自適應響應式布局。
- **Tom Chen Project Hub 整合**：已於 `projects.json` 註冊（Port: `7027`，Kind: `static`）。
