# 如何寫好一個企劃案 (How to Write a Good Proposal)

這是一個關於如何撰寫各類企劃案的知識庫與範本集合。無論是政府標案、商業行銷企劃，還是公司內部的專案提案，良好的企劃書結構與邏輯都是成功說服決策者的關鍵。

## 專案內容目錄

1. **[政府標案企劃書撰寫指南](./政府標案企劃書撰寫指南.md)**
   - 針對政府採購與標案的「服務建議書」撰寫要點。
   - 包含評分邏輯導向、標準架構與得標關鍵技巧。

2. **[行銷企劃案撰寫指南](./行銷企劃案撰寫指南.md)**
   - 針對商業環境中的行銷活動、產品上市等企劃。
   - 包含八大核心模組與實戰提案技巧。

3. **[通用企劃書架構範本](./通用企劃書架構範本.md)**
   - 提供一份空白的標準 6W2H1E1R 企劃書範本，方便您直接複製使用。

## 核心觀念：企劃書的目的在於「溝通」與「解決問題」

在開始動筆前，請務必記住以下幾個核心原則：
- **以「閱讀者」視角出發**：評審、老闆或客戶在意的不是「你有多好」，而是「你能如何解決他們的問題」。
- **邏輯清晰優於華麗辭藻**：運用圖表、列點與清晰的標題，讓讀者能在 3 分鐘內抓到重點。
- **可行性與風險控管**：政府與企業同樣害怕「做不到的承諾」，展現對細節的掌控力是建立信任的關鍵。
