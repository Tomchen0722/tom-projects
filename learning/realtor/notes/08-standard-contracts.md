# 第 8 單元：各式契約書範本與應記載及不得記載事項實務

> **【考照重要性】：★★★★☆（必考 8~10 題，成屋買賣、委託銷售、要約斡旋實務題庫精髓）**

---

## 壹、 不動產委託銷售契約書（專任 vs 一般）

| 比較項目 | 專任委託銷售契約 | 一般委託銷售契約 |
| :--- | :--- | :--- |
| **定義** | 委託期間內，賣方**只能委託該單一經紀業**出售 | 賣方可同時委託多家經紀業，亦可自行出售 |
| **自行出售責任** | 賣方若自行出售或另託他人，**視為違約**，仍應支付全額服務報酬 | 賣方可自行出售，成交後立即通知已委託之業者即可，無需賠償 |
| **審閱期** | **至少 3 日** | **至少 3 日** |

## 貳、 內政部版要約書 vs 買賣斡旋金（定金收據）

1. **經紀業之告知義務**：
   - 經紀業受買方委託承購時，**應同時向買方詳細說明內政部版「要約書」與「斡旋金」之替代關係與法律效果**。
   - 應由買方自由選擇，**嚴禁強制要求買方必須支付現金斡旋金**！
2. **要約書之法律效力**：
   - 要約書送達賣方承諾前，買方享有**無條件隨時撤回權**（以書面向經紀業或賣方為之）。
   - 賣方承諾簽署要約書後，買賣契約即告成立。
   - 若賣方承諾後買方反悔不買，違約金通常約定為**買方出價總金額之 3%**。
3. **斡旋金之法律效力**：
   - 賣方同意出售並於斡旋金收據上簽章承諾時，該斡旋金即**自動轉為定金**。
   - 買方反悔不買，賣方得沒收定金；賣方承諾後反悔不賣，賣方應**加倍返還定金**（民法第 249 條）。

## 參、 成屋買賣契約應記載及不得記載事項

### 一、 應記載事項
1. 契約審閱期不得少於 **5 日**。
2. 買賣標的物現況確認書（是否有漏水、海砂屋、輻射屋、非自然身故凶宅等）。
3. 履約保證條款（價金信託或成屋履約保證專戶）。
4. 稅費負擔劃分：地價稅、房屋稅以交屋日為基準按天數比例分算；土地增值稅由出賣人負擔；契稅由買受人負擔。

### 二、 不得記載事項（常考！）
1. **不得約定**買方拋棄民法上物之瑕疵擔保請求權。
2. **不得約定**買賣雙方於契約成立後，免除經紀業之違約連帶賠償責任。
3. **不得約定**出賣人收取定金後得任意解除契約不加倍返還。

## 肆、 房屋租賃契約應記載及不得記載事項

1. **押金上限**：最高不得超過 **2 個月租金總額**。
2. **法定絕對不得記載事項（租屋族保障核心！）**：
   - **不得約定**承租人不得申報租賃費用支出（報稅扣除額）。
   - **不得約定**承租人不得遷入戶籍。
   - **不得約定**應由出租人負擔之稅捐（如租賃所得稅、增加之地價稅）轉嫁由承租人負擔。
   - **不得約定**出租人得任意調漲租金。
