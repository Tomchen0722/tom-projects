單元一 · 基礎觀念

01
Git 是什麼？為什麼工程師離不開它先理解「版本控制」要解決的真正問題，再碰指令。
02
安裝 Git 與 VS Code、做好初次設定把工具備齊，並設定好你的「工程師身分證」。
03
Git 三大區域：搞懂這個，一切都通了工作區、暫存區、儲存庫——Git 所有指令都在這三者之間搬東西。

單元二 · 單人基本操作

04
建立專案與你的第一個 commitinit → add → commit → log，完整走一次 Git 的日常循環。
05
.gitignore 最佳實務（Python／Node／AI 專案）教 Git 對哪些檔案「視而不見」——這是專業與業餘的分水嶺。
06
Commit Message 撰寫規範：Conventional Commits讓每一則 commit 訊息都專業、可讀、甚至能自動產生更新日誌。
07
查看歷史、比較差異、還原檔案log、diff、restore、checkout——安全地在時間線上來回穿梭。
08
VS Code 圖形介面完整操作（不背指令也能用 Git）把前面學的所有操作，用滑鼠完整走一遍。

單元三 · 分支與遠端協作

09
分支 Branch：多人協作的核心為什麼有了分支，三個人才能同時開發不打架。
10
合併 Merge 與解決衝突 Merge Conflict把分支的成果併回主線，並學會冷靜處理「衝突」這件新手最怕的事。
11
Rebase 與「Merge 還是 Rebase？」的抉擇讓歷史變乾淨的另一種合併方式，以及它的黃金鐵律。
12
Stash、Cherry-pick、Revert、Reset 四大工具四個名字很像但用途完全不同的實用指令，一次搞懂何時用哪個。
13
連上 GitHub：clone、remote、push、pull、fetch把本機的 Git 和雲端的 GitHub 接起來，真正開始多人協作。

單元四 · 企業級開發流程

14
Pull Request 與 Code Review：公司協作的心臟程式碼不是自己 merge，而是開 PR 請人審完再合——這是企業開發的核心儀式。
15
Fork 與 Upstream：參與開源專案當你沒有某個 repo 的寫入權限，卻想貢獻程式碼時的標準做法。
16
版本號、Git Tag 與 GitHub Release 發布流程怎麼幫專案標記 v1.0、v2.0，並在 GitHub 正式發佈一個版本。
17
資安：別讓 API Key 與 .env 被推上 GitHub最容易發生、後果最嚴重的新手事故，這一課教你預防與善後。
18
Git LFS：管理大型模型、圖片與影片為什麼大檔不能直接進 Git，以及 AI 專案怎麼正確處理權重和資料。
19
GitHub Actions：自動測試與自動部署（CI/CD）讓「每次 push 自動跑測試、每次發版自動部署」成真。

單元五 · 事故救援大全

20
Git 事故救援大全：做錯了怎麼救reflog 是你的時光機——push 錯分支、誤刪 commit、誤 merge、reset 弄丟東西，一課全收錄。
