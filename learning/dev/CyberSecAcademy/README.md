# 資安自學院 · CyberSec Academy

一個用 Python (Flask) 寫成的資安自學網站，從**零基礎到企業應用**，用**高中程度**的方式解釋。

## 涵蓋範圍（8 條學習路線 · 33 章 · 265 題測驗 · 180+ 條指令示範）

| 階段 | 路線 | 對應證照 |
|---|---|---|
| 打底 | 資安基礎觀念 | 零基礎起點 |
| 打底 | 網路基礎 | CompTIA Network+ · Cisco CCNA |
| 打底 | Linux 系統與加固 | CompTIA Linux+ |
| 核心 | 資安通識 | CompTIA Security+ |
| 攻防 | 網路防禦（藍隊） | EC-Council CND |
| 攻防 | 道德駭客（紅隊） | EC-Council CEH |
| 攻防 | 威脅偵測與 SOC | CompTIA CySA+ |
| 企業 | 企業應用與職涯 | 整合實戰 |

## 每個章節都包含
- **為什麼要學**（生活化比喻）
- **詳細說明 + 舉例**（高中程度）
- **視覺化圖解**（SVG）
- **對照表格**
- **動手做**（可點擊帶入模擬終端機的指令示範）
- **章節測驗**（模擬考題，即時批改與解析）
- **帶走這三句**（重點總結）

## 特色功能
- 學習進度追蹤（完成度、連續學習天數、各路線進度條）
- 模擬終端機（教學沙盒，不會動到你的電腦）
- 全站搜尋、術語小辭典、章節收藏
- 深色護眼介面、支援手機（RWD）、無障礙設計

## 怎麼啟動

### 方法一：雙擊啟動（最簡單）
直接雙擊 **`啟動網站.bat`**，它會自動安裝 Flask 並開啟瀏覽器。

### 方法二：手動
1. 安裝 Python 3.8 以上（https://www.python.org）
2. 開啟命令提示字元，切到本資料夾，執行：
   ```
   pip install -r requirements.txt
   python app.py
   ```
3. 打開瀏覽器前往 http://127.0.0.1:5000
4. 要停止：在視窗按 Ctrl + C

## 重要提醒
本網站所有「攻擊」相關的實作，都刻意設計成**只在你自己的實驗環境、對你自己的目標執行**。
學習這些技術是為了**理解攻擊、設計防禦**。
