PBQ（情境題）策略——考試最大挑戰

🎯 PBQ 是什麼？

PBQ 是模擬真實操作的互動題：配置防火牆規則、分析網路封包、拖放 OSI 層級對應、識別惡意 Log 模式等。通常有 3-5 題，每題配分較高。

  1. 先跳過 PBQ：考試開始先點「跳過」，把 PBQ 留到後面。PBQ 耗時，先完成普通選擇題保住基本分
  2. 普通題全部答完後，回來處理 PBQ（約剩 20-25 分鐘）
  3. PBQ 的技巧：仔細看圖表和說明，通常答案就在題目的情境描述裡
  4. 不要完美主義：PBQ 給最合理的答案就送出，不要為了 PBQ 犧牲選擇題的時間
  5. 每題平均約 5 分鐘，超時就放最合理的答案離開

消去法——Security+ 版本

Security+ 題目的特殊邏輯：「最佳實踐」≠ 「最複雜的方案」
CompTIA 喜歡考「從安全最佳實踐出發的決策」

排除「只是沒有明顯問題」的選項
❌ 雖然沒錯但不是安全最佳實踐（如：允許所有流量通過再過濾）
✅ 遵循最小權限、預設拒絕、深度防禦

「最適合」情境關鍵字
「速度最快」→ 對稱加密（AES）
「最安全的 MFA」→ 硬體安全金鑰（FIDO2），不是 SMS OTP
「最無法偵測」→ Insider Threat（內部威脅），不是外部攻擊
「防止資料外洩的第一步」→ 資料分類（Data Classification）

4 個風險應對策略
Accept（接受）/ Transfer（轉移，保險）/ Avoid（迴避）/ Mitigate（緩解）
→ 題目問「公司決定不處理某風險」= Accept；「購買保險」= Transfer

Security+ 關鍵字對應答案

🔑 攻擊技術 → 名稱

「用 AD 服務帳號票據離線破解」→ Kerberoasting
「用 NTLM Hash 不知道密碼登入」→ Pass-the-Hash
「攻擊者利用受信任網站下載惡意程式」→ Drive-by Download / Watering Hole
「假冒無線 AP 讓使用者連線」→ Evil Twin Attack
「利用程式未驗證輸入大小」→ Buffer Overflow
「加密你的檔案要贖金」→ Ransomware（加密型勒索軟體）
「利用 URL 中的使用者 ID 讀他人資料」→ IDOR（Insecure Direct Object Reference）/ Broken Access Control
「誘騙使用者點擊惡意連結執行操作」→ CSRF（Cross-Site Request Forgery）

🔑 防禦技術 → 名稱

「完全不信任網路邊界，每次都驗證」→ Zero Trust Architecture
「多層防護，即使一層失效仍安全」→ Defense in Depth（深度防禦）
「高權限帳號 JIT 授權、Session 錄影」→ PAM（Privileged Access Management）
「確保容器映像只來自授權來源」→ Binary Authorization / Container Image Signing
「偵測並回應端點上的可疑行為」→ EDR（Endpoint Detection and Response）
「關聯多個設備的安全日誌找複雜攻擊」→ SIEM（Security Information and Event Management）
「憑證失效的即時查詢」→ OCSP（比 CRL 更即時）

🔑 合規框架 → 適用範圍

GDPR→ 歐盟個人資料保護；72 小時通報；違規罰款高達全球營收 4%
HIPAA→ 美國醫療健康資訊；PHI（Protected Health Information）的安全要求
PCI DSS→ 支付卡行業；持卡人資料（CHD）保護；Tokenization 縮小範圍
SOC 2→ 美國雲端/SaaS 服務商稽核；Trust Service Criteria；Type II 對客戶說服力最強
NIST CSF→ 美國政府框架；5 功能：Identify/Protect/Detect/Respond/Recover
ISO 27001→ 國際 ISMS 標準；可認證；全球企業通用

最常考的混淆概念（一定要區分）

混淆點正確區分
Authentication vs AuthorizationAuthentication（認證）= 你是誰；Authorization（授權）= 你能做什麼。先 AuthN 再 AuthZ。
Vulnerability vs Threat vs Risk漏洞（弱點存在）；威脅（有人想利用它）；風險 = 威脅 × 漏洞 × 影響
IDS vs IPSIDS：被動偵測（旁路），只告警；IPS：主動攔截（In-line），封鎖惡意流量
Symmetric vs AsymmetricSymmetric（AES）：同一把金鑰加解密，速度快；Asymmetric（RSA/ECC）：公鑰加密私鑰解密，速度慢
Hashing vs EncryptionHash：單向，不可逆，用於完整性；Encryption：可逆（有金鑰），用於機密性
RPO vs RTORPO（Recovery Point Objective）：最多可接受損失多少資料；RTO（Recovery Time Objective）：服務必須在多久內恢復
Phishing vs Spear Phishing vs WhalingPhishing：廣泛群發；Spear Phishing：針對特定個人（更精準）；Whaling：針對高管（魚叉釣大魚）
Black Box vs White Box vs Gray Box滲透測試的資訊掌握程度：Black（零知識）/ Gray（部分知識）/ White（完整知識）

考試當天檢查清單

  • 社會工程：Phishing/Spear/Whaling/Vishing/Smishing/Pretexting 的區分
  • 密碼學：對稱（AES-256）vs 非對稱（RSA 2048+）vs 雜湊（SHA-256）的用途
  • 網路安全：防火牆（Stateful/Stateless）、IDS vs IPS、VPN 協議（IPSec/SSL）、DMZ
  • 身分管理：MFA 類型（TOTP/FIDO2/SMS 的安全強度排序）、PAM、SSO（SAML vs OAuth）
  • 事件應變：NIST 六階段（準備→偵測→遏制→根除→復原→事後學習）
  • 數位鑑識：Chain of Custody、先建映像再分析、易失性資料優先採集（記憶體 > 磁碟）
  • 合規：GDPR 72 小時通報、PCI DSS Scope、HIPAA PHI、SOC 2 Type II
  • 風險管理：Qualitative vs Quantitative（ALE = ARO × SLE）
  • 架構：Zero Trust、Defense in Depth、最小權限、職責分離（Separation of Duties）
  • PBQ 策略：先跳過 PBQ，普通題先全部作答，最後 20 分鐘回來處理
