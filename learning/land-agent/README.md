# 地政士（土地登記專業代理人）專技普考：證照通關全能學習系統

> **目標 100% 考取證照！收錄最新修訂四大專業考科深度實務講義、600 題不重複完整解析題庫與全真計時模擬考 Web 學習平台。**

---

## 🌟 專案特色亮點

1. **四大專業考科深度講義（`notes/`）**：
   - 深入整理：民法概要與信託法概要、土地法規與平均地權條例（含打炒房禁轉售重罰5,000萬修法、土地徵收條例、地政士法）、土地登記規則與地籍測量實施規則（登記簿三部別、單獨申請24款、繼承登記與限制登記）、土地稅法規（地價稅2‰自用、土增稅一生一次與一生一屋10%、重購退稅要件與5年列管、房屋稅囤房稅2.0全國歸戶單一自住1%/非自住2.0%~4.8%、契稅六大稅率、遺產及贈與稅法三級累進10/15/20%、房地合一2.0四級距與自住400萬免稅）。
2. **600 題不重複標準題庫（`assets/questions-data.js` & `exam/question-bank-full.md`）**：
   - 題題嚴格包含：【題目】、【選項 A/B/C/D】、【正確答案】、【明確法規依據】、【詳細白話精闢解析】與【考點防呆陷阱提點】。
   - 四大專業科目各 150 題，全方位無死角涵蓋命題大綱。
3. **現代化單機離線互動測驗平台（`index.html`）**：
   - **全真模擬考試**：支援 50 題衝刺模考（45分鐘）或 100 題全真模考（60分鐘），均勻隨機抽題，倒數計時、題目跳題卡、自動評分診斷（60分及格門檻、各科雷達強弱分析）。
   - **章節循序練習**：支援四大專業考科獨立篩選練習，即選即揭示標準答案、法條依據與考點防呆提示。
   - **錯題強化筆記本**：練習或模考做錯之題目自動保存於 LocalStorage，支援針對錯題單獨反覆重測直至精熟。
   - **全題庫關鍵字即時搜尋**：輸入關鍵字（如「房地合一」、「34條之1」、「信託」、「抵押權」、「重購退稅」）即時調出對應考題並高亮標註。
   - **高頻數字速記卡**：考前 30 分鐘必讀 120 組法定天數、月數、年限、稅率、比率、免稅額與罰鍰密碼，支援分類翻卡檢視。
   - **支援深色 / 淺色護眼模式切換**：純前端靜態架構，毋須安裝任何伺服器即可離線暢快運行。
