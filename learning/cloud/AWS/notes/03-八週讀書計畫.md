# AWS SAA-C03 八週讀書計畫

> 每週約 8-10 小時。已有基本概念者可壓縮為 4-6 週（合併週次）。

## 第 1 週：基礎 + IAM 與安全
- AWS 全球基礎架構（Region / AZ / Edge Location）
- IAM：User、Group、Role、Policy、STS、政策評估邏輯
- Organizations 與 SCP、KMS 加密基礎
- 📌 練習：閃卡「安全」分類 + 模擬試題「領域 1」

## 第 2 週：運算 EC2 / Lambda / 容器
- EC2 執行個體類型、購買選項、Placement Group
- Auto Scaling Group 與 ELB（ALB/NLB/GWLB）
- Lambda 限制與使用場景、ECS/EKS/Fargate 區分
- 📌 動手做：免費方案開一台 EC2 + ALB + ASG

## 第 3 週：儲存 S3 / EBS / EFS
- S3 儲存類別、Lifecycle、Versioning、複寫、加密、Bucket Policy
- EBS 類型與快照、EFS/FSx 使用場景
- Storage Gateway、Snow Family、Transfer Acceleration
- 📌 練習：閃卡「儲存」分類；動手建 S3 靜態網站

## 第 4 週：資料庫
- RDS Multi-AZ vs Read Replica（必考）
- Aurora 架構與 Serverless、DynamoDB（容量模式、DAX、Global Tables、Streams）
- ElastiCache Redis vs Memcached、資料庫選型（Redshift/Neptune/Timestream）
- 📌 練習：模擬試題「快速練習」模式測試前四週綜合

## 第 5 週：網路 VPC
- VPC、子網路、路由表、IGW/NAT、SG vs NACL（必考）
- VPC Endpoint、Peering、Transit Gateway、PrivateLink
- Direct Connect vs VPN、Route 53 路由政策
- CloudFront vs Global Accelerator
- 📌 動手做：建一個含公私子網路的 VPC + NAT Gateway

## 第 6 週：應用整合 + 分析 + 彈性架構
- SQS/SNS/EventBridge/Step Functions（解耦必考）
- Kinesis Streams vs Firehose、Athena/Glue/EMR/QuickSight
- 災難復原四策略、AWS Backup、多區域架構
- 📌 練習：模擬試題「領域 2」

## 第 7 週：成本優化 + 監控 + 弱項補強
- Savings Plans/RI/Spot、S3 成本、資料傳輸費
- CloudWatch（Metrics/Logs/Alarms）、CloudTrail、Config
- 📌 完整模擬考一次 → 依「各領域表現」找出弱項回頭複習

## 第 8 週：衝刺
- 每天一輪「錯題複習」模式直到全對
- 重讀《服務對照速查表》與《四大領域重點筆記》
- 官方 Exam Prep（Skill Builder 有免費 SAA-C03 練習題組）
- 考前一天：只看速查表，早點睡
