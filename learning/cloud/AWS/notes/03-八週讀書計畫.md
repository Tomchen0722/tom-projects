# AWS SAA-C03 八週讀書計畫

> 教材共 **22 章 + 應試策略**，題庫 **116 題**、閃卡 **71 張**。
> 每週約 10-12 小時。已有雲端經驗者可壓縮為 5-6 週（合併第 2+3 週、第 6+7 週）。
> 每週的「📖 讀」直接對應教材檔名，「📌 練」對應題庫與閃卡的分類。

---

## 第 1 週：基礎 + IAM 與安全

📖 讀：`basics.html`、`01-account-iam.html`、`12-identity-api.html`

- AWS 全球基礎架構（Region / AZ / Edge Location）
- IAM：User、Group、Role、Policy、STS、政策評估邏輯
- Cognito 兩個池的差別、API Gateway 三種授權
- Organizations 與 SCP、KMS 加密基礎
- 📌 練：閃卡「安全」分類 + 模擬試題「領域 1」

---

## 第 2 週：運算 EC2 / Lambda / 容器

📖 讀：`03-ec2-storage.html`、`06-elb-asg.html`、`07-serverless.html`

- EC2 執行個體類型、五種購買選項、Placement Group
- Auto Scaling Group 與 ELB（ALB/NLB/GWLB）、**Warm Pool 與 Lifecycle Hook**
- Lambda 限制、冷啟動、併發模型、冪等性
- SQS / SNS / EventBridge / Step Functions 的分工
- 📌 練：閃卡「運算」分類；動手做 EC2 + ALB + ASG

---

## 第 3 週：容器與 CI/CD

📖 讀：`11-ecs-containers.html`、`16-eks.html`、`17-cicd.html`、`10-iac.html`

- ECS 架構、Task Definition、**三層 IAM 角色**、Fargate vs EC2 啟動類型
- ECS vs EKS 的四個判斷點、IRSA、VPC CNI 的 IP 耗盡、Karpenter
- Code 家族四兄弟、四種部署策略、OIDC 免金鑰
- CloudFormation / Terraform / CDK 的取捨
- 📌 練：閃卡「容器」分類

---

## 第 4 週：儲存 S3 / EBS / EFS / FSx

📖 讀：`04-s3-deep.html`、`20-file-backup.html`

- S3 儲存類別、Lifecycle、Versioning、複寫、加密、Bucket Policy
- **S3 進階**：Select、Access Point、Multi-Region Access Point、Object Lambda、Requester Pays、Batch Operations
- **CloudFront 內容保護**：OAC、Signed URL vs Signed Cookie、Functions vs Lambda@Edge
- EBS 類型與快照、**FSx 四種的判斷順序**、EFS 儲存類別與吞吐模式
- **Storage Gateway 四種**（Cached vs Stored 別搞反）
- **AWS Backup、Vault Lock、DLM 的分界**
- 📌 練：閃卡「儲存」分類；動手建 S3 靜態網站 + CloudFront

---

## 第 5 週：資料庫

📖 讀：`05-database.html`

- RDS Multi-AZ vs Read Replica（必考）
- Aurora 架構、Serverless v2、Global Database、Blue-Green
- DynamoDB（容量模式、DAX、Global Tables、Streams、分區鍵設計）
- ElastiCache Redis vs Memcached vs MemoryDB
- 專用資料庫：Redshift / Neptune / Timestream / QLDB / DocumentDB / Keyspaces
- 📌 練：閃卡「資料庫」分類；模擬試題「快速練習」測試前五週綜合

---

## 第 6 週：網路 VPC 與混合雲

📖 讀：`02-vpc-build.html`、`19-hybrid-network.html`

- VPC、子網路、路由表、IGW/NAT、SG vs NACL（必考）
- VPC Endpoint、Peering、Transit Gateway、PrivateLink
- **Direct Connect 三種 VIF、DX Gateway 的兩個限制、DX 韌性四等級**
- **DX + VPN 的 BGP 自動備援**、TGW 多路由表隔離與 ECMP
- **Route 53 Resolver 雙向混合 DNS**（Inbound vs Outbound）
- RAM 共享子網路、Egress-Only IGW
- CloudFront vs Global Accelerator、Route 53 路由政策
- 📌 練：閃卡「網路」分類；動手建含公私子網路的 VPC + NAT Gateway

---

## 第 7 週：分析、AI、遷移 + 維運治理

📖 讀：`13-analytics.html`、`14-ai-ml.html`、`15-migration.html`、`21-ssm-directory.html`、`22-governance-edge.html`

- Kinesis 四兄弟、Athena 降成本四手段、Glue / Lake Formation / OpenSearch / MSK
- AI 服務三層架構、Textract vs Rekognition、Transcribe vs Polly
- **遷移 7R、DataSync vs Storage Gateway、DMS + SCT、DRS、Transfer Family**
- **SSM 三個前置條件**、Session Manager、Patch Manager、Parameter Store vs Secrets Manager
- **Directory Service 三選一**、Control Tower 三種防護欄、Service Catalog、RAM
- **Outposts / Local Zones / Wavelength 的判斷點**
- 📌 練：閃卡「整合分析」「遷移混合」「維運治理」分類；模擬試題「領域 3」

---

## 第 8 週：架構、資安、成本 + 衝刺

📖 讀：`09-architecture.html`、`18-security-services.html`、`08-monitor-cost.html`、`exam-strategy.html`

- Well-Architected 六大支柱、六種參考架構、**DR 四策略**、情境題五步驟解題法
- GuardDuty / Inspector / Macie / Security Hub 的分工
- **Detective（調查根因）、Audit Manager（我的證據）、Artifact（AWS 的報告）、Firewall Manager（跨帳號）**
- CloudWatch / CloudTrail / Config、FinOps 月度流程
- **成本陷阱**：Interface Endpoint 開太多、TGW vs Peering、跨 AZ 流量、冷儲存最短天數
- 📌 練：**完整模擬考 116 題** → 依「各領域表現」找出弱項
- 📌 每天一輪「錯題複習」模式直到全對
- 考前兩天：重讀《服務對照速查表》，特別是最後的「最容易搞反的十二組」
- 考前一天：只看速查表，早點睡

## 讀不完的話：優先順序

時間不夠時照這個順序砍，效益由高到低：

| 優先 | 章節 | 理由 |
|---|---|---|
| **必讀** | 01 IAM、02 VPC、03 EC2/儲存、04 S3、05 資料庫、06 ELB/ASG、07 無伺服器 | 這七章涵蓋約六成的題目 |
| **必讀** | `exam-strategy.html` + 兩份速查筆記 | 投報率最高的兩小時 |
| **高** | 09 架構與 DR、19 混合網路、20 檔案與備份 | DR 與混合網路是每次必考 |
| **中** | 08 監控成本、18 資安服務、21 SSM、22 治理 | 題數穩定但單題不難 |
| **中** | 11 ECS、15 遷移 | 各約 2-4 題 |
| **可略讀** | 10 IaC、13 分析、14 AI/ML、16 EKS、17 CI/CD | SAA 只考選型層次，不考細節 |
