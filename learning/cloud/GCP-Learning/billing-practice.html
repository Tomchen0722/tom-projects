GCP 計費實戰練習

ACE 考試必考！Sustained Use Discount、Committed Use、BigQuery 計費、Egress 費用——全部用計算題練熟。

1. GCP 計費的四個維度

運算（Compute）
vCPU + RAM
按秒計費，最少 1 分鐘。關機後停收 CPU/RAM，但磁碟仍收費。
儲存（Storage）
GB × 月
GCS 按實際儲存量，Cloud SQL 按佈建空間，BigQuery 按儲存資料量（前 10 GB 免費）。
網路 Egress
進免費，出收費
資料流出 GCP 收費，流入（Ingress）免費。同 Region 內傳輸免費，跨 Region 或出網路都要錢。
API 呼叫量
請求數 / 掃描量
BigQuery 按掃描 TB 計費。Cloud Functions 按呼叫次數和執行時間。Cloud Run 按 CPU×秒。

自動

無需承諾，用越多折越多
最高57%
Committed Use Discount
（CUD / 承諾使用折扣）

最高91%
Preemptible / Spot VM
隨時可中斷，適合批次

Sustained Use Discount（SUD）計算邏輯

SUD 分段折扣（Compute Engine N1/N2 系列）：
使用率 0%-25% → 按全價計費
使用率 25%-50% → 這段打 80%（折 20%）
使用率 50%-75% → 這段打 60%（折 40%）
使用率 75%-100% → 這段打 40%（折 60%）

整個月跑滿的等效折扣：約 30%
重要：SUD 是自動計算的，不需要任何設定
練習 1：一台 n2-standard-4 VM 在某月跑了 100% 的時間（730 小時），全價 $0.2 / 小時。SUD 後實際費用？
查看解答
計算步驟：
全月 730 小時，把它分成四段：
0-25%（0-182.5 小時）：182.5 × $0.2 = $36.50
25-50%（182.5-365 小時）：182.5 × $0.2 × 0.8 = $29.20
50-75%（365-547.5 小時）：182.5 × $0.2 × 0.6 = $21.90
75-100%（547.5-730 小時）：182.5 × $0.2 × 0.4 = $14.60
總計 = $102.20（若全價跑滿是 $146，SUD 後省約 30%）

實際上 GCP 不要求你手算，但要知道 SUD 自動觸發且最多約 30% 折扣。

Committed Use Discount（CUD）選擇

類型承諾方式折扣適合情境
Resource-based CUD承諾特定 vCPU + 記憶體最高 57%（3年）已知的固定工作負載（資料庫、常駐服務）
Spend-based CUD承諾每月最低消費金額最高 17%Cloud Run、Cloud SQL 等不好預估資源量的服務
考試陷阱：CUD 是承諾，不管是否實際使用都要付費。如果工作負載波動大、無法確定需求，CUD 可能得不償失。SUD 無此風險（自動、免承諾）。

3. BigQuery 計費模式

模式收費方式適合情境
On-demand（按需）每掃描 1 TB 收 $5
前 1 TB/月免費		不定期查詢、流量小
Capacity（容量型）
前稱 Flat-rate		購買 Slot（計算單元），月/年承諾
100 Slot 起，約 $1,600/月		高頻查詢、大企業
儲存費Active：$0.02/GB/月
Long-term（90天未修改）：$0.01/GB/月（半價）		所有使用者都收
練習 2：分析師每天執行 3 次查詢，每次掃描 50 GB。一個月（30 天）的 BigQuery 查詢費是多少？
查看解答
計算：
每月掃描量：3 次 × 50 GB × 30 天 = 4,500 GB = 4.5 TB
前 1 TB 免費，收費部分：4.5 - 1 = 3.5 TB
費用：3.5 × $5 = $17.50 / 月

優化建議：在 Query 上加 SELECT 指定欄位（避免 SELECT *）、分區表只掃描所需分區，可以把掃描量砍到 1/10 以下。
BigQuery 成本控制三招：
① --maximum_bytes_billed：設上限，超過就取消查詢，防止意外高費
② --dry_run：估算掃描量再決定是否執行
③ Partitioning + Clustering：分區讓 BQ 只掃特定日期的資料，Clustering 進一步減少掃描

4. 網路 Egress 費用（最常被忽略）

流量方向費用
Ingress（資料流入 GCP）免費
同 Zone 內 VM 互傳（使用內部 IP）免費
同 Region 不同 Zone 間（使用內部 IP）$0.01 / GB
不同 Region 間$0.01-$0.08 / GB（依 Region）
GCP → 網際網路（前 1 TB/月）$0.12 / GB
GCP → 網際網路（1-10 TB/月）$0.11 / GB
GCP → CDN（Cloud CDN）更低費率（$0.02-$0.08）
練習 3：一個影音串流服務在 GCS（asia-east1）存放 10 TB 影片，每月有 50,000 個使用者各下載 200 MB。不用 CDN 的 Egress 費用？若用 Cloud CDN 可省多少？
查看解答
每月 Egress 流量：50,000 × 200 MB = 10,000,000 MB = 10 TB

不用 CDN：直接從 GCS 到網際網路
前 1 TB：1,024 GB × $0.12 = $122.88
剩餘 9 TB：9,216 GB × $0.11 = $1,013.76
總計約 $1,137 / 月

用 Cloud CDN：CDN Egress 費率約 $0.04/GB（台灣）
假設 95% 流量命中 CDN 快取：9.5 TB × $0.04 = $388
未命中的 5%（0.5 TB）從 GCS → CDN：按較低費率約 $30
Cloud CDN 總計約 $418 / 月，省約 63%

5. Budget Alert 設定與最佳實踐

Budget Alert 的三個觸發點（預設）：
50% 預算消耗 → Email 通知（預警）
90% 預算消耗 → Email 通知（高警戒）
100% 預算消耗 → Email 通知（超出）

自動控制（需自行設定）：
Budget → Pub/Sub → Cloud Functions → 停止 VM / 禁用帳單
⚠️ Budget Alert 本身不會自動停止資源！
情境推薦作法
開發/測試環境防止超支設定預算 Alert → Pub/Sub → Cloud Function 停止所有 Compute VM
BigQuery 防止意外高費--maximum_bytes_billed 或 Table 層級的 Slot Reservation
整個 Org 的費用可視化Billing Export to BigQuery → Data Studio / Looker Studio Dashboard
部門費用分攤Resource 加 Label（如 team:marketing），Billing Report 按 Label 分組

6. Cloud Storage 儲存類別費用比較

儲存類別儲存費（/GB/月）存取費（/GB）最少儲存時間適合情境
Standard$0.020免費無熱資料、頻繁存取
Nearline$0.010$0.0130 天每月存取一次以下（備份）
Coldline$0.004$0.0290 天每季存取一次（災難備份）
Archive$0.0012$0.05365 天每年存取一次以下（法規封存）
練習 4：公司有 5 TB 的日誌需要保存 2 年，預計每季才會查一次。選哪個儲存類別最划算？計算 2 年的儲存費。
查看解答
選擇：Coldline（每季存取一次，符合 ≤ 每月一次，且 90 天最小儲存期限可接受）

2 年儲存費：
5 TB = 5,120 GB
5,120 GB × $0.004 × 24 個月 = $491.52

比較 Standard：5,120 × $0.020 × 24 = $2,457.60
省下：$1,966，省約 80%

注意：若用 Archive（$0.0012），費用更低但每次存取費更高（$0.05/GB），如果每季都要查幾十 GB，Archive 不一定更划算。
