這套教材怎麼用

這不是一本可以「翻完」的書，是一條要「走完」的路。四個使用原則：

  1. 照順序走。每一課都假設你懂前面的內容。跳著看會卡在名詞上。
  2. 實作一定要動手。看懂和做過是兩件事。標示「實作」的課，請真的打開 Cloud Shell 打指令。
  3. 做完自我檢測再往下。每課最後的問答題是「應用題」，答不出來表示還沒真的理解——那就回頭再看一次。
  4. 做完實作記得清理資源。每一課的實作最後都有清理指令，不要跳過。
開始之前必做的一件事

第 03 課會教你設定預算警報。請不要跳過那一步——雲端帳單失控是新手最常見的意外，而且發生時你通常不會馬上知道。設定完再往下走。
