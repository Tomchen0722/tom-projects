GCP 自學道場 — 從零到企業級
================================

【怎麼開始】
用滑鼠左鍵雙擊本資料夾裡的  index.html
（建議用 Chrome 或 Edge 開啟）

【資料夾內容】
  index.html      學習總覽與地圖，從這裡開始
  lessons\        40 堂課程（L01 ~ L40）
  assets\         樣式與程式（請勿刪除或移動）

【使用說明】
1. 課程請照 L01 開始依序學習，每一課都建立在前一課之上。
2. 每課底部有「標記為已完成」按鈕，進度會存在瀏覽器中，
   下次開啟仍然保留。
3. 標示「實作」的課程請實際打開 Google Cloud Shell 動手做，
   只看不做學不會。
4. 每課最後的「自我檢測」是應用題，答不出來代表還沒真正理解。

【重要提醒】
第 03 課會教你設定「預算警報」，請務必不要跳過。
雲端帳單失控是新手最常見的意外。

【建議節奏】
  密集：每週 15~20 小時 → 約 2 個月
  穩定：每週 6~8 小時   → 約 4~5 個月（推薦）
  輕量：每週 3 小時     → 約 8~10 個月
