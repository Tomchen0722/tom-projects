# 字根字首魔法學院 (EtymoRoots Master)

> **English Morphology, Grammar Breakdown & Thematic Reading Master**  
> 一個專為深度英語學習者打造的詞源學與句型語法解析系統。

---

## 🌟 核心特色 (Key Features)

1. **44 組核心字根／字首與繁中原意**
   - 清楚闡釋希臘語與拉丁語古字根（涵蓋 `tele-`, `prot-`, `spect`, `dict`, `port`, `bio`, `auto-`, `chron`, `audi`, `micro-`, `scrib`, `poly-`, `bene-`, `trans-`, `vis/vid`, `geo`, `hydr`, `therm`, `graph/gram`, `phon`, `tract`, `struct`, `ject`, `duc/duct`, `cap/capt/cept`, `ced/ceed/cess`, `mit/miss`, `cred`, `cur/curs`, `fac/fact/fect`, `gen/gener`, `log/logy/loqu`, `ped/pod`, `sens/sent`, `fin`, `jur/jud/jus`, `form`, `nov`, `pel/puls`, `sub-`, `re-`, `inter-`, `mal-`, `super-` 等共 44 組核心語素）。
   - 包含發音音標與語言學背景典故。

2. **757 個核心衍生單字形態拆解公式 (Morphological Equations)**
   - 視覺化算式呈現：`【字首/字根】(原意) + 【基本詞/字尾】(原意) ➔ 【衍生新單字】(繁中)`。
   - 例如：`tele-` (遠) + `phone` (聲音) ➔ `telephone` (電話)。
   - 例如：`proto-` (第一/最初) + `type` (模型/鑄模) ➔ `prototype` (原型、雛形)。
   - 詳細記錄造字邏輯與語意演變路徑，每組字根平均收錄 17~20 個高階衍生詞。

3. **完整雙音標與真人 TTS 發音 (Phonetics & TTS Audio)**
   - 全站「有英文處皆可發音」：單字、音標、語素部件、例句切片、篇章句子、測驗選項皆有獨立 🔊 朗讀按鈕。
   - 支援全站任意雙擊英文單字即時發音 (Universal Double-Click TTS)。
   - 每個單字均標註 **KK 音標** 與 **IPA 國際音標**。
   - 整合 Web Speech API 真人語音引擎，支援 0.75x 慢速、0.9x 自然稍慢、1.0x 標準、1.2x 敏捷語速調節。

4. **權威情境例句與深度句型文法解析 (Grammar Microscope)**
   - 針對 757 個衍生單字打造貼合母語人士語境的經典例句。
   - 提供「句型文法顯微鏡」抽屜，逐層拆解：
     - **主句結構**：S + V + O、五大基本句型、名詞子句、狀詞子句。
     - **句法成分切片**：主詞 (Subject)、謂語動詞 (Predicate)、直接受詞 (Direct Object)、受詞補語、修飾狀詞 (Adverbials)。
     - **文法要點提煉**：時態語態（過去完成被動態、假設語氣等）、分詞構句、關係子句、固定介系詞搭配。

5. **主題篇章短文與卡拉OK動態有聲朗讀 (Thematic Short Stories)**
   - 將同根衍生單字巧妙編織為 44 篇通順流暢的自然小故事。
   - 支援「雙語對照」與「英文純享」檢視模式。
   - 提供「全文有聲伴讀」功能，句子即時高亮同步卡拉OK效果。
   - 每篇附帶篇章閱讀理解測驗 (Comprehension Check)。

6. **多元練習與記憶輔助**
   - **字根拼裝挑戰**：互動拼圖遊戲，組裝語素部件。
   - **3D 翻卡記憶**：支援單字翻面記憶與收藏（LocalStorage 本機持久化保存）。

## 🚀 啟動方式 (Quick Start)

### 方式一：點擊啟動檔 (Windows)
雙擊資料夾內的 `啟動.bat`，系統將自動啟動本機伺服器並在瀏覽器開啟：
`http://127.0.0.1:7025`

### 方式二：靜態瀏覽
直接用瀏覽器開啟 `index.html` 即可使用完整功能。

### 方式三：透過 Tom Chen 專案總控台 (Hub)
已於專案根目錄之 `projects.json` 正式註冊，啟動 Hub 後即可在「語言學習 (LANGUAGE)」類別中看到本系統。
