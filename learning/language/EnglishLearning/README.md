# 英文學習系統 English Learning System

免額外套件的 Python 英文學習程式（語音使用 Windows 內建功能）。

## 啟動方式

雙擊 `啟動.bat`，或在此資料夾執行 `py -3.13 main.py`。

## 功能

| 分頁 | 功能 |
|------|------|
| 📖 字庫與例句 | 4000 個分級單字（初級=國中 1418 / 中級=四級 1600 / 進階=六級 982），KK 音標、繁中釋義、真題例句，可搜尋、發音、慢速發音 |
| 📚 文章導讀 | 20 篇分級文章（英文＋繁中對照），逐段朗讀、全文朗讀、慢速、停止、隨機一篇、翻譯顯示切換 |
| 🧠 圖像記憶 | 圖像記憶法閃卡：emoji 圖像聯想＋彩色音節拆解＋自訂聯想筆記，「記住了/再複習」追蹤，可只複習不熟的字 |
| 👄 嘴型發音 | KK 音標 17 個母音＋24 個子音，嘴型圖解（嘴唇/牙齒/舌位/氣流）、發音要領說明、示範單字朗讀 |
| 📝 單字測驗 | 看中文選英文，四選一，自動朗讀答案並記錄成績 |
| 🎧 聽音練習 | 播放單字或句子聽寫，支援慢速重播 |
| 🎤 發音練習 | 聽示範後對麥克風朗讀，Windows 語音辨識比對評分 |
| ✍ 英文寫作 | 隨機題目、字數統計、基本檢查、朗讀作文、儲存至 essays |

## 檔案說明

- `main.py`：主程式；`extra_tabs.py`：圖像記憶＋嘴型發音模組
- `wordbank.json`：4000 字字庫（`build_wordbank.py` 可重新產生）
- `articles.json`：導讀文章（可自行新增，格式照現有內容）
- `mnemonics.json`：你的聯想筆記；`memory_progress.json`：記憶追蹤
- `progress.json`：測驗成績；`essays/`：儲存的作文

## 需求

- Windows 10/11、Python 3.8+（含 tkinter）
- 產生字庫需要 `opencc-python-reimplemented`（已安裝）；日常使用不需要任何套件
- 發音練習需要麥克風與英文 (en-US) 語音辨識
