# 英文歌學英語系統 (English Song Learning)

專為台灣學習者打造的沉浸式「聽歌學英文」互動學習網頁系統。結合原汁原味經典英語曲目、高解析度雙語歌詞、變速不變調音樂播放器、歌詞單字即點即查字典、聽力克漏字測驗與影子跟讀錄音工作室！

---

## 🌟 核心特色功能

1. **雙語歌詞即時同步 (Smart Bilingual Lyrics)**
   - 英文原文、KK / IPA 音標、精緻繁體中文翻譯對照。
   - 卡拉OK動態發光與自動捲動置中，讓學習節奏永不落後。
   - 單字即點即查：點擊歌詞中的任何英文單字，立即跳出發音音標、詞性與詳細繁中釋義。
   - 單句重點語法、片語、連音 (Linking) 與弱化 (Weak forms) 提示。

2. **慢速變速不變調音樂播放器 (Audio Speed Controller)**
   - 支援 `0.5x`、`0.75x`、`0.85x`、`1.0x`、`1.25x`、`1.5x` 快速切換與 `0.5x ~ 2.0x` 無段微調滑動條。
   - 採用現代瀏覽器音高鎖定保護技術 (`preservesPitch = true`)：**放慢速度時男聲女聲依然自然好聽，絕無變調或機器人聲音**。
   - 支援「單句循環 (A-B Repeat)」：單句無限循環播放，最適合反覆聽寫 (Dictation) 與精聽訓練。
   - 內建高品質 Web Audio 音樂伴奏合成器：零外部依賴、無 404 風險，開箱即聽高品質伴奏。
   - 支援即時動態頻譜可視化 (Audio Visualizer Canvas)。

3. **聽力克漏字練習模式 (Listening Cloze Test)**
   - 自動挑選歌詞關鍵字進行挖空測驗。
   - 支援 0.75x 慢速聽句重播、單句 TTS 朗讀。
   - 支援鍵盤輸入拼寫或四選一單字點選，即時給予連擊回饋與成績統計。

4. **影子跟讀錄音室 (Shadowing Studio)**
   - 透過瀏覽器麥克風進行即時發音錄音。
   - 提供「原唱示範軌」與「我的錄音軌」雙軌比對播放，讓學習者親耳聽出連音與語調差異。

5. **單曲精選單字卡 (Flashcards) & 個人生字筆記本 (Wordbook)**
   - 3D 翻轉單字卡：正面英文與真人發音，背面中文釋義與歌曲出處。
   - 點擊「⭐ 收藏至生字本」，資料持久化儲存於瀏覽器 LocalStorage。
   - 支援一鍵匯出生字本為文字檔 (TXT)，方便匯入 Anki 或 Quizlet。

6. **自訂歌曲與 LRC 匯入器 (Custom Song & LRC Importer)**
   - 支援匯入任何您喜愛的 MP3 音訊檔案。
   - 支援貼上或上傳標準 LRC 時間戳記歌詞，客製化您的專屬英語學習曲目庫。

## 🚀 啟動方式

### 方法一：雙擊啟動腳本
在專案目錄下雙擊 `啟動.bat`，系統將自動啟動本機伺服器並在預設瀏覽器中開啟頁面。

### 方法二：指令列啟動
```bash
# 在本專案目錄下執行
python -m http.server 7020
```
然後在瀏覽器中開啟 [http://127.0.0.1:7020](http://127.0.0.1:7020)。

## ⌨️ 鍵盤快捷鍵

| 按鍵 | 功能說明 |
|------|---------|
| `Space` | 播放 / 暫停歌曲 |
| `←` / `→` | 倒退 5 秒 / 快轉 5 秒 |
| `↑` / `↓` | 播放速度加快 0.1x / 放慢 0.1x |
| `[` / `]` | 跳至上一句歌詞 / 跳至下一句歌詞 |
| `L` | 切換當前單句循環模式 (A-B Repeat) |
| `Esc` | 關閉單字查詢彈窗 |

## 📁 檔案結構

```
learning/language/english-songs/
├── index.html              # 沉浸式前端主頁面
├── css/
│   └── style.css           # 現代暗黑黑膠演播室風格 Glassmorphism 樣式表
├── js/
│   ├── songs-data.js       # 預載歌曲資料庫 (含精準 LRC 時間戳、歌詞、翻譯、音標、單字庫)
│   ├── audio-player.js     # 音訊播放引擎 (含 Web Audio 伴奏合成、變速不變調、頻譜分析)
│   ├── lyrics-engine.js    # 歌詞同步引擎 (毫秒級同步、單字分詞點擊、字典查詢、LRC 解析)
│   ├── learning-modes.js   # 學習模式管理器 (聽力克漏字、錄音比對、單字閃卡、生字本)
│   └── app.js              # 主控制器 (事件調度、快捷鍵、視覺化動畫)
├── 啟動.bat                 # Windows 一鍵啟動腳本
└── README.md               # 專案詳細說明文件
```
