🧩 題型 04

邏輯推導題

三段論、真假話、排序推理。學會符號化與畫表格,再繞的題目都能拆。

🎯 核心心法:不要用「感覺」推理

邏輯題最大的陷阱是「聽起來很合理」。人的直覺常常會補上題目沒說的假設,結果推出錯誤結論。

正確做法有兩個:①把文字符號化(變成「若 P 則 Q」的形式)②把資訊畫成表格。一旦視覺化,答案往往就自己跳出來了。

💡 鐵則:只能用題目給的資訊推理,不能加入常識。就算題目說「所有的鳥都不會飛」,在這題裡它就是真的。邏輯題考的是推理的形式,不是內容對不對。

🔗 一、條件推理:四種命題(最重要)

原命題:若 P 則 Q(例:若下雨,則地濕)

名稱形式範例與原命題等價?
原命題若 P 則 Q若下雨,則地濕—
逆否命題若 非Q 則 非P若地不濕,則沒下雨✓ 等價(一定對)
逆命題若 Q 則 P若地濕,則下雨✗ 不等價
否命題若 非P 則 非Q若沒下雨,則地不濕✗ 不等價
💡 為什麼逆命題不成立?因為「地濕」可能是別的原因造成的——灑水車經過、有人潑水。原命題只保證「下雨 → 地濕」這個方向,不保證反過來。

只有「逆否命題」與原命題等價。這是整個邏輯題最該記牢的一句話,考試出現頻率極高。

有效推理 vs 常見謬誤

推理方式形式是否有效
肯定前件已知「若P則Q」與「P成立」→ 推出 Q✓ 有效
否定後件已知「若P則Q」與「Q不成立」→ 推出 非P✓ 有效
肯定後件(謬誤)已知「若P則Q」與「Q成立」→ 推出 P✗ 無效
否定前件(謬誤)已知「若P則Q」與「P不成立」→ 推出 非Q✗ 無效
⚠️ 記憶口訣:「肯前、否後」有效;「肯後、否前」是謬誤。

白話理解:「下雨 → 地濕」
• 看到下雨 → 一定地濕 ✓(肯定前件)
• 看到地乾 → 一定沒下雨 ✓(否定後件)
• 看到地濕 → 一定下雨了? ✗(可能是灑水)
• 沒下雨 → 地一定乾? ✗(可能有人潑水)

🔺 二、三段論與集合關係

✓ 有效的三段論
前提1:所有的 A 都是 B
前提2:所有的 B 都是 C
結論:所有的 A 都是 C ✓

例:所有貓都是哺乳類;所有哺乳類都是動物 → 所有貓都是動物 ✓
✗ 常見的無效推理
前提1:所有的貓都是動物
前提2:有些動物是黑色的
結論:有些貓是黑色的?✗ 無效!

因為「有些動物是黑色的」中的那些動物,可能完全不包含貓(可能全是黑狗)。題目沒說,就不能推。
💡 看到「有些」「某些」就要提高警覺。包含「所有」的前提可以往下傳遞;但含「有些」的前提,推導能力很弱,通常無法得出確定結論。

實用技巧:畫圈圈(文氏圖)。把每個類別畫成一個圈,「所有 A 是 B」就把 A 圈畫在 B 圈裡面。畫完之後,結論成不成立一目了然——而且你會發現,只要能畫出一種反例,那個結論就不成立。

🎭 三、真假話問題

典型題型:幾個人各說一句話,已知其中幾句真幾句假,推出真相。

例:甲、乙、丙三人中有一人打破了窗戶。
甲說:「不是我。」
乙說:「是丙。」
丙說:「乙在說謊。」

已知三人中只有一人說真話。請問是誰打破的?

解法 A:矛盾法(快)

1
找矛盾對——乙說「是丙」,丙說「乙說謊」。這兩句必定一真一假(不可能同真也不可能同假)。
2
推論——既然唯一的一句真話已經在乙丙之中,那麼甲說的必定是假話。
3
解出答案——甲說「不是我」是假話 → 就是甲打破的。

解法 B:窮舉法(穩)

假設甲「不是我」乙「是丙」丙「乙說謊」真話數
甲打破假假真1 ✓ 符合
乙打破真假真2 ✗
丙打破真真假2 ✗

答案:甲打破的。

💡 兩種解法怎麼選?時間充裕、人數少(3–4 人)→ 用窮舉法最保險,把表格畫出來絕不會錯。時間緊迫 → 先找矛盾對(互相否定的兩句話),常常三秒破題。

找矛盾對的訣竅:看有沒有兩句話「一句說 X 是真、另一句直接否定它」。這種組合必定一真一假,可以立刻縮小範圍。

📊 四、排序推理(表格法)

例:甲、乙、丙、丁四人比賽,名次無並列。已知:
① 乙的名次比甲前面
② 丙不是第一名,也不是第四名
③ 丁的名次比乙前面

請問第一名是誰?
1
把關係串起來——由 ③ 丁<乙,由 ① 乙<甲,合併得 丁 < 乙 < 甲(名次越前數字越小)。
2
放入限制——由 ② 丙只能是第 2 或第 3 名。
3
逐一嘗試——
若丙=第2 → 丁乙甲依序填 1、3、4
若丙=第3 → 丁乙甲依序填 1、2、4
4
找出必然成立的部分——兩種情況下,丁都是第一、甲都是第四。所以第一名必定是丁。
⚠️ 這題有個重要觀念:資訊不足時,答案可能只有「部分確定」。
上例中乙與丙的先後無法確定(兩種排法都成立),但丁第一、甲第四是確定的。

所以甄試常這樣問:「以下何者必定為真?」——你要選的是在所有可能情況下都成立的那一項,而不是「有可能成立」的。看到「必定」「一定」這種字眼,就要檢查每一種可能。
💡 排序題的通用做法:①先把所有「A 在 B 前面」的關係串成一條鏈 ②把「不是第幾名」這類限制標在表格上 ③剩下的可能性通常只有一兩種,列出來比對即可。
一定要動手畫,純用腦袋想三個人以上就會亂。

📋 邏輯題速查表

題型辨識特徵解法
條件推理出現「若⋯則⋯」「只要⋯就⋯」符號化,記住只有逆否等價
三段論「所有」「有些」「沒有」畫文氏圖,找反例
真假話幾人發言,說明有幾句真假找矛盾對,或窮舉表格
排序推理名次、座位、順序串關係鏈 + 畫表格
對應配對誰對應什麼(職業、顏色、城市)畫二維表格,用 ○✗ 逐格刪

⚠️ 四個必記的陷阱

陷阱說明
加入常識只能用題目給的前提推理,不能用現實世界的知識補充
把逆命題當成立「若P則Q」不能推出「若Q則P」
「有些」當「所有」用含「有些」的前提推導力很弱,常無法得出確定結論
混淆「可能」與「必定」問「必定為真」時,只要能舉出一個反例就不成立
💡 「必定為真」類型的萬用解法:找反例。不必證明它對,只要能想出一種符合所有條件、但讓該選項不成立的情況,就能刪掉它。刪到只剩一個,答案就出來了。這比正面推導快得多。

📝 隨堂練習

Q1. 已知「若小明有考到證照,則他會被錄取」。現在得知小明沒有被錄取。可以推論出什麼?

Q2. 前提:所有的工程師都會寫程式;小華會寫程式。可以推論「小華是工程師」嗎?為什麼?

Q3. A、B、C 三人中有一人考滿分。
A 說:「是 B。」　B 說:「不是我。」　C 說:「不是我。」
已知三人中只有一人說真話,誰考滿分?

Q4. 甲乙丙三人身高不同。已知「甲比乙高」「丙不是最高」。以下何者必定為真?
(A) 甲最高　(B) 乙最矮　(C) 丙比乙高　(D) 以上皆不必定

▶ 看解析
A1. 可以推論:小明沒有考到證照。
這是否定後件,屬於有效推理(等同逆否命題)。原命題「有證照 → 被錄取」的逆否是「沒被錄取 → 沒有證照」,兩者等價。

A2. 不可以。這是肯定後件的謬誤。
「所有工程師都會寫程式」只保證「工程師 → 會寫程式」這個方向。會寫程式的人可能是設計師、學生、業餘愛好者。畫文氏圖看:工程師的圈在「會寫程式」的圈裡面,但圈外還有很大空間,小華可能在那裡。

A3. 答案:C 考滿分。用窮舉法逐一檢驗:
• 若是 A:A說「是B」→假、B說「不是我」→真、C說「不是我」→真 → 真話 2 句 ✗
• 若是 B:A→真、B→假、C→真 → 真話 2 句 ✗
• 若是 C:A說「是B」→假、B說「不是我」→真、C說「不是我」→假 → 真話 1 句 ✓
只有「C 考滿分」符合「只有一人說真話」的條件。
提醒:這類題目一定要三種情況都檢查完,不能找到一個看似成立就停——因為題目的條件(幾句真話)正是用來排除其他情況的關鍵。

A4. 答案 (A) 甲最高。
推理:由「丙不是最高」→ 最高的只可能是甲或乙;又由「甲比乙高」→ 乙不可能最高。
兩者合起來 → 最高必定是甲。

為什麼其他選項不必定?符合條件的排法有兩種:
• 情況①:甲 > 乙 > 丙　　• 情況②:甲 > 丙 > 乙
(B) 乙最矮 → 情況①中最矮的是丙,不成立 ✗
(C) 丙比乙高 → 情況①中丙比乙矮,不成立 ✗
這就是「必定為真」題的標準解法:列出所有可能情況,只要有一種情況讓該選項不成立,就刪掉它。
