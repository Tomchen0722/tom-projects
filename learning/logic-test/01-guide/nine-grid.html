九宮格例題詳解

七種規律、七道例題。每一題都把「拿到題目後腦袋該怎麼跑」一步步寫出來,
不是只公布答案。看完你會有一套穩定的解題流程。

🎯 先記住這套流程

後面每一道例題,我都會照這套流程走一遍。看多了你就會內化成直覺:

步驟做什麼如果沒發現規律 →
1數線條,寫成 3×3 數字表往下一步
2看橫列數字(左→右)看直行
3看直行數字(上→下)看是否疊加
4數字沒變化 → 想疊加運算(OR/AND/XOR)看種類/位置
5每格數量都一樣 → 看種類分布或位置移動—
6推出答案該有幾條線 → 刪掉數量不符的選項—
7用另一列驗證規律成立,再作答—
💡 為什麼第一步永遠是「數線條」?因為數字是客觀的——不需要靈感、不會看走眼。而且出題者約有七成的規律建立在數量上。先把數字表寫出來,規律常常自己就跳出來了。
例題 1 數量遞減 難度:★☆☆(入門,完整示範數線條法)
問號處應該填哪一個?
A ✓
B
C
D
1
數線條,寫成數字表
別急著看圖形長怎樣,先一格一格數裡面有幾條線(外框不算):
左中右
第1列321
第2列321
第3列32?
▲ 把九格的線條數寫成這張表
2
看橫列:規律出現了
每一列由左到右都是 3 → 2 → 1,每次少一條線。
第三列已經是 3 → 2 → 所以問號處應該是 1 條線。
3
用另一列驗證
第一列:3 → 2 → 1 ✓　第二列:3 → 2 → 1 ✓
兩列都成立,規律確定不是巧合。(這一步很重要,別跳過)
4
數選項的線條數,直接刪
A = 1 條　B = 2 條　C = 3 條　D = 0 條
只有 A 是 1 條 → 答案就是 A,連「是哪一條線」都不用想。
✅ 答案:A(↗ 對角線)　解題只用了「數數字」,完全沒有猜。
💡 這題學到:數線條法的威力。很多人看到滿滿的線就慌了,但只要把它翻譯成 3、2、1 這種數字,難度立刻降到小學程度。

另外注意:這題四個選項的線條數剛好都不一樣(1/2/3/0),所以「算出數量」就直接定答案。這是甄試常見的設計,善用它可以省下大量時間。
例題 2 相加疊合 OR 難度:★★☆(數量只能縮小範圍,還要看組成)
問號處應該填哪一個?
A ✓
B
C
D
1
數線條
左中右
第1列112
第2列112
第3列11?
2
看橫列:1 + 1 = 2
前兩格都是 1 條,第三格是 2 條——剛好等於前兩格相加。
這是相加疊合(OR)的招牌特徵:第三格 = 前兩格的線全部合併。
3
驗證組成(不能只看數字)
第一列:水平 + 垂直 → 第三格是十字 ✓ 確實是兩條合併
第二列:↘ + ↗ → 第三格是 X 交叉 ✓ 也是合併
規律確認:第三格 = 第一格 ∪ 第二格
4
套用到第三列
第三列:第一格是水平線,第二格是↘ 對角線
合併起來 → 水平線 + ↘ 對角線
5
對照選項
先用數量刪:A、B、D 都是 2 條,C 只有 1 條 → 先刪掉 C
再看組成:A = 水平+↘ ✓　B = 水平+垂直 ✗　D = ↘+↗ ✗
→ 答案是 A
✅ 答案:A(水平線 + ↘ 對角線)
❌ 為什麼 B、D 是陷阱?
它們的線條數都對(2 條),但組成錯了。B 抄了第一列的答案(十字)、D 抄了第二列的答案(X)。出題者故意把「其他列的正確答案」放進選項,測你有沒有真的套用規律。
💡 這題學到:當數字表出現 1、1、2 或 2、2、4 這種「前兩個相加等於第三個」的形態時,幾乎可以確定是 OR 疊加。

但要注意:數量只能幫你刪掉一部分選項,最後還是要回頭確認「是哪幾條線」。這一步不能省。
例題 3 去同存異 XOR 難度:★★☆(數字全一樣,要想到疊加)
問號處應該填哪一個?
A ✓
B
C
D
1
數線條
左中右
第1列222
第2列222
第3列22?
2
數字全是 2 → 數量規律不存在
沒有遞增、沒有遞減、也不是相加(1+1=2 才是相加,這裡是 2+2≠2)。
數量完全沒有變化 → 立刻跳到「疊加運算」這條路。
而且問號處也應該是 2 條線。
3
判斷是哪種疊加
三種疊加的判斷法:
• 第三格最複雜 → 相加 OR(這題不是,都一樣是 2 條)
• 第三格最簡單 → 求同 AND(這題也不是)
• 三格差不多,但第三格少了重複那條 → 去同存異 XOR ✓
4
用第一列驗證 XOR
第一列:格1 = {水平, 垂直}　格2 = {垂直, ↘}
兩格共同有「垂直」→ 刪掉;只出現一次的「水平」和「↘」→ 保留
結果 = {水平, ↘} → 對照圖,第三格正是水平+↘ ✓
5
再用第二列確認
格1 = {↘, ↗}　格2 = {↘, 水平}
共同的 ↘ 刪掉 → 剩 {↗, 水平} → 對照圖第三格 ✓ 規律確定
6
套用到第三列
格1 = {水平, ↗}　格2 = {水平, 垂直}
共同的水平刪掉 → 剩 {↗, 垂直} → 答案 A
✅ 答案:A(↗ 對角線 + 垂直線)
❌ 陷阱在哪?B、C、D 全都是 2 條線,光靠數量一個都刪不掉。這題非得看懂 XOR 規則不可。
其中 B(水平+↗)是最容易選錯的——因為它保留了「水平」,而水平正是該被刪掉的那條共同線。
💡 這題學到:看到數字表整片都一樣(2、2、2),不要愣住——這正是在告訴你「規律不在數量,在組成」,直接跳到疊加運算去試。

XOR 的白話記法:「兩張都有的消掉,只有一張有的留下」。像兩張投影片疊起來,重疊的地方反而變不見。
例題 4 直行規律 難度:★★☆(橫列失效,必須換方向)
問號處應該填哪一個?
A ✓
B
C
D
1
數線條
左中右
第1列111
第2列222
第3列33?
2
看橫列:沒有變化
第一列 1、1、1;第二列 2、2、2 —— 左右完全沒變。
橫列這條路走不通,不要卡住,立刻換方向。
3
改看直行:規律出現了
由上往下看:
左行 1 → 2 → 3　中行 1 → 2 → 3　右行 1 → 2 → ?
每一行都是往下每次多一條線 → 問號處是 3 條。
4
確認「多的那條是怎麼加的」
右行:第一格 = ↘　第二格 = ↘ + ↗(保留舊的、加一條新的)
第三格 = ↘ + ↗ + 再加一條 → 應該是 3 條
5
數選項刪答案
A = 3 條　B = 2 條　C = 1 條　D = 4 條
只有 A 是 3 條 → 答案 A
✅ 答案:A(↘ + ↗ + 垂直,共 3 條)
💡 這題學到:橫列沒規律不代表題目無解,只代表你看錯方向。

數字表最大的好處就在這裡——一旦寫成表格,你可以免費地橫著看一遍、直著看一遍,不用重新盯圖。如果只用眼睛看圖形,換方向要重看九次,很容易亂掉、也很花時間。
例題 5 種類分布(拉丁方陣) 難度:★★★(數線條完全無效)
問號處應該填哪一個?
A ✓
B
C
D
1
數線條:全部都是 1
左中右
第1列111
第2列111
第3列11?
每一格都只有 1 條線。數量這條路徹底沒用了——橫的直的都沒變化。
2
數量無效 → 改記錄「種類」
既然每格都是 1 條,那差別一定在「是哪一種線」。
用代號重畫一次表格:H=水平、V=垂直、D=↘對角
左中右
第1列HVD
第2列VDH
第3列DH?
3
看出來了:像數獨
每一列都剛好出現 H、V、D 各一次:
第1列 H V D ✓　第2列 V D H ✓　第3列 D H ?
第三列已經有 D 和 H → 還缺 V(垂直線)
4
用直行雙重驗證
右行由上到下是 D、H、? → 也剛好缺 V ✓
橫看直看都指向垂直線,答案非常確定。
✅ 答案:A(垂直線)
💡 這題學到:當數字表整片都是同一個數字時,不要繼續在數量上鑽——那是死路。要立刻切換到「種類」這個維度。

好用的做法:把圖形換成代號(H、V、D)重畫表格。把圖變成字母後,規律會變得非常明顯——這題一旦寫成字母表,你會發現它其實就是一個 3×3 的數獨,而數獨誰都會解。

這也是圖形題的通則:想辦法把「圖」翻譯成「符號或數字」,大腦處理起來會快很多。
例題 6 位置移動 難度:★★★(數量相同,規律藏在位置)
問號處應該填哪一個?
A ✓
B
C
D
1
數線條
左中右
第1列111
第2列222
第3列22?
橫列沒變化;直行是 1、2、2 也不成規律。數量這條路又斷了。
2
數量無效 → 檢查「位置」
數量斷了之後,依流程下一個要看的是位置。
仔細看第一列的三格:都只有一條水平線,但高度不一樣——
靠上 → 中間 → 靠下,水平線一格一格往下移!
3
用第二列驗證
第二列每格都多了一條垂直線(整列固定不變),而水平線一樣是
靠上 → 中間 → 靠下 ✓ 規律成立。
4
拆解第三列的兩層規律
第三列有兩個要素要同時滿足:
① 水平線位置:靠上 → 中間 → 靠下
② 固定搭配的第二條線:這一列都是 ↘ 對角線
→ 答案 = 靠下的水平線 + ↘ 對角線
5
對照選項
A = 下水平 + ↘ ✓
B = 上水平 + ↘ ✗(位置錯)
C = 中水平 + ↘ ✗(位置錯)
D = 下水平 + 垂直 ✗(第二條線錯,那是第二列的)
✅ 答案:A(靠下的水平線 + ↘ 對角線)
❌ 這題的選項設計很陰險:四個選項全都是 2 條線,而且都長得很像。B、C 只錯在水平線的高度,D 只錯在第二條線的種類。只要有一個維度沒檢查到就會選錯。
💡 這題學到:當一題同時有兩層規律(位置在變 + 某條線固定),要分開處理、各自確認,不要混在一起想。

實用做法:在紙上把兩層分開寫——
「第①層:水平線位置 上/中/下」
「第②層:附加線 第1列無、第2列垂直、第3列↘」
寫成兩行之後,答案就是把兩層的結論合起來,不容易漏。
例題 7 求同 AND 難度:★★★(第三格反而變簡單)
問號處應該填哪一個?
A ✓
B
C
D
1
數線條
左中右
第1列332
第2列332
第3列33?
2
關鍵觀察:第三格反而「變少」
3、3 → 2。第三格比前兩格都簡單。
這不可能是相加(相加會變 6 條),只可能是「刪掉了一些線」。
→ 問號處應該是 2 條線。
3
是 AND 還是 XOR?
兩者都會讓線變少,怎麼分?
• AND(求同):只留下兩格都有的線
• XOR(去同存異):剛好相反,把兩格都有的刪掉
直接拿第一列驗算看看是哪一種。
4
用第一列驗算
格1 = {水平, 垂直, ↘}　格2 = {垂直, ↘, ↗}
兩格共同有:垂直、↘
對照圖中的第三格 → 正是垂直 + ↘ ✓
確定是 AND(保留共同的),不是 XOR。
5
用第二列再確認一次
格1 = {水平, ↘, ↗}　格2 = {水平, 垂直, ↗}
共同的:水平、↗ → 對照第三格 ✓ 規律穩了
6
套用到第三列
格1 = {水平, 垂直, ↗}　格2 = {垂直, ↘, ↗}
共同的 = 垂直、↗ → 答案 A
✅ 答案:A(垂直線 + ↗ 對角線)
❌ D 是最大的陷阱——它有 3 條線,一看就跟前兩格「感覺比較搭」。但數字表明明白白告訴你第三格是 2 條。先算數量,就不會被視覺感覺騙走。
💡 這題學到:看到第三格比前兩格簡單,就是在喊「我是 AND 或 XOR」。分辨方法很簡單——拿第一列直接驗算一次就知道是哪一種,不用猜。

三種疊加的一句話總結:
• OR 相加 → 第三格最複雜(1+1=2)
• AND 求同 → 第三格最簡單(3、3→2)
• XOR 去同存異 → 三格差不多(2、2、2)
光看數字表的「胖瘦」,就能三選一。

🎓 七題總複習:遇到什麼狀況、做什麼事

數字表長這樣代表什麼對應例題
3、2、1 或 1、2、3數量遞減/遞增例題 1
1、1、2(前兩個相加)相加疊合 OR例題 2
2、2、2(整片一樣)去同存異 XOR例題 3
橫的沒變、直的在變規律在直行例題 4
全部都是 1(完全沒差)看種類分布(拉丁方陣)例題 5
數量一樣但圖不同看位置移動例題 6
3、3、2(第三格變少)求同 AND例題 7
💡 把這張表記起來,九宮格就贏一半了。因為你不再是「盯著圖等靈感」,而是先寫出數字表,再用表格的形狀去對照該用哪一招。這是一個機械式的流程,壓力再大也不會當機。
⚠️ 最後三個提醒:
① 永遠用第二列驗證——只看第一列就下結論,很容易踩到出題者設計的假規律。
② 算出數量先刪選項——就算看不出「是哪幾條線」,光靠數量常常就能刪掉 2–3 個,剩下用猜的期望值也高很多。
③ 60 秒沒方向就跳過——標記起來最後再回頭。卡題是甄試最大的殺手,一題卡三分鐘等於放棄三題。
