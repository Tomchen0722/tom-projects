AAI 基礎與學習範式

人工智慧初一
Artificial Intelligence
讓電腦展現原本需人類智慧才能完成之行為的技術總稱，核心能力為學習、推理、自我修正。
狹義 AI初一
Narrow AI / Weak AI
只專精單一任務、無法遷移能力。目前所有商用 AI 都屬此類——這是最常考的判斷點。
通用 AI初一
AGI
能像人一樣把能力自由遷移到各種未訓練過的任務，尚未實現。
超級 AI初一
ASI
在幾乎所有領域全面超越最頂尖人類的假想系統，僅存在於理論討論。
圖靈測試初一
Turing Test
評審透過文字同時與人和機器對話，若無法分辨即認定機器具智慧行為。測「像不像人」，不保證真的理解。
中文房間初一
Chinese Room
哲學思想實驗（非可操作的測試），用來反駁「輸出正確等於真的理解」。
專家系統初一
Expert System
1980 年代以人工撰寫的大量 if-then 規則構成，因知識擷取瓶頸與脆弱性導致第二次 AI 寒冬。
AI 寒冬初一
AI Winter
期望落空導致投資與研究退潮的時期；常考的是 1987 年前後由專家系統失敗引發的第二次寒冬。
監督式學習初一
Supervised Learning
有標籤的學習。再依輸出分為分類（類別）與迴歸（連續數值）。
非監督式學習初一
Unsupervised Learning
無標籤，目的是探索資料中自然存在的結構（分群、降維、關聯規則、異常偵測）。
強化學習初一
Reinforcement Learning
靠「行動→環境獎懲→調整策略」學習。四要素：代理人、環境、行動、獎勵；目標是長期累積獎勵。
探索與利用權衡初一
Exploration-Exploitation
強化學習與推薦系統的核心兩難：嘗試新選項 vs. 沿用已知的好選項。
半監督式學習初一中三
Semi-supervised
少量標註＋大量未標註。常見手法為偽標籤與一致性正則化。
自監督式學習初一中三
Self-supervised
標籤從資料本身自動生成（遮字預測、對比學習），是大型語言模型能規模化的關鍵。
遷移學習初一中三
Transfer Learning
重用大資料集上預訓練的模型再微調。有效的原因是淺層學到的邊緣紋理等特徵可跨任務共用。
主動學習初一中三
Active Learning
讓模型挑出最不確定的樣本優先請人標註，把有限的標註預算花在刀口上。
弱監督中三
Weak Supervision
把專家規則寫成標註函式大規模產生雜訊標籤，再以標籤模型估計各函式可靠度後整合。
少樣本學習中三
Few-shot Learning
學習嵌入與相似度而非固定分類器；新類別只需算出原型即可分類，不必重訓。
領域自適應中三
Domain Adaptation
輸入分布改變但標籤定義不變（共變量偏移）時，讓模型適應新場域的技術。
災難性遺忘中三
Catastrophic Forgetting
只用新資料微調導致舊任務能力大幅退化。解法：重播、正則化、參數隔離。
分類 / 迴歸初一
Classification / Regression
輸出類別 vs. 輸出連續數值。判斷情境題的第二個問句。
多標籤分類初一中三
Multi-label
一個樣本可同時屬多類，各標籤獨立用 Sigmoid；與互斥的多類別（Softmax）不同。

B資料處理與特徵

資料洩漏初一中一
Data Leakage
訓練資料混入預測當下取不到的資訊。症狀：離線分數異常高、上線崩潰。
時間點正確性中一
Point-in-time Correctness
每筆樣本只能使用其預測時點之前已可取得的資料；注意「發生時間」不等於「可得時間」。
群組洩漏中一中三
Group Leakage
同一病人／使用者的多筆資料橫跨訓練與測試集，模型學到「認出這個人」。用分組切分解決。
訓練服務偏斜中一
Training-Serving Skew
離線與線上的特徵計算邏輯或資料新鮮度不一致。生產環境最常見也最難察覺的失效。
特徵儲存中一
Feature Store
「一次定義、兩處使用」：離線層供訓練、線上層供推論，共用同一份特徵定義。
標準化初一
Standardization / Z-score
減平均除標準差，使平均 0、標準差 1。適合近常態或有離群值。
正規化初一
Min-Max Normalization
壓縮到 0～1。需固定範圍時使用，對離群值敏感。
獨熱編碼初一
One-Hot Encoding
每個類別一欄 0/1。適合低基數名目尺度；高基數會維度爆炸。
順序編碼初一中三
Ordinal Encoding
依順序給整數。只能用在真的有順序的尺度，用在名目尺度會製造假的大小關係。
目標編碼中一中三
Target Encoding
以該類別的目標平均值取代。處理高基數有效，但必須折外計算並平滑否則嚴重洩漏。
四分位距法則初一
IQR Rule
超出 Q1−1.5×IQR 或 Q3+1.5×IQR 視為疑似離群；比 Z 分數更耐受偏斜分布。
缺失指示欄位初一
Missing Indicator
額外記錄「原本是否缺失」。因為「不願填寫」這件事本身可能帶有資訊。
類別不平衡初一中三
Class Imbalance
少數類極稀少導致準確率悖論。對策：換指標、類別權重、重抽樣、調閾值。
SMOTE初一中三
SMOTE
以少數類樣本間內插合成新樣本。只能在訓練折內做；對類別特徵與高維稀疏資料不適用。
資料增強初一中三
Data Augmentation
旋轉、翻轉、調亮度等變換擴增樣本多樣性。必須符合任務的不變性假設，否則等於製造錯誤標籤。
Mixup / CutMix中三
Mixup / CutMix
在樣本之間插值或貼區塊並依比例混合標籤，提供更平滑的決策邊界與更好的校準。
週期性編碼中三
Cyclical Encoding
以 sin/cos 成對把小時、月份映射到單位圓，讓 23 點與 0 點相鄰。
分箱中三
Binning
連續變數切區間。可表達非單調關係並對齊業務級距，代價是組內資訊損失。
交互特徵中三
Interaction Feature
兩特徵的組合才產生的效果。線性模型需明確建立；樹模型可自動捕捉。
多重共線性中三
Multicollinearity
變數間高度線性相關，使係數不穩定且可能反號；以變異數膨脹因子診斷。對純預測影響有限。
置換重要度中三
Permutation Importance
在驗證集上打亂某特徵看分數掉多少。比樹模型內建重要度公正（後者偏好高基數與連續特徵）。
標籤雜訊中三
Label Noise
標籤本身錯誤，直接限制模型效能上限。可用折外預測找出可疑樣本送人工複核。
標註者一致性中一
Inter-annotator Agreement
以 Kappa 係數扣除隨機一致後衡量。它隱含了模型能達到的效能天花板。
ETL / ELT初一中二
ETL / ELT
抽取、轉換、載入的資料整合流程；ELT 是先載入再於倉儲內轉換。

C訓練與最佳化

損失函數初一
Loss Function
量化預測與答案的差距，定義了模型優化的目標。選錯方向就全錯。
梯度下降初一
Gradient Descent
沿損失下降方向調整參數。新參數 = 舊參數 − 學習率 × 梯度。
學習率初一
Learning Rate
每次更新的步伐。太大震盪發散、太小收斂緩慢；最關鍵的超參數。
學習率預熱初一中三
Warmup
訓練初期由極小值逐步升高，避免被隨機初始權重的大梯度帶偏。Transformer 幾乎必用。
餘弦退火中三
Cosine Annealing
依餘弦曲線把學習率平滑降到接近零；帶重啟的版本可搭配快照集成。
回合 / 批次大小 / 迭代初一
Epoch / Batch Size / Iteration
看完全部資料一遍 / 一次更新用幾筆 / 更新了幾次。三者常被混淆。
參數 / 超參數初一
Parameter / Hyperparameter
模型自己學到的數字 vs. 訓練前由人設定的數字（學習率、樹深度、K 值）。
過擬合初一
Overfitting
訓練分數高、驗證分數低。本質是高變異：把雜訊也背起來了。
欠擬合初一
Underfitting
訓練與驗證分數都低且接近。本質是高偏差：模型太簡單。
偏差變異權衡初一
Bias-Variance Tradeoff
射箭比喻：高偏差＝穩定地射偏；高變異＝箭散一片。總誤差≈偏差²＋變異＋不可約誤差。
L1 正則化初一中三
Lasso
懲罰係數絕對值，會把部分係數推到恰好為 0，可自動選特徵；相關特徵中選誰不穩定。
L2 正則化初一中三
Ridge
懲罰係數平方，只把係數壓小不會為 0；讓相關特徵平均分攤權重，較穩定。
Elastic Net中三
Elastic Net
L1＋L2 混合，兼顧稀疏化與群組效應，適合「特徵多且高度相關」。
Dropout初一
Dropout
訓練時隨機關閉神經元，推論時全開；等同訓練指數多個子網路再集成。
提早停止初一
Early Stopping
驗證指標連續數回合不改善即停止並回復最佳權重；容忍值避免因短暫波動誤停。
交叉驗證初一中三
Cross-Validation
切 K 份輪流當驗證集取平均。分層版本處理不平衡、分組版本處理群組洩漏。
巢狀交叉驗證中三
Nested CV
外層估效能、內層選超參數，避免選參造成的樂觀偏誤。
學習曲線中三
Learning Curve
橫軸是資料量，回答「該不該蒐集更多資料」。
驗證曲線中三
Validation Curve
橫軸是超參數，回答「該用多複雜的模型」。最佳點在驗證分數高點而非訓練高點。
Bagging初一
Bagging
並行訓練多個獨立模型再投票平均，主要降低變異。代表：隨機森林。
Boosting初一
Boosting
序列訓練，後者修正前者的錯誤，主要降低偏差。代表：XGBoost、LightGBM。
Stacking中三
Stacking
以各基模型的預測當特徵訓練元模型。元模型的訓練特徵必須用折外預測否則嚴重過擬合。
Adam / AdamW中三
Adam / AdamW
自適應優化器；AdamW 把權重衰減與梯度更新解耦，修正 L2 被自適應縮放扭曲的問題。
He / Xavier 初始化中三
He / Xavier Init
依層維度縮放初始權重變異數。He 搭 ReLU、Xavier 搭 Tanh/Sigmoid。
梯度裁剪中三
Gradient Clipping
梯度範數超過門檻即等比例縮回，保持方向只限制量值；處理梯度爆炸。
混合精度訓練中三
Mixed Precision
主要運算用半精度以省記憶體並加速，關鍵部分保留單精度並搭配損失縮放避免下溢。
梯度累積中三
Gradient Accumulation
分次計算梯度累加後才更新，在小顯存下達到等效大批次。
Focal Loss中三
Focal Loss
降低易分類樣本的損失權重，使訓練訊號集中在困難樣本；極度不平衡時常用。
Huber 損失中三
Huber Loss
誤差小時像 MSE、大時像 MAE，兼顧穩健性與可訓練性。
分位數損失中三
Quantile Loss
直接預測特定分位數，適合高估與低估成本不對稱的決策（如備貨）。

D評估指標

混淆矩陣初一
Confusion Matrix
真／偽＝判斷對不對，陽／陰＝模型說了什麼。偽陰性＝漏抓、偽陽性＝誤報。
準確率初一
Accuracy
(TP+TN)÷全部。不平衡資料上會嚴重誤導（準確率悖論）。
召回率初一
Recall / Sensitivity
TP÷實際陽性。「該抓的抓到幾成」。漏抓代價高時（篩檢、詐欺）優先。
精確率初一
Precision
TP÷判為陽性。「說有就真的有的比例」。誤報代價高時（誤刪信件）優先。
F1 分數初一
F1 Score
精確率與召回率的調和平均——會被小的那邊拖住，逼模型兩邊都顧。
ROC-AUC初一
ROC-AUC
隨機抽一正一負，模型給正樣本較高分的機率。衡量排序能力，不受閾值影響。
PR-AUC初一中三
PR-AUC
極度不平衡時比 ROC-AUC 更能反映真實表現；基準線等於正樣本比例。
巨集 / 微觀平均中三
Macro / Micro Average
各類等權（揭露稀有類失效） vs. 由多數類主導（等同整體準確率）。
MAE / RMSE初一
MAE / RMSE
絕對誤差平均 vs. 平方後開根號。RMSE 遠大於 MAE 代表存在少數極大誤差。
決定係數初一
R²
模型解釋了目標多少比例的變異。可以是負的（比猜平均值還差）；比較不同特徵數要看調整後 R²。
MAPE 的陷阱中三
MAPE
分母接近零時爆炸，且不對稱懲罰（低估上限 100%、高估無上限）使模型偏向低估。
NDCG中三
NDCG
排序評估：依相關程度給增益、依名次做對數折扣，再以理想排序正規化以跨查詢比較。
mAP中三
mean Average Precision
物件偵測指標。必須說明所用的 IoU 門檻，不同門檻的數值不可直接比較。
交集比聯集中三
IoU
兩框重疊面積÷聯集面積，用於判定偵測是否命中與非極大值抑制。
Dice 係數中三
Dice Coefficient
2×交集÷兩者面積和。分割任務常用，對前景大小不敏感，適合極度像素不平衡。
校準中一中三
Calibration
輸出機率是否對應真實發生率。與區辨能力（AUC）是兩回事；以可靠度圖診斷。
二次加權 Kappa中三
Quadratic Weighted Kappa
序數目標的評估：懲罰隨偏離距離的平方成長，能區分偏一級與偏四級。
統計顯著 vs. 實務顯著中二
Statistical vs. Practical
差異不像隨機 vs. 值不值得投入。樣本極大時微小差異也會顯著。

E深度學習架構

激活函數初一
Activation Function
引入非線性。沒有它，疊幾層都等同一層線性模型。
ReLU初一
ReLU
取 max(0, x)。正區間梯度恆為 1，隱藏層的預設選擇；負區間可能造成神經元死亡。
Softmax初一
Softmax
把分數轉為加總為 1 的機率分布，用於多類別互斥的輸出層。
反向傳播初一
Backpropagation
用連鎖律由輸出往輸入逐層算出每個權重的梯度；效率來自中間結果重用。
梯度消失初一
Vanishing Gradient
連鎖律逐層相乘使梯度趨近 0，淺層學不動。解法：ReLU、殘差連接、正規化、良好初始化。
殘差連接初一中三
Residual Connection
輸出＝輸入＋F(輸入)。使學習恆等映射變容易並提供梯度捷徑，是深度能到上百層的關鍵。
退化問題中三
Degradation Problem
加深反而使訓練誤差也變高——是最佳化困難而非過擬合。
卷積神經網路初一
CNN
局部感受野＋權重共享＋平移不變性，大幅減少參數並符合影像特性。
感受野中三
Receptive Field
輸出一個位置對應的原始輸入範圍。小於物件尺寸會使大物件分割破碎。
空洞卷積中三
Dilated Convolution
在卷積核取樣點間插間隔，不降低解析度就擴大感受野，分割任務的關鍵技術。
深度可分離卷積中三
Depthwise Separable Conv
拆成逐通道空間卷積＋逐點通道混合，大幅減少參數，行動裝置架構的核心。
LSTM初一
LSTM
以遺忘／輸入／輸出三閘控制細胞狀態；更新以加法為主故能保留長距離資訊。
Transformer初一初二
Transformer
以自注意力取代循環結構，可平行運算且任意兩詞距離皆為一步。
自注意力初一初二
Self-Attention
以 Query／Key／Value 計算每個詞對其他詞的關注權重，產生融合上下文的表示。
位置編碼中三
Positional Encoding
自注意力本身對順序無感，必須額外加入位置資訊才能區分「貓追狗」與「狗追貓」。
批次正規化中三
Batch Normalization
跨批次內樣本正規化。小批次不穩、對變長序列不友善、訓練與推論行為不一致。
層正規化中三
Layer Normalization
對每個樣本跨特徵維度正規化，不依賴批次；Transformer 與循環網路的標準。
生成對抗網路初一
GAN
生成器與判別器對抗訓練。挑戰：訓練不穩、模式崩潰、缺乏客觀收斂指標。
自編碼器初一中三
Autoencoder
壓縮再重建。可用於降維、去雜訊，以及只用正常資料訓練後以重建誤差做異常偵測。
擴散模型中三
Diffusion Model
學習逐步去噪。相較 GAN 訓練穩定、多樣性佳，但推論需多步迭代。
詞嵌入初一
Word Embedding
以稠密向量表示詞，語意相近者向量相鄰；相較獨熱編碼大幅降維且保留語意。
歸納偏置中三
Inductive Bias
架構內建的資料結構假設。CNN 有局部性與平移等變性故樣本效率高；ViT 較弱故需大資料。

F生成式 AI

生成式 AI初二
Generative AI
學習資料分布並從中取樣產生新內容；鑑別式則是學習類別間的決策邊界。
自迴歸生成初二
Autoregressive
逐一預測下一個詞元，每個新詞都以前文為條件。所以前文品質決定後續品質、錯誤會累積。
詞元初二
Token
模型處理文字的最小單位，由分詞器決定。不等於字或詞，不同模型的計價差異由此而來。
子詞分詞中三
Subword Tokenization
常見詞保持完整、罕見詞拆成常見片段；兼顧詞彙表大小與未登錄詞處理。
上下文視窗初二
Context Window
單次能處理的詞元上限，包含系統提示、對話歷史、檢索內容與輸出。
無狀態初二
Stateless
API 每次呼叫獨立，所謂「記憶」是應用端把歷史一併送出——所以成本會隨輪數累積。
溫度初二
Temperature
調整輸出機率分布的平緩程度。低＝穩定一致、高＝多樣發散。
核採樣初二
Top-p / Nucleus Sampling
從累積機率達 p 的最小候選集合中採樣，動態限制候選範圍。
提示工程初二
Prompt Engineering
六要素：角色與任務、背景素材、目標受眾、輸出格式、風格限制、範例與排除條件。
零樣本 / 少樣本初二
Zero-shot / Few-shot
不給範例 vs. 給數個示範。少樣本不改變模型參數（情境學習）。
情境學習初二
In-context Learning
模型從提示中的範例推斷任務規則，效果只存在於這次呼叫的上下文。
思維鏈初二
Chain-of-Thought
要求逐步推理再給結論。適合多步驟任務；簡單任務只增加成本與延遲。
幻覺初二
Hallucination
產生流暢但錯誤的內容。成因是模型在做機率生成而非查證事實；語氣自信與正確無關。
知識截止初二
Knowledge Cutoff
參數知識停在訓練語料的時間點，之後的事件一無所知。
檢索增強生成初二中一
RAG
把知識放在可更新的外部索引，模型只負責理解與組織。可附出處、可即時更新、可控權限。
切塊初二
Chunking
文件切成可檢索的段落。太大混入雜訊、太小失去脈絡；應沿語意邊界切並加重疊。
嵌入模型初二中三
Embedding Model
把文字轉成向量供相似度檢索。查詢與文件必須用同一個模型，換模型須重建索引。
混合檢索初二
Hybrid Search
關鍵字檢索（擅長型號專有名詞）＋向量檢索（擅長換句話說）並融合結果。
重排序初二中三
Re-ranking
以交叉編碼器對少量候選精算相關性。第一階段重召回、第二階段重精準。
雙塔模型中三
Bi-encoder
分別編碼查詢與文件，文件向量可離線預計算，適合大規模即時檢索。
交叉編碼器中三
Cross-encoder
查詢與文件一起輸入深度互動，精度高但無法預計算，只用於重排少量候選。
查詢改寫初二
Query Rewriting
依對話脈絡把「那它的維修費呢」補全成可獨立檢索的完整問題。
語意快取初二
Semantic Cache
相似問題直接回既有答案。門檻過寬會誤判、快取鍵必須含權限維度。
微調初二
Fine-tuning
更新模型參數以學會特定行為模式（格式、語氣）；不適合承載頻繁變動的事實知識。
參數高效微調初二中一
PEFT / LoRA
凍結原權重，只訓練少量新增參數；訓練成本低、每任務只需數十 MB 適配權重。
指令微調初二
Instruction Tuning
以「指示→理想回覆」配對訓練，讓模型從文字接龍機器變成可用助理。
人類回饋強化學習初二
RLHF
以人類偏好排序訓練獎勵模型再調整語言模型。副作用：獎勵駭客、諂媚傾向。
知識蒸餾初二中三
Knowledge Distillation
用大模型的軟標籤（含類別間相似度的暗知識）訓練小模型。須以人工標註集驗證。
工具呼叫初二
Function / Tool Calling
模型輸出結構化呼叫請求，由應用程式實際執行並把結果回傳。
AI 代理人初二
AI Agent
接收目標後自行規劃、使用工具、反思調整。要素：規劃、工具、記憶、反思迴圈。
提示詞注入初二中一
Prompt Injection
把惡意指令藏在輸入或模型會讀取的外部內容中誘使其執行；間接注入危害更大。
越獄初二
Jailbreak
以角色扮演、假設情境等話術誘使模型繞過安全規範。
首字延遲中一
TTFT
送出請求到產出第一個詞元。受輸入長度與排隊影響；串流輸出可大幅改善感知延遲。
每字延遲中一
TPOT
之後每產出一個詞元的時間。受模型大小與記憶體頻寬影響。
連續批次中一
Continuous Batching
完成的請求立即移出、等待的立即補入，使批次維持高佔用；吞吐常可提升數倍。
鍵值快取中一
KV Cache
快取先前詞元的鍵與值避免重複計算；佔用記憶體隨序列長度與併發成長，是容量瓶頸。
提示前綴快取中一
Prompt Caching
固定的長系統提示只計算與計費一次；要求前綴完全一致且置於最前方。

GMLOps 與部署

MLOps初一中一
MLOps
把模型從實驗帶到可靠生產的工程實踐：自動化管線、版本控管、監控、再訓練、回滾。
模型註冊庫中一
Model Registry
記錄每個模型版本的訓練資料、程式碼版本、指標、核准狀態與負責人的單一事實來源。
實驗追蹤中一
Experiment Tracking
記錄所有實驗的超參數、資料版本、指標與產出；與模型註冊庫互補。
影子模式中一
Shadow Deployment
新模型接收真實流量但輸出不影響決策，只記錄比對。零風險驗證。
金絲雀發布中一
Canary Release
先切少量流量給新版本實際決策，監控後逐步放大。
藍綠部署中一
Blue-Green
維護兩套環境，驗證後一次切換流量，可快速完整回滾。
功能旗標中一
Feature Flag
讓「部署」與「發布」解耦，可秒級關閉功能而不需回滾部署。
冠軍挑戰者中一
Champion-Challenger
現行模型負責決策、挑戰者以影子模式並行，達到事前約定的勝出條件才晉升。
資料漂移初一中一
Data Drift
輸入特徵的分布改變。以 PSI、KS 檢定等監控。
概念漂移初一中一
Concept Drift
輸入與輸出之間的關係改變。與資料漂移是不同概念。
群體穩定性指標中一
PSI
比較兩期分布差異，常以 0.1／0.25 作為輕微／顯著漂移的參考門檻。
服務等級目標中一
SLO
明確可量測的服務承諾（可用率、P95 延遲、品質指標）。
錯誤預算中一
Error Budget
允許不達標的額度。99.9% 可用率≈每月 43 分鐘；用來客觀取捨速度與穩定。
冪等性中一
Idempotency
同一操作重複執行結果不變。批次重跑與代理人重試的正確性基礎。
指數退避中一
Exponential Backoff
重試間隔逐次加倍並加隨機抖動，避免所有客戶端同時重試造成雪崩。
熔斷中一
Circuit Breaker
依賴持續失敗時暫停呼叫，避免累積等待拖垮整體。
自動化偏誤中一
Automation Bias
人面對長期正確的系統會降低警覺、審核流於形式。需以風險分層與介面設計對抗。
量化中一中三
Quantization
降低權重與運算的數值精度以省記憶體並加速；需實測品質損失。
剪枝中三
Pruning
移除冗餘權重或結構；結構化剪枝較容易取得實際加速。
算子融合中三
Operator Fusion
把連續運算合併為單一核心，減少記憶體讀寫與啟動開銷，推論加速的主要來源之一。
動態批次中三
Dynamic Batching
以最大批次大小與最大等待時間兩參數，在延遲上限內盡量提高吞吐。
資料平行中一中三
Data Parallel
各卡持完整模型副本處理不同資料並同步梯度；等效批次變大需調整學習率。
邊緣運算初一中一
Edge Computing
推論放終端以取得低延遲、離線可用、省頻寬與隱私；訓練仍放雲端取得彈性算力。
聯邦式學習初一中一
Federated Learning
讓模型移動而非資料移動。隱私非自動保證，需搭配安全彙總或差分隱私。

H大數據工程

OLTP / OLAP中二
OLTP / OLAP
短小高併發讀寫（行式） vs. 大範圍掃描聚合（列式）。共用資源會互相拖垮。
資料湖 / 資料倉儲中二
Data Lake / Warehouse
讀取時定義結構（彈性） vs. 寫入時定義結構（一致）。湖倉架構試圖兼具兩者。
開放表格式中二
Delta / Iceberg / Hudi
在檔案上加中繼資料與交易日誌，提供原子寫入、快照隔離、時間旅行與結構演進。
列式儲存中二
Columnar Storage
同欄位資料連續存放。三大優勢：欄位裁剪、高壓縮率、區塊統計資訊可跳過。
小檔案問題中二
Small File Problem
每檔的固定開銷與檔案數成正比，且中繼資料查詢本身成瓶頸。以壓實與分區設計解決。
分區 / 分桶中二
Partitioning / Bucketing
低基數篩選欄位做分區裁剪 vs. 高基數欄位雜湊分桶（且同鍵分桶可免洗牌連接）。
洗牌中二
Shuffle
把相同鍵的資料跨節點集中。涉及序列化、網路傳輸與落地，分散式運算最昂貴的操作。
窄依賴 / 寬依賴中二
Narrow / Wide Dependency
不需移動資料 vs. 需要洗牌；後者是階段邊界與效能瓶頸。
資料傾斜中二
Data Skew
少數鍵佔絕大比例造成落後任務。加分區或加節點都沒用，需加鹽兩階段聚合或分離處理。
廣播連接中二
Broadcast Join
小表複製到各節點在本地連接，完全免除大表洗牌。
惰性求值中二
Lazy Evaluation
轉換只建立計畫、行動才觸發執行，讓最佳化器能綜觀全局做下推與合併。
事件時間 / 處理時間中二
Event / Processing Time
實際發生 vs. 進入系統。有延遲時差異巨大，統計「實際發生」必須用事件時間。
水位線中二
Watermark
估計「早於某時刻的資料應已到齊」，作為觸發視窗計算的依據。是延遲與完整性的取捨。
滾動 / 滑動 / 會話視窗中二
Tumbling / Sliding / Session
不重疊 / 重疊（成本＝長度÷步長） / 依活動間隔動態決定邊界。
恰好一次中二
Exactly-once
需三者齊備：來源可重播、引擎檢查點與狀態一致、輸出端冪等或交易式提交。
背壓中二
Backpressure
下游跟不上時反向讓上游放慢，避免記憶體無限累積而崩潰。
變更資料擷取中二
CDC
讀取資料庫交易日誌取得每一次變更（含刪除），對來源負擔低且延遲秒級。
星型架構中二
Star Schema
事實表＋去正規化維度表，一層連接、查詢效能與可讀性佳，資料倉儲主流。
事實表粒度中二
Grain
「一列代表什麼」。應選最細的原子粒度且全表一致，混合粒度會造成重複計算。
緩慢變動維度中二
SCD Type 2
屬性變更時新增一列並記錄生效失效日，使歷史事實關聯到當時的屬性值。
代理鍵中二
Surrogate Key
與來源系統無關的識別碼。可隔離來源變更、支援 SCD Type 2、處理併購重號。
實體解析中二
Entity Resolution
判定不同記錄是否為同一實體。流程：標準化→分塊→比對評分→雙門檻決策→黃金紀錄。
語意層中二
Semantic Layer
集中維護指標定義供所有工具引用，終結「三個部門三個數字」。
資料契約中一中二
Data Contract
明訂結構、語意、值域、品質保證與變更政策，並以自動檢核在寫入時驗證。
資料血緣中一中二
Data Lineage
資料的流動與依賴關係圖。用於變更影響分析、根因追溯與個資流向盤點。
資料網格中二
Data Mesh
領域自治＋資料即產品＋自助平台＋聯邦式治理；是組織轉型而非單純技術方案。
分區容錯下的取捨中二
CAP
網路分區時只能在一致性與可用性間取捨。金流庫存傾向強一致、社群計數可最終一致。
分片鍵中二
Shard Key
需分布均勻、基數足夠、支援主要查詢、避免單調遞增（會造成寫入熱點）。
涵蓋索引中二
Covering Index
索引本身已包含查詢所需欄位，可免回表。複合索引順序：等值條件在前、範圍條件在後。
謂詞下推中二
Predicate Pushdown
把篩選條件推到最接近資料來源處執行，依檔案統計跳過整個區塊。
物化視圖中二
Materialized View
預先算好並保存結果。比率類指標應預存分子分母而非預存比率。
基數估計中二
HyperLogLog
以極小記憶體估計不重複計數且可合併，適合分散式與即時儀表板；結果是估計值。

I統計與分析

選擇偏誤中二
Selection Bias
樣本取得方式使其不具母體代表性。樣本量再大也無法修正。
存活者偏誤中二
Survivorship Bias
只分析仍存在的樣本（只看現有客戶而忽略已流失者），系統性高估表現。
辛普森悖論中二
Simpson's Paradox
各分組都成立的關係在合併後逆轉，成因是各組的組成比例不同。
混淆變數中二
Confounder
同時影響處理與結果的變數，會製造虛假的相關。
A／B 測試中一中二
A/B Test
隨機分流比較。五要素：隨機分流、事前指定主要指標、樣本量、統計顯著、只改一個變因。
護欄指標中一中二
Guardrail Metric
監控優化主要指標時可能被犧牲的面向（退貨率、客訴、延遲）。
新奇效應中一中二
Novelty Effect
使用者對新事物短期好奇而提高互動，隨時間衰減；需延長觀察期。
多重比較中一中二
Multiple Comparisons
同時檢定多個指標會大幅提高偽陽性。12 個指標至少一個偶然顯著的機率約 46%。
檢定力中二
Statistical Power
真的有效果時能偵測到的機率（常設 0.8）。不顯著可能只是檢定力不足。
信賴區間中二
Confidence Interval
涵蓋 0 就不能宣稱有效果；區間寬度反映估計的精確度。
增益模型中二中三
Uplift Modeling
估計個體處理效果，找出「說服型」客群。傳統預測模型排前面的常是必然型（白花錢）。
傾向分數配對中二
Propensity Score Matching
以特徵相近者配對比較，平衡可觀測的混淆變數；無法處理未觀測的差異。
差異中之差異中二
Difference-in-Differences
前後期×受影響與否的雙重比較，消除固定群體差異與共同時間趨勢。
存活分析中二
Survival Analysis
處理右設限（尚未發生事件）資料。Kaplan-Meier 估存活曲線、Cox 模型估各因素風險比。
世代分析中二
Cohort Analysis
依註冊月份等分組追蹤各期表現，可揭露「整體成長只是靠大量獲客掩蓋流失」。
顧客終身價值中二
CLV / LTV
留存曲線×各期貢獻毛利並折現。不可用歷史累計消費平均代替（存活者偏誤）。
歸因模型中二
Attribution Model
最後點擊高估末端管道、首次點擊相反。真正的增量需以實驗量測。
支援度 / 信賴度 / 提升度初一中二
Support / Confidence / Lift
涵蓋範圍 / 規則可靠度 / 排除「B 本身就熱銷」的假象；Lift>1 為正相關。
手肘法初一
Elbow Method
找 K 與群內平方和曲線的轉折點。不能選誤差最小的 K（K＝樣本數時誤差為 0）。
輪廓係數初一
Silhouette Score
同時衡量群內緊密度與群間分離度，值介於 −1 到 1。
北極星指標中二
North Star Metric
代表產品核心價值且與長期營收有因果關聯的少數指標。
指標錯位中二
Metric Misalignment
短期代理指標（點擊率）與真正的價值不等價，優化它會誘發誘餌式內容。

J倫理、法規與治理

歷史偏誤初一
Historical Bias
資料忠實記錄了過去本身就不公平的決策，模型學習後把不公平自動化並放大。
代理變數初一中三
Proxy Variable
與敏感屬性高度相關的其他特徵。刪除性別欄位不等於沒有歧視——超高頻考點。
統計均等初一中三
Demographic Parity
各群體的正向決策比率相同（如錄取率一致）。
機會均等初一中三
Equal Opportunity
各群體中「實際合格者被正確錄取」的比率相同（真陽率一致）。
公平性不可兼得初一中三
Impossibility Result
基礎發生率不同時，多種公平性定義數學上無法同時滿足，只能依情境取捨並記錄理由。
可解釋 AI初一中一
XAI
全域解釋（模型整體行為） vs. 局部解釋（單筆預測成因）。
SHAP初一中三
SHAP
以 Shapley 值分配各特徵貢獻。限制：相關特徵貢獻被分攤、反映關聯而非因果。
LIME初一
LIME
在該樣本附近用簡單線性模型局部近似，產生個案層級的解釋。
部分依賴圖中三
PDP
特徵相關時會產生現實不存在的組合而失真；此時應改用累積局部效應圖（ALE）。
反事實解釋中一中三
Counterfactual
「要改什麼、改多少結果才會不同」。建議須可行、不得涉及不可改變或受保護的屬性。
捷徑學習中三
Shortcut Learning
學到有效但不具泛化性的表面線索（醫院標記、設備紋理）。隨機切分的測試集無法暴露。
對抗樣本初一中一
Adversarial Example
人眼難察覺的微小擾動使模型高信心誤判。防禦：對抗訓練＋系統層多感測器融合。
資料投毒初一中一
Data Poisoning
把惡意樣本混入訓練資料。後門攻擊只在特定觸發器出現時發作，極難被例行測試發現。
深度偽造初一
Deepfake
合成逼真影音。防範重點是不要把身分驗證建立在可被合成的訊號上。
再識別風險初一中二
Re-identification
準識別欄位（生日、性別、郵遞區號）組合起來即可還原身分。刪姓名≠去識別化。
k-匿名初一中二
k-Anonymity
任一組準識別欄位的組合至少對應 k 筆記錄，使個體無法被單獨指認。
差分隱私初一中二
Differential Privacy
加入校準過的雜訊，保證任一個體是否被納入對輸出影響極小；隱私預算越小保護越強但效用越低。
加密抹除中二
Crypto-shredding
備份等不可變儲存中，以銷毀加密金鑰的方式達成實質刪除。
個人資料保護法初二中一
PDPA（台灣）
目的特定、告知義務、當事人權利、安全維護、委外監督；國際傳輸主管機關得限制。
GDPR 第 22 條初一初二
GDPR Art.22
對重大影響的全自動化決策設限；當事人有權要求人工介入、表達意見、提出異議。
歐盟人工智慧法初一中一
EU AI Act
風險分級。就業、授信、教育、司法多屬高風險；具域外效力。
資料保護影響評估初二中一
DPIA
高風險處理前的系統性評估；最關鍵的是必要性與比例原則的檢視。
營業秘密的保密措施初二
Trade Secret
保護要件之一是「已採取合理保密措施」——把未公開技術輸入外部服務可能不符此要件。
模型卡初一中一
Model Card
隨模型發布的透明度文件：用途、不建議用途、資料概況、分群體表現、限制與聯絡方式。
AI 風險登錄中一
AI Risk Inventory
所有 AI 應用的清冊並依風險分級，據以決定驗證、審查與監控的強度。
影子 AI初二
Shadow AI
員工私下使用未核准工具。根因是需求未被滿足；單純封鎖反而失去可視性。
