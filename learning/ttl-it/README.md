# 🍷 台灣菸酒招考從業職員 資訊管理 備考全攻略系統

> **TTL IT Exam Prep Portal**  
> 專為報考「臺灣菸酒股份有限公司（TTL）從業職員甄試 — 資訊管理類組」考生打造之全方位高分通關學習平台。  
> 採用**暖色系日式簡約風（和紙風格）**設計，全站英文均提供**標準真人語音朗讀（Web Speech API）**與**精準繁體中文翻譯**。

---

## 📌 平台特色與核心亮點

1. **全站英文發音與繁中翻譯（Speech & Translation）**
   - 包含單字、協定縮寫全稱、文法例句、題幹與選項，點擊 `🔊` 即可立即聆聽標準真人發音。
   - 搭載**全域劃詞浮動朗讀泡泡**：在頁面上選取任何英文單字或句子，即自動浮現「🔊 朗讀發音」快捷按鈕。
   - 提供音節分割、IPA/KK 音標標註與上下文精準繁中翻譯。

2. **暖色系日式簡約設計系統（Warm Japanese Minimalist Design）**
   - 和紙質樸底色（`#FDFBF7`）、沉穩墨黑（`#1F1A17`）、品牌琥珀金（`#B87818`）、朱紅重音（`#C2410C`）與常盤綠（`#4A7C59`）。
   - 採用 Google Fonts：Noto Serif TC、Cormorant Garamond、Noto Sans TC 與 JetBrains Mono。

3. **完整涵蓋共同科目與專業科目（100% 筆試配分覆蓋）**
   - **共同科目（佔筆試 10%）**：
     - 國文：論文寫作（50%）—— 獨家「起承轉合」四段架構法、6 篇台酒專屬高分範文、公營事業金句庫。
     - 英文：選擇測驗（50%）—— 30 組高頻職場與科技單字、十大核心文法公式、即時測驗。
   - **專業科目（佔筆試 90%，致勝關鍵）**：
     - 計算機概論（50%）—— CPU管線化、作業系統行程與死結、網路OSI/TCP/IP與子網切割、資安零信任、軟體工程與AI。
     - 資料庫管理及應用（50%）—— ANSI/SPARC 三層架構、ERD轉關聯表、1NF~BCNF正規化數理推導、SQL複雜查詢、交易ACID與2PL並行鎖定。

4. **150+ 專業術語速查發音庫（Interactive Glossary）**
   - 涵蓋硬體架構、作業系統、網路通訊、資安密碼、資料庫、軟體工程雲端AI及台酒職場英文。
   - 支援即時關鍵字模糊搜尋與分類標籤一鍵過濾。

5. **實戰互動題庫與申論範本（Exam Question Bank）**
   - 英文選擇題具備**即選即評**機制（綠色正確/紅色錯誤提示並自動展開繁中詳解）。
   - 專業申論與計算題提供折疊式「滿分擬答示範」，包含完整數學公式與步驟拆解。

## 🚀 快速啟動與預覽

### 方法一：使用批次檔一鍵啟動（推薦）
直接雙擊執行目錄下的：
```bash
啟動.bat
```
系統會自動在終端機啟動 Python HTTP 伺服器並以預設瀏覽器開啟 `http://127.0.0.1:7025`。

### 方法二：透過指令列啟動
```powershell
cd c:\AI\tom-projects\learning\ttl-it
python -m http.server 7025
```
接著在瀏覽器中開啟：`http://127.0.0.1:7025`
