第 6 章　資料結構與演算法

6-1　線性資料結構

結構特性操作應用
陣列 Array連續記憶體，索引存取存取 O(1)、插刪 O(n)查表、影像像素
鏈結串列 Linked List不連續，靠指標相連存取 O(n)、已知位置插刪 O(1)動態資料
堆疊 Stack後進先出 LIFOpush／pop 皆 O(1)函式呼叫、Undo、括號配對、運算式求值、DFS
佇列 Queue先進先出 FIFOenqueue／dequeue O(1)列印排程、CPU 排程、BFS
雙向佇列 Deque兩端皆可進出O(1)瀏覽器歷史
優先佇列依優先權出列O(log n)作業排程；以 Heap 實作
🧒 堆疊 vs 佇列，一秒分清

堆疊 = 洗好疊起來的盤子：只能拿最上面那個，最後放的最先拿。
→ 瀏覽器「上一頁」：逛了 A→B→C，按上一頁回到 B。

佇列 = 排隊買飲料：先來的先買到。
→ 印表機工作：先送出的先印。

環狀佇列公式（常考計算）

入列：rear = (rear + 1) % MAX　出列：front = (front + 1) % MAX
元素個數 = (rear − front + MAX) % MAX
空：front == rear　滿（犧牲一格）：(rear + 1) % MAX == front

運算式表示法（常考）

表示法A + B × C特性
中序 InfixA + B × C人類習慣，需括號與優先權
前序 Prefix+ A × B C運算子在前
後序 PostfixA B C × +電腦最好處理，不需括號
轉換技巧：依優先權加上完整括號 → 運算子移到右括號位置＝後序、移到左括號位置＝前序 → 去掉括號。

後序求值：遇運算元 push；遇運算子 pop 兩個（先 pop 的是右運算元）運算後 push 回去。
注意：8 2 / 是 8÷2 不是 2÷8——減法與除法順序不可顛倒。

6-2　樹

名詞定義
二元樹每節點最多 2 個子節點，且區分左右
完整二元樹除最後一層外皆填滿，最後一層靠左排列
二元搜尋樹 BST左 < 根 < 右；中序走訪＝由小到大排序
平衡樹（AVL）任一節點左右高度差 ≤ 1，保證 O(log n)
堆積 Heap完整二元樹且父子有大小關係；不是 BST，兄弟間無順序
📐 重要性質（常考計算） ‧ 第 i 層最多 2^(i−1) 個節點（根為第 1 層）
‧ 高度 h 最多 2^h − 1 個節點
‧ n 個節點的最小高度 = ⌈log₂(n+1)⌉
‧ n₀ = n₂ + 1（樹葉數 = 分支度 2 的節點數 + 1）

陣列表示（根從 1 起）：左子 = 2i、右子 = 2i+1、父 = ⌊i/2⌋
走訪順序用途
前序根 → 左 → 右複製樹、輸出前序式
中序左 → 根 → 右BST 中序 = 排序
後序左 → 右 → 根刪除樹、計算運算式
層序由上而下、由左而右用佇列實作（BFS）

6-3　演算法複雜度（必考）

成長速度：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
複雜度典型演算法
O(1)陣列索引存取、雜湊查詢（平均）
O(log n)二分搜尋、平衡樹操作
O(n)線性搜尋、走訪串列
O(n log n)Merge / Heap / Quick Sort（平均）
O(n²)Bubble / Selection / Insertion Sort
O(2ⁿ)費氏數列樸素遞迴、子集合列舉
💡 判讀迴圈複雜度的技巧 看迴圈變數怎麼變化，不要看有幾層：
i++ → 線性 O(n)｜i *= 2 或 i /= 2 → 對數 O(log n)

for(i=1;i<=n;i++) for(j=1;j<=n;j*=2) → n × log n = O(n log n)，不是 O(n²)。

6-4　排序演算法（必考比較）

演算法最佳平均最壞空間穩定
氣泡 BubbleO(n)*O(n²)O(n²)O(1)✅
選擇 SelectionO(n²)O(n²)O(n²)O(1)❌
插入 InsertionO(n)O(n²)O(n²)O(1)✅
快速 QuickO(n log n)O(n log n)O(n²)O(log n)❌
合併 MergeO(n log n)O(n log n)O(n log n)O(n)✅
堆積 HeapO(n log n)O(n log n)O(n log n)O(1)❌
計數 CountingO(n+k)O(n+k)O(n+k)O(k)✅
基數 RadixO(d·n)O(d·n)O(d·n)O(n+k)✅
💡 三個必背重點 1. 穩定：泡插合、計基桶（氣泡、插入、合併、計數、基數、桶子）
2. 不穩定：選快堆謝（選擇、快速、堆積、謝耳）
3. Quick Sort 在「已排序資料」上最慢（O(n²)），而 Insertion Sort 在已排序資料上最快（O(n)）——這個反直覺的對比幾乎年年考。

* 氣泡排序需加入「本回無交換即提早結束」的改良才有 O(n) 最佳情況。

穩定排序＝鍵值相同的元素，排序後相對順序不變。實務價值：多欄位排序時（先依年資排、再依部門排），需用穩定排序才不會破壞前一次的結果。

6-5　搜尋與雜湊

方法前提複雜度
線性搜尋無O(n)
二分搜尋必須已排序O(log n)
雜湊搜尋建立雜湊表平均 O(1)、最壞 O(n)

雜湊碰撞處理：開放定址（線性探測、二次探測、雙重雜湊）／鏈結法（每格掛一條串列）。
負載因子 α = n/m，開放定址須 < 1，實務上超過 0.75 就應擴充並重新雜湊。

二分搜尋比較次數：1024 筆最壞需 11 次（不是 10 次）——log₂1024 = 10 是「砍半次數」，剩最後 1 筆還要再比一次。

第 8 章　資料庫

8-1　基本概念與鍵值

術語俗稱
關聯 Relation資料表 Table
值組 Tuple列 Row／記錄
屬性 Attribute欄 Column／欄位
鍵值定義
超鍵 Super Key能唯一識別的屬性集合（可含多餘屬性）
候選鍵最小的超鍵

8-2　正規化（常考判斷）

階段要求判斷捷徑
1NF所有值皆為單元值，無重複群組看到「電話：A/B/C」就違反
2NF1NF ＋ 無部分相依主鍵為單一屬性 → 自動符合
3NF2NF ＋ 無遞移相依找 X→Y→Z 的鏈（Y 非鍵）
BCNF每個 FD 的決定因素都是超鍵比 3NF 嚴格

正規化消除三種異常：新增異常（想加資料卻加不進去）、刪除異常（刪一筆連帶失去其他資訊）、修改異常（同資料存多份，改一處造成不一致）。

8-3　SQL 基礎（常考語法）

類別指令
DDL 定義CREATE、ALTER、DROP、TRUNCATE
DML 操作SELECT、INSERT、UPDATE、DELETE
DCL 控制GRANT、REVOKE
TCL 交易COMMIT、ROLLBACK
SELECT 部門, COUNT(*) AS 人數, AVG(薪資) AS 平均薪
FROM 員工
WHERE 到職日 < '2024-01-01'    -- 過濾「列」
GROUP BY 部門
HAVING COUNT(*) >= 5          -- 過濾「組」
ORDER BY 平均薪 DESC;
📐 執行順序（推論出所有常考陷阱） FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

推論 1：WHERE 不能用聚合函數（那時還沒分組）→ 要用 HAVING
推論 2：WHERE 不能用 SELECT 的別名；但 ORDER BY 可以（它在 SELECT 之後）
指令類別可否 ROLLBACK保留結構
DELETEDML可以✅
TRUNCATEDDL通常不可✅
DROPDDL通常不可❌
COUNT(*) 含 NULL 的列；COUNT(欄位) 只數非 NULL。
AVG 的分母不含 NULL——5 筆資料有 2 筆 NULL，AVG 是除以 3 不是 5。

8-4　交易與 JOIN

ACID意義
原子性 Atomicity全部成功或全部失敗
一致性 Consistency前後皆滿足完整性限制
隔離性 Isolation並行互不干擾
持久性 Durability提交後不遺失
JOIN 類型回傳
INNER JOIN只有兩邊都符合的列
LEFT JOIN左表全部＋右表符合者（無對應處為 NULL）
RIGHT JOIN右表全部＋左表符合者
FULL JOIN兩邊全部
CROSS JOIN笛卡兒積（m × n 列）

索引：加速查詢，但增加寫入成本與儲存空間。資料庫索引多採 B+ 樹（樹矮、範圍查詢快）。

第 10 章　資訊安全（高頻）

10-1　資安三大目標與加密

目標意義防護
機密性 C只有授權者能看加密、存取控制
完整性 I未被竄改雜湊、數位簽章
可用性 A需要時能用備份、備援、防 DDoS
項目對稱式非對稱式
金鑰加解密同一把公鑰／私鑰成對
速度快慢
金鑰配送困難容易
演算法AES、DES、3DESRSA、ECC、DH
📐 三個必背口訣 ① 要保密 → 用「對方的公鑰」加密（只有對方私鑰能解）
② 要簽名 → 用「自己的私鑰」簽章（大家用你的公鑰驗證）
③ HTTPS 是混合加密：非對稱式交換金鑰 → 對稱式傳大量資料
技術提供的保障可否還原
加密機密性✅ 有金鑰可還原
雜湊（SHA-256）完整性❌ 單向
HMAC完整性＋來源鑑別❌
數位簽章完整性＋鑑別性＋不可否認性❌
不可否認性只有數位簽章能達成（HMAC 因雙方共用金鑰，無法歸責）。
MD5 與 SHA-1 已不安全，現行標準是 SHA-256。
密碼儲存要用 bcrypt／Argon2 ＋ 隨機鹽（Salt），不可用 AES 加密（可還原）或 MD5（太快）。

蠕蟲 Worm自我複製、自動傳播，不需人操作
木馬 Trojan偽裝成正常軟體
勒索軟體加密檔案索取贖金
間諜／鍵盤側錄竊取資料與帳密
Rootkit藏於系統深層，極難偵測
殭屍網路 Botnet受控主機群，用於 DDoS
⚠️ 勒索軟體防護的關鍵 備份必須有「離線」或「不可變」副本——若備份一直連在網路上，會被一起加密。
3-2-1 原則：3 份副本、2 種媒體、1 份異地。
另注意：RAID 不是備份，它防硬碟故障，不防誤刪與加密。

10-3　防護設備與驗證

設備功能
防火牆依規則過濾流量；原則預設拒絕，只開放必要服務
IDS入侵偵測——只告警不阻擋（旁接）
IPS入侵防禦——主動阻擋（串接）
WAF網頁應用防火牆，擋 SQLi、XSS
DMZ放置對外服務的中間地帶；資料庫絕不可放 DMZ
VPN加密通道連回內網；應搭配 MFA
📐 多因子驗證（MFA） 三類因子：你知道的（密碼）、你擁有的（手機 OTP、晶片卡）、你本身的（指紋、臉部）

MFA 必須是不同類別的組合。「密碼 + 安全提問」不算 MFA（兩者都是「你知道的」）——這是常考陷阱。

第 12 章　考前速記表

五大送分區（合計約 15 題／30 分，務必零失誤）

主題速記重點
進位轉換二↔十六每 4 位一組、二↔八每 3 位一組；權重減法法最快
邏輯閘AND 都 1 才 1｜OR 有 1 就 1｜XOR 不一樣才 1；笛摩根「斷線變號」
Big-O1 < log n < n < n log n < n² < 2ⁿ；i*=2 是 log n
埠號22 SSH｜25 SMTP｜53 DNS｜80 HTTP｜443 HTTPS｜3389 RDP
OSI 分層應表會傳網資實；交換器 L2、路由器 L3

最容易被考倒的 20 個觀念

  1. 8 位元 2 的補數範圍是 −128～+127（負數多一個）。
  2. 2 的補數只有一個零，1 的補數與帶符號大小有兩個。
  3. 浮點數有誤差，金額不可用浮點數。
  4. b 是 bit、B 是 Byte；100 Mbps 傳 100 MB 要約 8 秒。
  5. '0'=48、'A'=65、'a'=97；大寫轉小寫 +32。
  6. XOR：A⊕A=0、A⊕0=A；做兩次會還原。
  7. NAND 與 NOR 是萬用閘。
  8. 管線化提升「吞吐量」，不縮短單一指令時間。
  9. SRAM 用於 Cache、DRAM 用於主記憶體（需 Refresh）。
  10. RAID 5 最少 3 顆、可壞 1 顆；RAID 6 可壞 2 顆。
  11. RAID 不是備份（防不了誤刪與勒索軟體）。
  12. 行程是資源配置單位、執行緒是 CPU 排程單位。
  13. 等待狀態不能直接回到執行狀態，要先回就緒。
  14. SJF 平均等待時間最短，但可能造成飢餓。
  15. 死結四條件：互斥、持有並等待、不可搶奪、循環等待。
  16. Belady 異常只發生在 FIFO（增加頁框反而缺頁更多）。
  17. Quick Sort 在已排序資料上最慢，Insertion Sort 最快。
  18. 穩定排序：泡插合、計基桶。
  19. WHERE 不能用聚合函數（要用 HAVING）；COUNT(*) 含 NULL。
  20. MFA 必須是不同類別的因子；隱藏 SSID 與 MAC 過濾不是有效安全措施。
