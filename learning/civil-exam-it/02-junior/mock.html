二進位 11010110₍₂₎ 的十進位值為？
💡 第 1 題詳解　正解 (C)128+64+16+4+2 = 214
2
十進位 175 轉為十六進位為？
💡 第 2 題詳解　正解 (B)175 = 1010 1111₍₂₎ → AF；驗算 10×16+15 = 175
3
十六進位 3C7₍₁₆₎ 轉為二進位為？
💡 第 3 題詳解　正解 (A)3=0011、C=1100、7=0111（每位展開 4 位元）
4
以 8 位元 2 的補數表示 −35，其二進位為？
💡 第 4 題詳解　正解 (B)+35 = 00100011 → 反轉 11011100 → +1 = 11011101（A 是 1 的補數）
5
8 位元 2 的補數可表示的整數範圍為？
💡 第 5 題詳解　正解 (B)−2ⁿ⁻¹ ~ 2ⁿ⁻¹−1；只有一個零故負數多一個
6
二進位 10110₍₂₎ 右移 2 位後的十進位值為？
💡 第 6 題詳解　正解 (B)10110₍₂₎ = 22；右移 2 位 = ÷4 = 5（截斷小數）
7
IEEE 754 雙精度浮點數（double）的指數與尾數位元數為？
💡 第 7 題詳解　正解 (B)double：1+11+52 = 64；float 為 1+8+23 = 32
8
字元 'd' 的 ASCII 值為？（'a' = 97）
💡 第 8 題詳解　正解 (B)'a'=97 → 'd' 為第 4 個字母 → 97+3 = 100
9
關於 UTF-8，下列敘述何者正確？
💡 第 9 題詳解　正解 (B)UTF-8 為 1～4 bytes 可變長度且與 ASCII 相容；Unicode 才是字元集
10
在 200 Mbps 網路下傳輸 100 MB 檔案，理論上約需？
💡 第 10 題詳解　正解 (C)100 MB = 800 Mb；800÷200 = 4 秒（b 與 B 差 8 倍）
11
當 A=0、B=1 時，下列哪個閘的輸出為 0？
💡 第 11 題詳解　正解 (D)AND 需兩者皆 1；OR/XOR/NAND 在 0,1 時皆為 1
12
依笛摩根定律，(A · B)' 等於？
💡 第 12 題詳解　正解 (B)「斷線、變號」：· 變 +
13
化簡 A · (A + B) 的結果為？
💡 第 13 題詳解　正解 (A)吸收律 A·(A+B) = A
14
若 A ⊕ B = 1，則下列何者必成立？
💡 第 14 題詳解　正解 (B)XOR：不一樣才是 1
15
具有 4 條輸入線的解碼器（Decoder），最多有幾條輸出線？
💡 第 15 題詳解　正解 (C)解碼器 n 進 → 2ⁿ 出 = 2⁴ = 16
16
下列何者屬於循序邏輯電路？
💡 第 16 題詳解　正解 (D)正反器有記憶性；其餘為組合邏輯
17
存放「目前正在執行之指令」的暫存器為？
💡 第 17 題詳解　正解 (B)IR 存「現在這個」；PC 存「下一個」的位址
18
某程式有 4×10⁹ 個指令，CPI = 1.5，時脈 3 GHz，執行時間為？
💡 第 18 題詳解　正解 (B)(4×10⁹ × 1.5) ÷ 3×10⁹ = 2 秒
19
Cache 命中率 90%、Cache 存取 5 ns、主記憶體 100 ns，平均存取時間為？
💡 第 19 題詳解　正解 (B)0.9×5 + 0.1×100 = 4.5 + 10 = 14.5 ns
20
下列何者為非揮發性記憶體？
💡 第 20 題詳解　正解 (C)SRAM、DRAM 皆為揮發性；Flash 為非揮發性
21
使用 6 顆 2TB 硬碟建立 RAID 6，可用容量為？
💡 第 21 題詳解　正解 (C)RAID 6 = (n−2)×容量 = (6−2)×2TB = 8 TB
22
下列關於 RAID 的敘述何者正確？
💡 第 22 題詳解　正解 (C)RAID 0 無容錯、RAID 1 為 50%、RAID 不是備份
23
馮紐曼架構的瓶頸主要來自？
💡 第 23 題詳解　正解 (B)指令與資料共用一條匯流排＝馮紐曼瓶頸
24
下列 I/O 方式中，CPU 負擔最低的是？
💡 第 24 題詳解　正解 (C)DMA 由控制器搬移，CPU 只在頭尾介入
25
下列何者為執行緒私有（不與同行程其他執行緒共享）？
💡 第 25 題詳解　正解 (C)執行緒私有：堆疊、暫存器、PC；其餘皆共享
26
行程處於「執行中」需等待 I/O 時，會轉為何種狀態？
💡 第 26 題詳解　正解 (B)執行 → 等待；I/O 完成後回就緒（不能直接回執行）
27
三個行程同時抵達，執行時間 8、2、5，採 SJF 之平均等待時間為？
💡 第 27 題詳解　正解 (B)SJF 順序 2→5→8；等待 0、2、7 → 平均 3
28
最適合分時系統以確保回應時間的排程演算法為？
💡 第 28 題詳解　正解 (C)RR 以時間量子輪流，回應時間佳
29
下列何者不是死結的必要條件？
💡 第 29 題詳解　正解 (B)四條件為互斥、持有並等待、不可搶奪、循環等待
30
分段（Segmentation）主要產生何種碎片？
💡 第 30 題詳解　正解 (B)固定大小→內部碎片；可變大小→外部碎片
31
3 個頁框，存取序列 2,3,2,1,5,2,4,5,3，採 FIFO 之缺頁次數為？
💡 第 31 題詳解　正解 (C)逐格追蹤：2,3,1,5,2,4,3 缺頁 → 7 次（須畫表）
32
增加頁框數量反而使缺頁次數增加，此現象稱為？
💡 第 32 題詳解　正解 (B)Belady 異常只發生於 FIFO
33
chmod 750 file 代表的權限為？
💡 第 33 題詳解　正解 (A)7=rwx、5=r-x、0=---
34
下列何者不是作業系統的功能？
💡 第 34 題詳解　正解 (C)那是編譯器的工作
35
後序運算式 4 5 + 2 * 3 - 的值為？
💡 第 35 題詳解　正解 (B)(4+5)=9 → 9×2=18 → 18−3 = 15
36
中序 (A + B) * (C - D) 轉後序為？
💡 第 36 題詳解　正解 (A)((A B)+ (C D)-)* → A B + C D − *
37
大小 10 的環狀佇列，front = 8、rear = 3，元素個數為？
💡 第 37 題詳解　正解 (B)(3−8+10)%10 = 5
38
高度為 6 的二元樹（根為第 1 層），最多節點數為？
💡 第 38 題詳解　正解 (B)2⁶−1 = 63（忘記減 1 會選 64）
39
某二元樹有 20 個分支度為 2 的節點，樹葉節點數為？
💡 第 39 題詳解　正解 (C)n₀ = n₂+1 = 21
40
對 BST 做何種走訪可得由小到大的排序？
💡 第 40 題詳解　正解 (B)BST 中序＝由小到大
41
下列程式片段的時間複雜度為？
for(i=n;i>0;i/=2) for(j=0;j<n;j++) c++;
💡 第 41 題詳解　正解 (B)外層 i/=2 → log n 次；內層 n 次 → O(n log n)
42
下列排序中，何者為穩定排序且最壞情況為 O(n log n)？
💡 第 42 題詳解　正解 (B)合併排序：穩定且最壞 O(n log n)（代價為 O(n) 空間）
43
對 100 萬筆 0～999 的整數排序，最有效率的方法為？
💡 第 43 題詳解　正解 (C)值域 k=1000 遠小於 n → 計數排序 O(n+k)
44
雜湊表使用線性探測的主要缺點為？
💡 第 44 題詳解　正解 (B)線性探測會形成連續佔用區塊＝主要聚集
45
下列關於主鍵之敘述何者錯誤？
💡 第 45 題詳解　正解 (D)一表只能有一個主鍵（但可為複合主鍵）
46
關聯 R(學號, 課號, 學生姓名, 成績)，主鍵為 (學號, 課號)，且 學號→學生姓名。此關聯違反？
💡 第 46 題詳解　正解 (B)學生姓名只依賴主鍵的一部分＝部分相依 → 違反 2NF
47
SQL 中要過濾「分組後」的結果，應使用？
💡 第 47 題詳解　正解 (B)WHERE 過濾「列」、HAVING 過濾「組」
48
IP 位址 172.18.9.200/27 的網路位址為？
💡 第 48 題詳解　正解 (A)/27 → 區塊 32 → 段界 …160/192/224；200 落在 192~223
49
下列協定與埠號對應何者錯誤？
💡 第 49 題詳解　正解 (D)SSH 為 22；23 是 Telnet
50
機關將自建機房的虛擬機移至雲端業者提供的虛擬主機服務，屬於？
💡 第 50 題詳解　正解 (A)取得虛擬機等基礎運算資源＝IaaS

📊 (二) 為何要由大到小排序
理由說明
網路位址須對齊區塊邊界/26 的網路位址必須是 64 的倍數（0、64、128、192）
若先配小的例如先給路由器 .0/30，則下一個 /26 無法從 .0 起，只能從 .64 開始 → 浪費或無法容納
由大到小則自然對齊大區塊先占，剩餘空間仍能容納所有小區塊
📊 (三) 伺服器區隔離加強
措施說明
獨立 VLAN與使用者網段分離，VLAN 間流量經 L3 設備並套用 ACL
僅開放必要服務埠如僅允許辦公網段連 443；資料庫埠不對使用者網段開放
管理埠限管理網段SSH 22／RDP 3389 僅允許管理端或跳板機連入
對外服務另置 DMZ資料庫絕不可置於 DMZ
雙向管控與日誌防火牆預設拒絕、管制出向流量、日誌集中至 SIEM

📝 (二) GCD 與 LCM 
// 最大公因數（輾轉相除法）
int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

// 最小公倍數：先除再乘，避免溢位
int lcm(int a, int b) {
    return a / gcd(a, b) * b;
}

驗算：gcd(12, 18)
a=12,b=18 → t=12, a=18, b=12 → t=6, a=12, b=6 → t=0, a=6, b=0 → 回傳 6 ✔
lcm(12,18) = 12/6×18 = 36 ✔

加分點：說明「先除再乘」可避免 a×b 溢位。

思路：像整理撲克牌——把第 i 張牌插入前面已排好的部分。比 key 大的元素往後挪，再放入 key。

int i, j, key;

for (i = 1; i < n; i++) {          // 從第 2 個元素開始
    key = a[i];                    // 待插入的值
    j = i - 1;
    while (j >= 0 && a[j] > key) {  // 比 key 大的往後挪
        a[j + 1] = a[j];
        j--;
    }
    a[j + 1] = key;                // 插入正確位置
}

// 基本版：O(n)
long long power(int x, int n) {
    if (n == 0) return 1;        // 終止條件（任何數的 0 次方為 1）
    return x * power(x, n - 1);   // 遞迴關係
}

// 加分版：快速冪 O(log n)
long long fastPower(int x, int n) {
    if (n == 0) return 1;
    long long half = fastPower(x, n / 2);
    if (n % 2 == 0) return half * half;        // n 為偶數
    else            return half * half * x;    // n 為奇數
}

驗算（2⁵）：
基本版：2×2×2×2×2×1 = 32，遞迴 5 層

快速冪原理：x^n = (x^(n/2))²，每次把指數砍半 → O(log n)。寫出這個是明顯加分。

// 基本版
int isPalindrome(char s[]) {
    int len = 0;
    while (s[len] != '\0') len++;      // 計算長度

    int i;
    for (i = 0; i < len / 2; i++) {      // 只需比較一半
        if (s[i] != s[len - 1 - i])      // 注意是 len-1-i
            return 0;
    }
    return 1;
}
// 進階版：忽略大小寫與非字母字元（雙指標法）
int isPalinAdv(char s[]) {
    int left = 0, right = 0;
    while (s[right] != '\0') right++;
    right--;                                  // 指向最後一個字元

    while (left < right) {
        // 左指標跳過非字母
        while (left < right && !isAlpha(s[left]))  left++;
        // 右指標跳過非字母
        while (left < right && !isAlpha(s[right])) right--;

        // 統一轉小寫後比較
        if (toLower(s[left]) != toLower(s[right])) return 0;
        left++;
        right--;
    }
    return 1;
}

// 輔助函式
int isAlpha(char c) {
    return (c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z');
}
char toLower(char c) {
    if (c >= 'A' && c <= 'Z') return c + 32;
    return c;
}

下列程式意圖「找出陣列中第二大的元素」，但有多處錯誤。
int a[6] = {3, 9, 5, 9, 1, 7};
int i, max, second;
max = 0;
second = 0;
for (i = 0; i <= 6; i++) {
    if (a[i] > max) {
        max = a[i];
    }
    if (a[i] > second && a[i] < max) {
        second = a[i];
    }
}
printf("第二大 = %d", second);

(二) 寫出修正後的程式。（12 分）

📊 (一) 錯誤分析
編號錯誤說明與後果
①陣列越界i <= 6 會存取 a[6]，但合法索引為 0~5 → 未定義行為，讀到垃圾值
②初值設為 0 不安全若陣列全為負數，max 與 second 永遠不會更新 → 錯誤回傳 0
③更新邏輯錯誤當找到新的 max 時，舊的 max 應成為 second，但程式未做此處理 → 結果錯誤
④判斷順序造成漏判max 已在同一輪被更新，故第二個 if 的 a[i] < max 恆為假（因 a[i] 就等於 max）→ second 幾乎不會被更新
⑤未處理重複值{3,9,5,9,...} 中 9 出現兩次；「第二大」是指 7（不同數值）還是 9（第二個位置）？題意須先釐清
⑥未處理元素不足若 n < 2 則無「第二大」，應回傳錯誤或提示
本題最關鍵的是 ③ 與 ④：這是邏輯錯誤——程式能跑完、不會當掉，但答案就是錯的，也是最難發現的一類 bug。
📝 (二) 修正後的程式 
#define N 6

int a[N] = {3, 9, 5, 9, 1, 7};
int i;

// ② 以第一個元素為基準，避免全負數問題
int max = a[0];
int second = -2147483647;      // 或用旗標標示「尚未找到」

// ⑥ 元素不足處理
if (N < 2) {
    printf("元素不足，無第二大\n");
} else {
    for (i = 1; i < N; i++) {          // ① 用 < 且從 1 開始
        if (a[i] > max) {
            second = max;              // ③ 舊的 max 降為 second
            max = a[i];
        } else if (a[i] < max && a[i] > second) {
            second = a[i];             // ④ 改為 else if，避免同輪衝突
        }
        // ⑤ a[i] == max 時不處理 → 表示「第二大」指不同數值
    }

    if (second == -2147483647)
        printf("所有元素相同，無第二大\n");
    else
        printf("最大 = %d，第二大 = %d\n", max, second);
}

驗算（{3, 9, 5, 9, 1, 7}）：

ia[i]判斷maxsecond
初始—max = a[0]3極小值
199 > 3 → 更新93
255 < 9 且 5 > 395
39等於 max → 不處理95
411 < 5 → 不處理95
577 < 9 且 7 > 597
結果：最大 9、第二大 7 ✔（複雜度 O(n)，只需一次掃描）

⚠️ 作答時務必註明題意假設 「本解法將『第二大』定義為次大的不同數值；若題意為第二個位置（即重複的 9 也算），則移除 a[i] < max 條件即可。」

主動釐清模糊題意並說明假設，是申論題的加分行為。
