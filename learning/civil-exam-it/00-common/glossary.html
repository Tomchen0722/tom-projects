🔎 使用方式

  • 申論題寫術語時務必中英並列：資料隱碼攻擊（SQL Injection）。只寫其中一種會少拿印象分。
  • 考前一天不要讀新東西，翻這頁 + 自己的錯題本就好。
  • 用瀏覽器的 Ctrl + F 直接搜尋你想找的縮寫。

🌳 資料結構與演算法

縮寫／英文中文一句話說明
ADT (Abstract Data Type)抽象資料型別只定義「能做什麼操作」，不管內部怎麼實作
Big-O Notation大 O 符號描述演算法成長速度的上界（最壞情況）
Amortized Analysis攤還分析把偶爾很貴的操作平均分攤到多次操作上
LIFO / FIFO後進先出／先進先出Stack 用 LIFO，Queue 用 FIFO
BST (Binary Search Tree)二元搜尋樹左子樹 < 根 < 右子樹
AVL TreeAVL 平衡樹任一節點左右高度差 ≤ 1，靠旋轉維持
Red-Black Tree紅黑樹用顏色規則維持近似平衡，插刪比 AVL 快
B-Tree / B+ TreeB 樹／B+ 樹多元平衡樹，資料庫索引的標準結構
Heap堆積完全二元樹且父子有大小關係，用於優先佇列
Trie字典樹用字元逐層分岔，做字串前綴搜尋
DFS / BFS深度優先／廣度優先搜尋DFS 用堆疊（或遞迴）、BFS 用佇列
MST (Minimum Spanning Tree)最小生成樹連接所有節點且總權重最小；Prim、Kruskal
DP (Dynamic Programming)動態規劃把大問題拆小、記住子問題答案避免重算
Greedy Algorithm貪婪演算法每步都選當下最好的，不保證全域最佳
Divide and Conquer分治法分割 → 解決 → 合併，如 Merge Sort
Backtracking回溯法走不通就退回上一步換條路，如八皇后
NP-CompleteNP 完全目前找不到多項式時間解法的一類難題
Stable Sort穩定排序相同鍵值的相對順序不變（Merge、Insertion、Bubble 穩定）
In-place就地演算法只用 O(1) 額外空間
Collision雜湊碰撞兩個鍵算出同一個位址；用鏈結法或開放定址解決

🗄️ 資料庫

縮寫／英文中文一句話說明
DBMS資料庫管理系統管理資料庫的軟體，如 MySQL、Oracle
RDBMS關聯式資料庫管理系統以表格（關聯）為基礎的 DBMS
DDL / DML / DCL / TCL資料定義／操作／控制／交易語言CREATE｜SELECT INSERT｜GRANT｜COMMIT
ERD (Entity-Relationship Diagram)實體關係圖用實體、屬性、關係描述資料模型
PK / FK主鍵／外鍵PK 唯一識別一列；FK 指向另一表的 PK
Candidate Key / Super Key候選鍵／超鍵能唯一識別的最小屬性集／任意能識別的集合
1NF / 2NF / 3NF / BCNF第一至第三正規化／BC 正規化逐步消除重複、部分相依、遞移相依
FD (Functional Dependency)函數相依A→B：知道 A 就能決定 B
ACID原子性、一致性、隔離性、持久性交易必須具備的四個特性
2PL (Two-Phase Locking)兩階段鎖定先只加鎖、後只解鎖，保證可序列化
Deadlock死結互相等待對方持有的鎖而卡住
Dirty Read / Phantom Read髒讀／幻讀讀到未提交資料／同一查詢兩次結果列數不同
OLTP / OLAP線上交易處理／線上分析處理前者處理日常交易，後者做多維分析
ETL萃取、轉換、載入把來源資料整理進資料倉儲的流程
Data Warehouse / Data Mart / Data Lake資料倉儲／資料超市／資料湖整合型歷史資料／部門子集／原始格式大量存放
NoSQL非關聯式資料庫鍵值、文件、欄族、圖形四類
CAP TheoremCAP 定理一致性、可用性、分區容錯三者最多同時滿足兩個
Sharding / Replication分片／複寫水平切分資料／複製多份提高可用性
Index / Clustered Index索引／叢集索引加速查詢；叢集索引決定資料實體排序
View / Stored Procedure / Trigger檢視表／預存程序／觸發器虛擬表／預先編譯的程式／事件自動執行
