📊 (三) 退化與 AVL
項目內容
BST 退化依已排序（或反序）順序插入 → 成為歪斜樹（高度 n）→ 操作退化為 O(n)
AVL 平衡因子BF = 左高 − 右高，要求 |BF| ≤ 1；失衡時以旋轉回復
高度保證N(h)=N(h−1)+N(h−2)+1 → h ≈ 1.44 log n → 操作保證 O(log n)
類型發生情形處理旋轉次數
LL左子樹的左邊插入對失衡節點右旋單
RR右子樹的右邊插入對失衡節點左旋單
LR左子樹的右邊插入先對左子左旋，再對失衡節點右旋雙
RL右子樹的左邊插入先對右子右旋，再對失衡節點左旋雙

判別口訣：從失衡節點往下走兩步，走的方向就是類型名稱。LR／RL 旋轉後「中間值」成為新根。

📐 (二) 0/1 背包
狀態定義：dp[i][w] = 考慮前 i 個物品、容量 w 時之最大價值

遞迴關係式：
dp[i][w] = dp[i−1][w]　（若 wᵢ > w，放不下）
dp[i][w] = max( dp[i−1][w], dp[i−1][w−wᵢ] + vᵢ )　（否則）

邊界：dp[0][w] = 0、dp[i][0] = 0
複雜度：時間 O(nW)、空間 O(nW)（可用滾動陣列壓為 O(W)）

重要說明：O(nW) 為擬多項式時間（W 為數值而非輸入長度），0/1 背包本質為 NP-Complete。

加分：分數背包（可切割）具貪婪選擇性質，按單位價值貪心即最佳；0/1 背包不可——反例：W=10，物品 A(6,12)、B(5,10)、C(5,10)，貪婪取 A 得 12，最佳為 B+C 得 20。
