A. 複雜度分析（第 1～8 題）

1複雜度
下列關於漸進符號的敘述，何者錯誤？
  • (A) O 表示上界，Ω 表示下界
  • (B) 若 f(n) = Θ(g(n))，則 f(n) = O(g(n)) 且 f(n) = Ω(g(n))
  • (C) 2n² + 3n = O(n³) 是正確的敘述
  • (D) 若 f(n) = O(g(n))，則必定 f(n) = Θ(g(n))
看詳解
答案：(D)
O 只保證「不超過」，不保證「就是這個等級」。例如 n = O(n²) 成立，但 n ≠ Θ(n²)。

其他選項：
(A) 正確，定義如此。
(B) 正確，Θ 就是同時滿足上下界。
(C) 正確且是常見陷阱：O(n³) 是合法的上界（雖然不是最緊的）。「2n²+3n = O(n³)」在數學上為真，只是不夠精確。考試若問「最緊的上界」才要答 O(n²)。
2複雜度
遞迴式 T(n) = 3T(n/4) + n²，T(1) = 1，其時間複雜度為？
  • (A) Θ(n log n)　(B) Θ(n²)　(C) Θ(n^1.5)　(D) Θ(n² log n)
看詳解
答案：(B) Θ(n²)
主定理：a = 3、b = 4 → n^(log₄3) = n^0.79。
f(n) = n² 明顯大於 n^0.79（差距超過 n^ε），且滿足正規條件 3·(n/4)² = 3n²/16 ≤ c·n²（取 c = 3/16 < 1）。
→ Case 3，T(n) = Θ(f(n)) = Θ(n²)。

直覺理解：合併的成本（n²）遠大於遞迴的成本，所以總成本就由最上層決定。
3複雜度
下列複雜度由小到大排列，何者正確？
  • (A) log n < √n < n < n log n < n² < 2ⁿ
  • (B) log n < n < √n < n log n < 2ⁿ < n²
  • (C) √n < log n < n < n² < n log n < 2ⁿ
  • (D) log n < √n < n log n < n < n² < 2ⁿ
看詳解
答案：(A)
關鍵比較：√n = n^0.5 < n = n^1，且 log n 成長最慢（比任何 n^ε 都慢）。
n < n log n 因為 log n > 1（n ≥ 2 時）。

驗證法：代 n = 100 → log₂100 ≈ 6.6 < √100 = 10 < 100 < 664 < 10,000 < 天文數字。✔
4複雜度
下列程式片段的時間複雜度為？
for(i=1; i<=n; i++) for(j=1; j<=n; j=j*2) count++;
  • (A) O(n)　(B) O(n log n)　(C) O(n²)　(D) O(log² n)
看詳解
答案：(B) O(n log n)
外層 i 跑 n 次。內層 j 從 1 開始每次乘 2：1, 2, 4, 8, …, n → 跑 log₂n 次。
總計 n × log n。

陷阱：看到雙層迴圈就答 O(n²) 是最常見的錯誤。要看迴圈變數怎麼變化：j++ 是線性、j*=2 是對數、j+=j 也是對數。
5複雜度
關於攤還分析（Amortized Analysis），下列敘述何者正確？
  • (A) 就是平均情況分析，依機率分布計算
  • (B) 分析一連串操作的總成本平均值，且對最壞情況仍有保證
  • (C) 只能用於分析遞迴演算法
  • (D) 攤還成本一定小於最壞情況成本
看詳解
答案：(B)
攤還分析與平均情況分析不同：後者需假設輸入的機率分布；前者不需機率，是對「任意 n 次操作序列」的總成本取平均，因此有最壞情況的保證。

(A) 錯：混淆了兩個概念，這是最常見的陷阱。
(C) 錯：與遞迴無關，典型應用是動態陣列、Union-Find、Splay Tree。
(D) 錯：單次操作的最壞成本可能很高（如動態陣列擴充是 O(n)），攤還後才是 O(1)。敘述方向雖然接近但「一定」過於絕對。
6複雜度
河內塔（Tower of Hanoi）搬移 n 個盤子所需的最少移動次數為？
  • (A) n²　(B) 2ⁿ　(C) 2ⁿ − 1　(D) n!
看詳解
答案：(C) 2ⁿ − 1
遞迴式 T(n) = 2T(n−1) + 1，T(1) = 1。
展開：T(n) = 2ⁿ⁻¹ + 2ⁿ⁻² + … + 2 + 1 = 2ⁿ − 1（等比數列和）。

白話：要搬 n 個，得先把上面 n−1 個搬去中繼柱（T(n−1)）、搬最大的那個（1 次）、再把 n−1 個搬回來（T(n−1)）。
7複雜度
下列何者不是演算法的必要特性？
  • (A) 有限性（Finiteness）　(B) 明確性（Definiteness）　(C) 至少一個輸入　(D) 至少一個輸出
看詳解
答案：(C)
演算法可以有零個輸入（例如「印出 1 到 100 的質數」不需輸入），但必須至少有一個輸出（否則做了等於沒做）。

延伸考點：作業系統不符合「有限性」（設計上就是要一直執行），因此不是演算法。
8複雜度
T(n) = T(n−1) + n，T(1) = 1，其複雜度為？
  • (A) Θ(n)　(B) Θ(n log n)　(C) Θ(n²)　(D) Θ(2ⁿ)
看詳解
答案：(C) Θ(n²)
T(n) = n + (n−1) + (n−2) + … + 1 = n(n+1)/2 = Θ(n²)。

重要：此式不能用主定理（主定理要求 T(n/b) 形式的除法遞減，這裡是減法）。這正是 Quick Sort 最壞情況的遞迴式。

B. 線性結構（第 9～14 題）

9堆疊
中序運算式 A * (B + C) / D − E 轉為後序運算式為？
  • (A) A B C + * D / E −　(B) A B * C + D / E −　(C) A B C * + D E / −　(D) A B C + D * / E −
看詳解
答案：(A) A B C + * D / E −

完全括號法：
A * (B+C) / D − E
→ (((A * (B+C)) / D) − E)
運算子往右括號移：
→ (((A (B C)+)* D)/ E)−
去括號 → A B C + * D / E −

驗算：代 A=2, B=1, C=2, D=3, E=1
原式 = 2*(1+2)/3 − 1 = 2 − 1 = 1
後序：2 1 2 + * 3 / 1 − → 1+2=3 → 2*3=6 → 6/3=2 → 2−1=1 ✔
10堆疊
後序運算式 8 2 / 3 4 * + 5 − 的值為？
  • (A) 9　(B) 11　(C) 13　(D) 15
看詳解
答案：(B) 11
8, 2 push → 遇 /：8/2 = 4 → push 4
3, 4 push → 遇 *：3*4 = 12 → push 12
遇 +：4 + 12 = 16 → push 16
5 push → 遇 −：16 − 5 = 11

注意：pop 出的第一個是右運算元。此題 8 2 / 是 8÷2 而非 2÷8。
11佇列
大小為 MAX 的環狀佇列，採「犧牲一格」判斷法。若 front = 7、rear = 2、MAX = 10，佇列中有幾個元素？
  • (A) 4　(B) 5　(C) 6　(D) 9
看詳解
答案：(B) 5
公式：(rear − front + MAX) % MAX = (2 − 7 + 10) % 10 = 5 % 10 = 5

驗證：出列是 front 先 +1 再取，所以實際元素在索引 8, 9, 0, 1, 2 → 共 5 個。✔

陷阱：直接算 rear − front = −5 會得到負數，必須加 MAX 再取模。
12鏈結串列
下列關於雙向鏈結串列相對於單向鏈結串列的優點，何者錯誤？
  • (A) 可雙向走訪
  • (B) 已知節點指標時可直接刪除該節點，不需先找前驅
  • (C) 佔用記憶體較少
  • (D) 反向走訪不需重新從頭開始
看詳解
答案：(C)
雙向串列每個節點多一個 prev 指標，記憶體用得更多，這是它的缺點而非優點。

(B) 是關鍵優點：單向串列要刪除節點 X，必須知道 X 的前一個節點才能改指標，通常得從頭走一遍 O(n)；雙向串列直接 X.prev.next = X.next 即可，O(1)。
13陣列
二維陣列 A[1..6][1..10]，以列優先（row-major）儲存，基底位址 2000，每元素佔 4 bytes。A[4][7] 的位址為？
  • (A) 2144　(B) 2148　(C) 2152　(D) 2156
看詳解
答案：(A) 2144
位址 = base + [(i − 1) × 每列元素數 + (j − 1)] × size
= 2000 + [(4 − 1) × 10 + (7 − 1)] × 4
= 2000 + [30 + 6] × 4 = 2000 + 144 = 2144

三個最容易粗心的地方：
1. 下界是 1 還是 0。本題 A[1..6][1..10] 下界為 1，所以要減 1。若題目寫 A[0..5][0..9] 就不用減。
2. 「每列元素數」取的是第二維長度（此處 10），不是第一維。列優先＝一列一列存，所以跨一列要跳過一整列的元素。
3. 別忘了乘元素大小。算出「第 36 個元素」之後還要 ×4 bytes。

(B) 2148 就是把 j 多算一格（未減下界）的結果，是最常見的錯誤答案。
14鏈結串列
要偵測單向鏈結串列中是否存在環路（cycle），使用 O(1) 額外空間的最佳方法為？
  • (A) 用雜湊表記錄走過的節點
  • (B) Floyd 快慢指標法
  • (C) 把每個節點加上 visited 標記
  • (D) 反轉串列後檢查
看詳解
答案：(B) Floyd 快慢指標法（龜兔賽跑）
慢指標一次走 1 步、快指標一次走 2 步。若有環，快指標終將從後面追上慢指標；若無環，快指標會先走到 NULL。
時間 O(n)、空間 O(1)。

(A) 可行但空間 O(n)。
(C) 需修改節點結構，且若串列為唯讀則不可行。
(D) 有環的串列無法正常反轉，會無窮迴圈。

C. 樹（第 15～26 題）

15二元樹
某二元樹有 25 個分支度為 2 的節點，則樹葉節點數為？
  • (A) 24　(B) 25　(C) 26　(D) 無法確定
看詳解
答案：(C) 26
性質：n₀ = n₂ + 1 → 26。

注意分支度為 1 的節點數（n₁）不影響這個關係，所以即使不知道 n₁ 也能唯一決定樹葉數。這正是這個公式好用的地方。
16走訪
某二元樹前序走訪為 A B D E C F G，中序走訪為 D B E A F C G，則後序走訪為？
  • (A) D E B F G C A　(B) D B E F G C A　(C) D E B G F C A　(D) E D B F G C A
看詳解
答案：(A) D E B F G C A

還原過程：
前序第一個 A = 根。中序中 A 的左邊 D B E、右邊 F C G。
左子樹：前序 B D E、中序 D B E → 根 B，左 D，右 E。
右子樹：前序 C F G、中序 F C G → 根 C，左 F，右 G。

　　　A
　／　　＼
　B　　　C
／＼　　／＼
D　E　 F　G

後序（左→右→根）：D E B → F G C → A = D E B F G C A
17走訪
下列哪一組走訪結果無法唯一決定一棵二元樹？
  • (A) 前序 + 中序　(B) 後序 + 中序　(C) 前序 + 後序　(D) 層序 + 中序
看詳解
答案：(C) 前序 + 後序
因為只有中序能區分左右子樹的分界。前序和後序都只能告訴你「誰是根」。

反例：前序 A B、後序 B A 可以是「A 的左子是 B」也可以是「A 的右子是 B」，無法區分。

(D) 層序 + 中序可以唯一決定（層序第一個也是根，之後逐層配合中序切割）。
18BST
依序將 50, 30, 70, 20, 40, 60, 80 插入空的二元搜尋樹，其中序走訪結果為？
  • (A) 50 30 70 20 40 60 80　(B) 20 30 40 50 60 70 80　(C) 20 40 30 60 80 70 50　(D) 20 30 40 60 70 80 50
看詳解
答案：(B) 20 30 40 50 60 70 80
不用畫樹也能答：BST 的中序走訪永遠是由小到大排序，所以答案就是把輸入排序。

(A) 是前序走訪結果。(C) 是後序走訪結果。

這是一定要建立的直覺：中序 + BST = 排序。
19AVL
依序插入 10, 20, 30 到空的 AVL 樹，需要進行何種旋轉？
  • (A) LL（單右旋）　(B) RR（單左旋）　(C) LR（雙旋轉）　(D) RL（雙旋轉）
看詳解
答案：(B) RR（單左旋）
插入 10 → 20 掛右邊 → 30 掛 20 的右邊。此時節點 10 的 BF = 0 − 2 = −2 失衡。
從失衡節點 10 往下走：右 → 右 → RR 型 → 對 10 做左旋，20 上升為根。

結果：20 為根，左子 10、右子 30。

口訣：旋轉類型的名字就是「從失衡點往下走兩步的方向」。
20AVL
依序插入 30, 10, 20 到空的 AVL 樹，需進行何種旋轉，旋轉後的根節點為？
  • (A) LL，根為 10　(B) LR，根為 20　(C) RL，根為 20　(D) RR，根為 30
看詳解
答案：(B) LR，根為 20
30 為根 → 10 掛左 → 20 掛 10 的右邊。節點 30 失衡（BF = 2）。
從 30 往下：左 → 右 → LR 型。

處理：先對 10 左旋（20 上來、10 變成 20 的左子），再對 30 右旋（20 成為根）。
結果：根 = 20，左子 10、右子 30。

小技巧：LR 與 RL 型旋轉後，「中間值」一定成為新的根。此題三個值 10/20/30 中，中間值就是 20。
21Heap
關於最大堆積（Max-Heap），下列敘述何者正確？
  • (A) 中序走訪可得到由大到小的排序結果
  • (B) 任一節點的左子節點必小於右子節點
  • (C) 搜尋任意特定值的時間複雜度為 O(log n)
  • (D) 最小值必定位於某個葉節點
看詳解
答案：(D)
Max-Heap 中，任何非葉節點都 ≥ 它的子節點，所以最小值不可能有子節點 → 必在葉節點。

(A) 錯：Heap 沒有左右順序，中序走訪毫無意義。
(B) 錯：左右子節點沒有任何大小關係，這是與 BST 最大的差別。
(C) 錯：Heap 只能 O(1) 取極值，搜尋任意值要 O(n)（因為無法判斷該往左還是往右）。
22Heap
將 n 個元素建構成一個堆積（Build-Heap），最佳的時間複雜度為？
  • (A) O(n)　(B) O(log n)　(C) O(n log n)　(D) O(n²)
看詳解
答案：(A) O(n)
由下而上（bottom-up）從最後一個非葉節點開始逐一 sift-down，總成本為
Σ (該層節點數 × 該層可能下沉高度) ≈ n × Σ(k/2ᵏ) = O(n)。

常見錯誤：以為「n 個元素各插入一次 O(log n)」= O(n log n)。逐一插入確實是 O(n log n)，但由下而上建堆只要 O(n)。兩者要分清楚。

注意：Heap Sort 整體仍是 O(n log n)，因為建堆 O(n) 之後還要做 n 次 delete-max，每次 O(log n)。
23B樹
關於 B+ 樹與 B 樹的比較，下列何者錯誤？
  • (A) B+ 樹的資料只存在葉節點
  • (B) B+ 樹的葉節點以鏈結串列相連，有利於範圍查詢
  • (C) 相同節點大小下，B+ 樹的分支度通常比 B 樹大
  • (D) B+ 樹單筆查詢的路徑長度不固定，可能在中間層就找到資料
看詳解
答案：(D)
這是 B 樹的特性。B+ 樹的內部節點只存索引鍵、不存資料，所有查詢都必須走到葉節點，路徑長度固定（等於樹高）。

(C) 正確且是關鍵：內部節點不放資料 → 同樣一個磁碟區塊能塞更多鍵值 → 分支度大 → 樹更矮 → 磁碟 I/O 更少。這是資料庫選 B+ 樹的主因。
24Huffman
字元頻率為 A:40、B:30、C:20、D:10，其霍夫曼編碼的平均碼長為多少位元？
  • (A) 1.8　(B) 1.9　(C) 2.0　(D) 2.2
看詳解
答案：(B) 1.9

建樹：
① 取最小兩個：C(20) + D(10) = 30
② 現有 {A:40, B:30, CD:30}，取最小兩個：B(30) + CD(30) = 60
③ A(40) + 60 = 100 → 根

編碼（左 0 右 1，一種可能）：
A = 0（1 位元）｜B = 10（2 位元）｜C = 111（3 位元）｜D = 110（3 位元）

平均碼長 = (40×1 + 30×2 + 20×3 + 10×3) / 100
= (40 + 60 + 60 + 30) / 100 = 190/100 = 1.9

比較：固定長度需 2 位元（2²=4 個字元），壓縮率 = (2−1.9)/2 = 5%。
25二元樹
一棵高度為 5 的二元樹（根為第 1 層），最多可有幾個節點？
  • (A) 16　(B) 31　(C) 32　(D) 63
看詳解
答案：(B) 31
2^h − 1 = 2⁵ − 1 = 31。

(C) 32 = 2⁵ 是最常見的錯誤，忘了減 1。
(A) 16 = 2⁴ 是第 5 層本身的最大節點數（2^(i−1)）。

提醒：有些教科書定義根為第 0 層、高度從 0 算，此時答案會不同。作答時務必先寫明採用的定義，這樣即使與出題者定義不同也不會被扣分。
26平衡樹
下列關於紅黑樹的性質，何者錯誤？
  • (A) 根節點必為黑色
  • (B) 紅色節點的子節點必為黑色

  • (A) 為了減少記憶體使用
  • (B) 為了讓 d[i][j] 的語意正確：使用前 k 個頂點作中繼時的最短距離
  • (C) 為了避免整數溢位
  • (D) 沒有差別，順序可任意調換
看詳解
答案：(B)
Floyd-Warshall 的 DP 狀態是 d(k)[i][j] = 只允許使用頂點 1…k 當中繼點時，i 到 j 的最短距離。
遞迴式：d(k)[i][j] = min( d(k−1)[i][j], d(k−1)[i][k] + d(k−1)[k][j] )

k 必須在最外層，才能保證計算 d(k) 時，所有需要的 d(k−1) 都已完成。若把 k 放內層，會用到還沒算好的值，結果錯誤。

38排序
任何基於比較的排序演算法，其最壞情況的時間複雜度下界為？
  • (A) Ω(n)　(B) Ω(n log n)　(C) Ω(n²)　(D) 無下界
看詳解
答案：(B) Ω(n log n)

決策樹證明：n 個元素有 n! 種可能排列，每次比較最多把可能性二分，故決策樹高度 ≥ log₂(n!)。由 Stirling 近似 log₂(n!) = Θ(n log n)。

所以計數／基數／桶子排序能達 O(n)，並不違反此下界——因為它們不使用比較，而是直接用資料值當索引。這是最常考的延伸問法。

40排序
基數排序（Radix Sort）每一輪必須使用穩定排序，原因為？
  • (A) 為了節省記憶體
  • (B) 若不穩定，前面幾輪已排好的較低位順序會被破壞
  • (C) 為了處理負數
  • (D) 為了降低時間複雜度
看詳解
答案：(B)
LSD 基數排序從最低位排到最高位。排「十位數」時，若兩筆資料十位相同，必須保留它們在「個位數」那輪的相對順序，否則結果錯誤。
