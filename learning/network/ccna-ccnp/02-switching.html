📋交換器的 MAC 位址學習

交換器（Switch）和集線器（Hub）最大的差別：交換器會學習哪個 Port 連著哪台電腦（MAC 位址），然後只把訊框送到對的 Port，不廣播給所有人。

比喻：Hub 像廣播電台，說話所有人都聽到。Switch 像有記憶的快遞員，第一次不知道，就問所有人（Flood）；記住了之後，下次直接送到對的門口（Unicast Forward）。

交換流程（三種情況）

情況動作說明
MAC 表有記錄直接轉發（Unicast Forward）查表找到目的 MAC → 只送那個 Port
MAC 表沒有記錄洪泛（Flood）送給除了來源 Port 以外的所有 Port
目的是廣播（FF:FF:FF:FF:FF:FF）永遠洪泛ARP、DHCP Discover 等廣播都這樣
 
# 查 Cisco Switch 的 MAC 位址表
show mac address-table

# 只看特定 VLAN
show mac address-table vlan 10

# 只看特定 Port
show mac address-table interface gigabitEthernet 0/1
MAC 位址表預設 300 秒（5 分鐘）後自動清掉沒有活動的記錄。可以用 mac address-table aging-time 600 調整。

🏘️VLAN — 虛擬切割廣播域

同一台交換器上的所有 Port 預設都在 VLAN 1（同一個廣播域）。VLAN 讓你把一台實體 Switch 切成多個「虛擬 Switch」，不同 VLAN 無法直接溝通，像住在不同棟的住戶。

比喻：辦公室一棟大樓，1 樓是業務部、2 樓是工程部、3 樓是財務部。雖然住同一棟（同一台 Switch），但各部門的廣播（例如「誰有印表機？」）不會跑到其他部門，互不干擾。要跨部門溝通，要透過大廳（Router／Layer 3 Switch）。

Access Port vs Trunk Port

類型說明連接對象
Access Port只屬於一個 VLAN，電腦感覺不到 VLAN 的存在一般電腦、印表機
Trunk Port可以同時傳多個 VLAN 的訊框，用 802.1Q 標籤區分Switch 對 Switch、Switch 對 Router
! === 建立 VLAN ===
Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config-vlan)# exit
Switch(config)# vlan 20
Switch(config-vlan)# name Engineering

! === 設定 Access Port（電腦接這裡）===
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

! === 設定 Trunk Port（Switch 對接用）===
Switch(config)# interface GigabitEthernet0/24
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport trunk allowed vlan 10,20,30

! === 驗證 ===
Switch# show vlan brief
Switch# show interfaces trunk

Router-on-a-Stick（單臂路由）— 跨 VLAN 通訊

只有一條 Trunk 線連接 Router，在 Router 上建子介面（subinterface）各自負責一個 VLAN 的閘道，就能讓不同 VLAN 互相通訊。

# Router 上設定子介面
Router(config)# interface GigabitEthernet0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0

Router(config)# interface GigabitEthernet0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
企業更常用 Layer 3 Switch 的 SVI（Switched Virtual Interface），在 Switch 上直接做路由，速度更快，不需要額外一台 Router。

🌳STP / RSTP — 防止迴路

如果兩台 Switch 之間有多條連線（為了備援），封包會在裡面無限繞圈（廣播風暴），整個網路癱瘓。STP 負責找出多餘的連線，把它邏輯上關掉，只留一條，需要時才啟用備援路徑。

比喻：城市道路規劃。A 城和 B 城之間有三條路，正常只開放一條走（STP 選出的路），另外兩條設路障（Blocking）。萬一那條路斷了，STP 自動移除其中一條路的路障，讓交通繞過去。

STP 關鍵術語

術語說明
Root BridgeSTP 的中心交換器，所有路徑從這裡算起。Bridge ID 最小的當選（優先權 + MAC）。
Root Port（RP）非 Root Switch 上，距離 Root Bridge 最近的那個 Port。每台非 Root Switch 只有一個 RP。
Designated Port（DP）每條網段上，負責轉發流量的 Port（通常是 Root Bridge 那端的 Port）。
Blocked Port被邏輯關掉的備援 Port，只收 BPDU 不轉發訊框。
BPDUSTP 的「選舉公告」，每 2 秒發一次，讓 Switch 知道拓撲狀況。

STP vs RSTP 收斂時間

協定標準收斂時間建議
STP（802.1D）原始版30–50 秒舊設備，盡量不用
RSTP（802.1W）快速版1–2 秒現代標準，預設使用
MSTP（802.1S）多實例1–2 秒多 VLAN 大型企業用
 
# 查目前 STP 狀態
Switch# show spanning-tree

# 查特定 VLAN 的 STP
Switch# show spanning-tree vlan 10

# 手動指定這台為 Root Bridge（priority 設最低）
Switch(config)# spanning-tree vlan 10 priority 4096

# 或用 macro
Switch(config)# spanning-tree vlan 10 root primary

# PortFast：接電腦的 Port 跳過 STP 等待（連接終端設備時用）
Switch(config-if)# spanning-tree portfast
PortFast 只能用在接電腦的 Access Port，絕對不能用在接其他 Switch 的 Port，否則會造成 STP 失效，引發廣播風暴。同時要搭配 spanning-tree bpduguard enable 防護。

🔗EtherChannel — 鏈路聚合

把 2–8 條實體線路綁在一起，讓 STP 以為只有一條線，但實際頻寬是倍增的，同時也提供備援。

協定說明廠商
LACP（802.3ad）國際標準，兩端都要支援，推薦使用跨廠商
PAgPCisco 專有協定Cisco only
Static（On）不協商，直接捆綁，不建議（缺乏錯誤偵測）任何
 
# 用 LACP 建立 EtherChannel（Port-channel 1）
Switch(config)# interface range GigabitEthernet0/1 - 2
Switch(config-if-range)# channel-group 1 mode active   # LACP active
Switch(config-if-range)# exit

# 在 Port-channel 介面設定 Trunk
Switch(config)# interface port-channel 1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20

# 驗證
Switch# show etherchannel summary
EtherChannel 兩端的 Port 設定（速度、duplex、VLAN 設定）必須完全一致，否則 Channel 無法建立。用 show etherchannel summary 看 SU 表示正常（S=in use, U=in use）。
