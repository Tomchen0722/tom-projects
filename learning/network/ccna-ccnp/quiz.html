八週讀書計畫

週次讀什麼做什麼
W1CH 1-1 OSI／TCP-IP裝好 Packet Tracer，練習基本 CLI 導航
W2CH 1-2 子網路（重中之重）每天算 20 題子網路，練到 30 秒內出答案
W3CH 1-3 + CH 2-1Lab：DHCP + NAT + Port Security
W4CH 2-2 VLAN／TrunkLab：Router-on-a-Stick 與 L3 Switch SVI
W5CH 2-3 STP／EtherChannelLab：手動指定 Root Bridge、LACP 通道
W6CH 3-1、3-2 路由Lab：多區域 OSPF、Floating Static + IP SLA
W7CH 4-1、4-2、4-3Lab：ACL 排錯、Netmiko 腳本
W8全面複習本站模擬考連續三次 90 分以上再報名
報名前的自我檢查：模擬考連續三次 ≥ 90 分、子網路題能在 30 秒內心算、Packet Tracer 能從空白拓樸完整建出一個含 VLAN + Trunk + Inter-VLAN Routing + DHCP + NAT 的網路。三項都做到再花錢報名（考試費約 USD 300）。
