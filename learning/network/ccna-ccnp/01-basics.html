🏛️OSI 七層模型 vs TCP/IP 四層

OSI（開放系統互連）模型是理解網路的「骨架」。現實世界用的是 TCP/IP，但考試和工程師討論問題時，都用 OSI 的語言。

比喻：想像你寄一封快遞。你填寫收件人（應用層）→ 裝箱（表達層）→ 確認對方有沒有空（會話層）→ 決定切幾包（傳輸層）→ 寫上貨車路線（網路層）→ 交給貨車司機（資料鏈路層）→ 貨車在公路上跑（實體層）。每一層只做自己的事，不管別層怎麼實作。

考試重點：各層的設備對應

設備運作在哪層識別依據主要功能
Hub（集線器）第 1 層無識別把訊號廣播給所有 Port
Switch（交換器）第 2 層MAC 位址依 MAC 表只傳給對的 Port
Router（路由器）第 3 層IP 位址跨網段傳送、決定最佳路徑
Layer 3 Switch第 2+3 層MAC + IP同時做交換和路由（企業常用）
Firewall（防火牆）第 3-7 層IP + Port + 應用依規則允許或拒絕流量
記憶口訣：「All People Seem To Need Data Processing」（Application、Presentation、Session、Transport、Network、Data Link、Physical）從上到下背。

🔢IP 位址結構

IPv4 位址由 32 個 bit 組成，分成 4 個「十進位數字」（每組 0–255），例如 192.168.1.100。

公有 IP vs 私有 IP

類型範圍用途
私有 IP（Class A）10.0.0.0 – 10.255.255.255大型企業內網
私有 IP（Class B）172.16.0.0 – 172.31.255.255中型企業
私有 IP（Class C）192.168.0.0 – 192.168.255.255家用路由器
Loopback127.0.0.0 – 127.255.255.255本機測試（ping 127.0.0.1）
APIPA（自動配置）169.254.0.0 – 169.254.255.255DHCP 失敗時自動取得，無法上網
比喻：私有 IP 就像公司的內線分機號碼（1001、1002...），私有 IP 只在公司內部有效。要和外面通話，要透過總機（NAT/路由器）轉換成對外的公有號碼。

✂️子網路切割（Subnetting）

子網路遮罩（Subnet Mask）告訴裝置哪些 bit 是「網路位址」、哪些是「主機位址」。/24 是 CIDR 表示法，代表前 24 個 bit 是網路部分。

IP 位址： 192.168.1.100
子網路遮罩：255.255.255.0 (= /24)
網路位址： 192.168.1.0 ← 這個子網的「名稱」
廣播位址： 192.168.1.255 ← 最後一個，傳給所有人
可用主機： 192.168.1.1 ~ 254 ← 共 254 台

VLSM（可變長子網路遮罩）— CCNA 必考

VLSM 讓你用不同大小的子網路，把 IP 空間切得恰到好處，不浪費。

# 需求：一個 /24 網段，要切成：
# 部門 A：50 台主機  → 需要 /26（62 台）
# 部門 B：25 台主機  → 需要 /27（30 台）
# 點對點鏈路：2 台   → 需要 /30（2 台）

部門 A: 192.168.1.0/26    (192.168.1.1 - 192.168.1.62)
部門 B: 192.168.1.64/27   (192.168.1.65 - 192.168.1.94)
鏈路:   192.168.1.96/30   (192.168.1.97 - 192.168.1.98)

📡三個關鍵協定：DHCP、DNS、ARP

DHCP — 自動發 IP 的機器

比喻：就像飯店 Check-in，你不需要自己決定住哪號房，前台（DHCP Server）會自動分配給你一個房號（IP 位址），並告訴你早餐在哪（Default Gateway）、叫什麼名字可以找到人（DNS Server）。

DHCP 四步驟：DORA（Discover → Offer → Request → Acknowledge）

DNS — 把域名翻成 IP 的字典

你輸入 google.com，電腦不認識這個名字，DNS 幫你查出對應的 IP（如 142.250.1.14），然後才能連過去。

# 測試 DNS 解析（Windows / Linux 都可用）
nslookup google.com
nslookup google.com 8.8.8.8     # 指定用 Google DNS

ARP — 問鄰居「你是哪台電腦？」

你知道對方的 IP，但不知道 MAC 位址，無法直接傳訊框。ARP 廣播問：「誰是 192.168.1.1？」，那台機器回答：「我是，我的 MAC 是 AA:BB:CC:DD:EE:FF」。

# 查看本機 ARP 快取表
arp -a

# Cisco 路由器：查 ARP 表
show ip arp
ARP 只在同一個廣播域（同一個 VLAN / 子網）有效。跨子網要靠路由器，路由器會回應自己的 MAC（Proxy ARP）或靠 Default Gateway。
