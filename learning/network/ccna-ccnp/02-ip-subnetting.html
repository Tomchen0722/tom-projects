🔢 為什麼要學二進位？

電腦只懂 0 和 1。IP 位址在電腦裡其實是 32 個 0/1 的序列，你看到的 192.168.1.100 只是「給人類看的十進位表示法」。
切割子網路的所有計算，本質上都是對這 32 個 bit 進行操作。不懂二進位，就只能死背，懂了之後任何題目都能推導出來。

十進位 vs 二進位

十進位（我們日常用的）每一位是 0–9，滿 10 進位。
二進位每一位只有 0 或 1，滿 2 進位。IP 位址的每一個「數字」（例如 192）代表 8 個 bit，稱為一個 Octet（八位元組）。

十進位 → 二進位（手算法）

方法：從最大位值（128）開始，逐一判斷「能不能減」：能減就填 1，不能就填 0。

範例：把 192 轉成二進位

192 ≥ 128，第 8 位填 1，剩下 192 − 128 = 64

2

64 ≥ 64，第 7 位填 1，剩下 64 − 64 = 0

公有 IP vs 私有 IP

私有 IP 是保留給內部網路用的，不會出現在公開網際網路上。透過 NAT，私有 IP 可以共用一個公有 IP 上網。

🎭 子網路遮罩原理

子網路遮罩（Subnet Mask）是 32 個 bit，左邊都是 1，右邊都是 0，中間沒有例外。
規則：遮罩的 1 的部分 = 網路位址（固定），0 的部分 = 主機位址（可變動）。

以 /24（255.255.255.0）為例：
IP 位址： 192.168.1.100
11000000.10101000.00000001.01100100
子網路遮罩：255.255.255.0
11111111.11111111.11111111.00000000
←————— 網路部分（固定）—————→ ←主機→

AND 運算（1 AND 1=1，其他=0）得到網路位址：
網路位址： 192.168.1.0 （主機位元全補 0）
廣播位址： 192.168.1.255（主機位元全補 1）
可用主機： 192.168.1.1 ~ 192.168.1.254（共 254 台）

CIDR 表示法（斜線表示法）

/24 是 CIDR（Classless Inter-Domain Routing）表示法，數字代表從左邊數有幾個 1。
例如 /24 = 前 24 個 bit 都是 1 = 255.255.255.0。

比喻：如果 IP 位址是一個地址「台灣台北市信義區某路100號5樓」，子網路遮罩就像是告訴你「縣市＋區」是固定的（網路部分），「路名＋號碼＋樓層」才是可以變動的（主機部分）。遮罩越長（/28 vs /24），固定的部分越多，能容納的主機數越少。

🧮 子網路切割五步驟計算法

記住這五個步驟，任何子網路題目都能解。每個步驟都有對應公式。

1
確認原始網段和需求

題目給你一個網段（例如 192.168.10.0/24）和需求（例如「需要切出 6 個子網路」或「每個子網需要 30 台主機」）

2
決定借幾個 bit

如果題目給「需要 N 個子網路」：借 n 個 bit，使得 2ⁿ ≥ N
如果題目給「每個子網需要 H 台主機」：主機位元 h 個，使得 2ʰ − 2 ≥ H，然後借的 bit = 總位元 − h − 原本的網路位元

3
計算新的遮罩（/N）

新遮罩 = 原本遮罩 + 借的 bit 數
例如：原本 /24，借 3 個 bit → 新遮罩 /27

4
計算「區塊大小」（Subnet Increment）

區塊大小 = 256 − 最後一個非 0 遮罩八位數
例如 /27 = 255.255.255.224，最後一組是 224 → 區塊大小 = 256 − 224 = 32

5
列出所有子網路

從原始網路位址開始，每次加一個「區塊大小」就是下一個子網路的起始位址。
每個子網路的廣播位址 = 下一個子網路起始位址 − 1
可用主機 = 網路位址 + 1 到廣播位址 − 1

三個核心公式（一定要記）：
子網路數量 = 2^(借的bit數)
每網路主機數 = 2^(剩餘host bit) − 2 （減 2：扣掉網路位址和廣播位址）
區塊大小 = 256 − 遮罩最後一個八位數 （或 = 2^(host bit數)）

🏗️ VLSM 可變長子網路遮罩 — 完整企業設計

傳統子網路切割要求每個子網路大小一樣（浪費 IP）。VLSM 允許每個子網路用不同長度的遮罩，讓 IP 使用率接近 100%。CCNA 必考，CCNP 要能設計。

比喻：停車場有 100 個停車格，傳統做法是全部畫成同樣大小（不管是要停機車還是大卡車）。VLSM 就是智慧停車場：大車位給大車、小車位給機車，同樣 100 格停更多輛。

VLSM 設計場景：一個 /20 分配給公司五個部門

原始網段：10.1.0.0/20（可用 IP：10.1.0.1 – 10.1.15.254，共 4094 個）

需求：

  • 總部：需要 500 台主機
  • 業務部：需要 200 台主機
  • 工程部：需要 100 台主機
  • 財務部：需要 50 台主機
  • 會議室 VLAN：需要 20 台主機
  • 三條 WAN 點對點鏈路：各需要 2 台

⚠️ 考試常見陷阱

陷阱 1：網路位址和廣播位址不能分配給主機
192.168.1.0（網路位址）和 192.168.1.255（廣播位址）不能給任何設備，這樣每個 /24 只有 254 個可用，不是 256 個。
陷阱 2：/31 和 /32 的特殊用途
/31：2 個位址，理論上沒有主機可用（都是網路/廣播），但 RFC 3021 允許用在點對點鏈路。
/32：只有 1 個 IP，用於 Loopback 介面（router-id），不代表子網路。
陷阱 3：跨越八位組的子網路（如 /22、/14）
切割點不在第四組而是在第三組時，區塊大小要看「切割發生的那組」。/22 = 255.255.252.0，第三組是 252，區塊大小 = 256 − 252 = 4，表示第三組每次跳 4。
陷阱 4：「需要 4 個子網」和「可用 4 個子網」不同
如果題目問「至少要切出 4 個子網」，你借 2 個 bit（2² = 4）剛好夠；但如果有特殊子網 0 和全 1 子網的限制（老教材），則需要借 3 個 bit（2³ = 8，排除頭尾後有 6 個）。現代 Cisco IOS 預設 ip subnet-zero 啟用，可以用 subnet 0 和廣播子網，不需要排除。

🔬 Packet Tracer Lab 實作指引

根據上面 VLSM 設計練習，在 Packet Tracer 中重現這個企業網路。

  1. 下載 Cisco Packet Tracer（免費，在 Cisco NetAcad 官網，需要免費帳號）
  2. 建立拓樸：1 台 Cisco 2911 Router + 5 台 2960 Switch + 各部門 PC 若干
  3. 設定 Router 介面：對每個子網路建立子介面（Router-on-a-Stick），設定各部門的閘道 IP
  4. 驗證連通性：從總部 PC ping 業務部 PC，確認跨子網路通訊正常
  5. 驗證隔離：不加路由規則時，確認不同 VLAN 之間不能互相 ping
  6. 加分挑戰：設定 ACL，讓財務部只能被總部存取，業務部不能訪問財務部

完成這個 Lab 後，你對子網路切割的理解會從「會算」升到「會用」。
