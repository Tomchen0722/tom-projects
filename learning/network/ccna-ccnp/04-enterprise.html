🔒ACL 存取控制清單

ACL 像路由器的保全守衛，根據規則允許（permit）或拒絕（deny）封包通過。規則從上到下逐條比對，第一條符合就停止。

比喻：夜店門口的名單。保全從名單第一行開始看：「VIP？放行。黑名單？拒絕。」一旦找到符合的，後面的規則就不看了。沒有符合任何規則？最底部有一條隱性拒絕（implicit deny all），全部擋掉。

標準 ACL vs 延伸 ACL

類型ACL 號碼過濾依據建議放置位置
標準 ACL1–99只看來源 IP靠近目的地
延伸 ACL100–199來源 IP、目的 IP、Protocol、Port靠近來源
命名 ACL名稱字串同上，但可以刪除單一條目推薦使用
! === 延伸 ACL：只允許業務部(192.168.10.0/24)訪問 HTTP ===
Router(config)# ip access-list extended SALES_TO_WEB
Router(config-ext-nacl)# permit tcp 192.168.10.0 0.0.0.255 any eq 80
Router(config-ext-nacl)# permit tcp 192.168.10.0 0.0.0.255 any eq 443
Router(config-ext-nacl)# deny ip any any log

! === 套用到介面（In = 進來的流量）===
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip access-group SALES_TO_WEB in

! === 驗證 ===
Router# show ip access-lists SALES_TO_WEB
Wildcard mask 和 Subnet mask 相反：0.0.0.255 代表最後 8 bit 不管（=符合 /24 網段）。記法：用 255.255.255.255 減去 subnet mask。

NAT — 私有 IP 轉換成公有 IP

家用路由器、企業防火牆幾乎都有 NAT。內部用私有 IP，出去網際網路時轉換成一個（或幾個）公有 IP，節省 IP 位址。

類型說明常見場景
Static NAT一對一，固定對應對外提供服務的伺服器（Web、Mail）
Dynamic NAT多對多，從 Pool 取較少用
PAT / Overload多對一，靠 Port 號區分家用路由器、企業上網（99% 的情況）
 
# PAT（最常用）：內部 192.168.0.0/24 共用外部介面 IP 上網
Router(config)# ip nat inside source list 1 interface GigabitEthernet0/1 overload

Router(config)# access-list 1 permit 192.168.0.0 0.0.0.255

Router(config)# interface GigabitEthernet0/0   # 內部介面
Router(config-if)# ip nat inside
Router(config)# interface GigabitEthernet0/1   # 外部介面
Router(config-if)# ip nat outside

Router# show ip nat translations

⚡QoS — 服務品質與流量整形

頻寬有限時，不是所有流量都一樣重要。語音電話（VoIP）延遲超過 150ms 就會斷斷續續；大型備份檔案晚個 10 分鐘傳完也沒關係。QoS 幫你設定優先順序。

比喻：醫院急診室的分流制度。心肌梗塞（VoIP）立刻進去；感冒（一般瀏覽）等候區坐著等；健康檢查（大型備份）明天再來。所有人都能看到醫生，但優先度不同。

DSCP 標記（QoS 標籤）

EF
語音
AF41
視訊
AF21
重要資料
BE
一般流量
CS1
背景備份
DSCP 值名稱適合流量最大延遲建議
46（101110）EF（Expedited Forwarding）VoIP 語音<150ms
34（100010）AF41視訊會議<400ms
18（010010）AF21關鍵業務資料盡力
0（000000）BE（Best Effort）一般上網、email不保證
8（001000）CS1大型備份、P2P不保證

MQC 三步驟（Modular QoS CLI）

# 步驟 1：class-map — 辨識流量
Router(config)# class-map match-all VOIP
Router(config-cmap)# match dscp ef

# 步驟 2：policy-map — 定義動作
Router(config)# policy-map QOS_POLICY
Router(config-pmap)# class VOIP
Router(config-pmap-c)# priority 512       # LLQ，保證 512Kbps
Router(config-pmap)# class class-default
Router(config-pmap-c)# fair-queue          # 其餘流量公平排隊

# 步驟 3：service-policy — 套用到介面
Router(config)# interface Serial0/0
Router(config-if)# service-policy output QOS_POLICY

🌐SD-WAN — 軟體定義廣域網路

傳統 WAN 靠昂貴的 MPLS 專線，所有流量都要繞回總部（Backhaul）。SD-WAN 把控制面和資料面分離，用軟體集中管理多條鏈路（MPLS + Internet + LTE），智慧選路，降低成本。

🧠
vManage
Web 管理介面，集中設定策略，推送到所有設備
🎛️
vSmart
控制器，負責路由策略與 Policy 分發
🔐
vBond
協調器，負責設備認證和 NAT 穿透
📡
vEdge / cEdge
分支機構的邊緣路由器，實際轉發資料

SD-WAN 優勢

  • 應用感知路由：視訊走延遲低的 MPLS，一般上網走便宜的 Internet
  • 集中管理：不需要一台一台 SSH 進去設定，vManage 一次推送
  • 快速分支展店：新分店寄一台 vEdge 過去，Zero Touch Provisioning 自動上線
  • 降低成本：減少 MPLS 依賴，混用廉價 Broadband + LTE
Cisco SD-WAN（原 Viptela）和 VMware VeloCloud 是目前市場兩大主流。CCNP ENCOR/ENARSI 考試對 SD-WAN 概念的考點越來越多。

🤖網路自動化

CCNP ENCOR 考試明確包含網路可程式化的內容。現代網路工程師要會用程式控制網路設備，不再只是 CLI 指令。

Netmiko — Python SSH 連線

from netmiko import ConnectHandler

# 定義設備
device = {
    'device_type': 'cisco_ios',
    'host':        '192.168.1.1',
    'username':    'admin',
    'password':    'cisco123',
}

# 連線並執行指令
with ConnectHandler(**device) as net_connect:
    output = net_connect.send_command('show ip interface brief')
    print(output)

    # 批次設定（設定模式）
    commands = [
        'interface GigabitEthernet0/1',
        'description 業務部',
        'ip address 192.168.10.1 255.255.255.0',
        'no shutdown',
    ]
    net_connect.send_config_set(commands)

RESTCONF — 用 HTTP API 操控網路

# 用 Python requests 讀取設備介面資訊（YANG 模型）
import requests, json

url = "https://192.168.1.1/restconf/data/ietf-interfaces:interfaces"
headers = {
    "Accept":       "application/yang-data+json",
    "Content-Type": "application/yang-data+json",
}

resp = requests.get(url, auth=('admin', 'cisco123'),
                    headers=headers, verify=False)
data = resp.json()
for iface in data['ietf-interfaces:interfaces']['interface']:
    print(iface['name'], '-', iface.get('description', '(無描述)'))
