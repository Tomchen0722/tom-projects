UNIT 05 · BLOCKS & ANNOTATION MASTERY

AutoCAD 2024 「圖塊」與「註解」高效製圖

電子電路板上有成百上千顆電阻、電容和 IC，難道要一個個重畫嗎？利用「印章模具學（圖塊 Block）」，畫好一次終身重用！搭配標準工程尺寸標註與引線，讓圖紙專業度達到甲級技術士水準！

核心架構 1. 圖塊 (Block) 的印章模具哲學 —— 畫一次，用一生

🧑‍🏫 高中生白話秒懂： 想像做鳳梨酥或餅乾。你先雕刻出一個精緻的「鋼製模具」（定義圖塊），之後要產出 1,000 塊餅乾，只要拿模具往麵團上一壓（插入圖塊），1 秒印出一個！

💡 為什麼不用 Copy 複製，而一定要做成圖塊？兩大救命理由：
1. 全圖連動修改：若你用 Copy 複製了 50 顆電阻，老闆突然說電阻焊盤要從 1.8mm 改大到 2.0mm，你就得手動改 50 次，改到眼睛抽筋！但若做成圖塊，你只要在「圖塊編輯器 (BEDIT)」裡修改模具一次，全圖 50 顆電阻瞬間自動同時更新！
2. 大幅縮小檔案體積：複製 1,000 個獨立圖形會讓 DWG 檔案暴增到幾十 MB；使用圖塊時，電腦只記錄「模具一次 + 1,000 個座標點」，檔案依然輕巧秒開！
🎯 製作電子元件圖塊三大步驟 (指令: BLOCK / B)：
1. 先在畫面上畫好元件（例如一個長 8mm、寬 2.8mm 的電阻絲印框與兩個焊盤）。
2. 輸入 B 按空白鍵，彈出圖塊定義對話框：
• 名稱 (Name)：輸入易懂的型號，例如 RESISTOR_TH (直插電阻)。
• 基準點 (Base point)：點擊「挑選點」，選擇電阻的「中心點」或「Pin 1 焊盤中心」作為抓取把柄。
• 選取物件 (Select objects)：把剛才畫的線和圓形圈選起來。
3. 點擊「確定」，一顆標準電子元件印章大功告成！
呼叫印章: 輸入 I (INSERT) ➜ 在圖塊清單中拖曳出 RESISTOR_TH 放置於電路板上
指令: BEDIT (快速鍵: BE) / EXPLODE (快速鍵: X) 2. 修改模具與積木拆解

🛠️ 圖塊編輯器 (BEDIT)

在任何圖塊上連續快按兩下滑鼠左鍵，立刻進入全螢幕「灰色背景的圖塊手術室」！在裡面隨意調整尺寸、加字，點擊右上角「關閉圖塊編輯器並儲存」，整個工程圖面立刻全面連動更新！

💥 分解 / 炸開 (EXPLODE / X)

如果某顆電阻想要做特殊修改、不想跟其他圖塊連動，點選它後在指令行輸入 X 按空白鍵！圖塊立刻被「炸開」，還原成各自獨立的線條和圓形，脫離模具控制。

指令: TEXT (單行) / MTEXT (多行) 3. 文字標記 —— 元件編號與電路板說明

在電路板上，我們必須標記 R1 10k、C1 10μF、NE555，AutoCAD 提供兩種文字工具：

類型 快速鍵 特點與適用場合
單行文字 (TEXT) DT 輕量快速！輸入起點、字高（如 PCB 絲印字高 1.5 mm）、旋轉角（0）後直接打字。適合標記零件短代號（R1、GND、VCC）。
多行文字 (MTEXT) MT 或 T 功能強大！拉出一個文字方塊，頂部出現類似 Word 的文字編輯列，支援段落排版、項目符號、特殊符號（如直徑 Ø、度數 °、微米 μ）。適合寫專案說明、設計注意事項。
指令: DIM 系列 (快速鍵: DLI / DAL / DRA / DDI) 4. 尺寸標註 —— 工廠加工與品管驗收的法定依據

🧑‍🏫 高中生白話秒懂： 「沒有標註尺寸的圖紙，只是一張廢紙！」工廠師傅必須根據你標的數字來裁切板子、設定鑽頭直徑。AutoCAD 的尺寸標註具有「關聯性」——當你用拉伸指令把電路板改長 10mm，上面的尺寸數字會自動跳轉為新數字！

📏 DIMLINEAR (DLI) 線性標註

專門標註水平或垂直長度。
點選電路板左下角與右下角，滑鼠往下拉，點一下左鍵放下尺寸線 ➜ 顯示 50.00 mm！

📐 DIMALIGNED (DAL) 對齊標註

專門標註斜線的真實幾何長度。
標註線會自動旋轉並平行於該斜線（標註 45 度斜走線長度必備）。

⭕ DIMRADIUS (DRA) 半徑標註

點選圓弧或圓形，自動標出 R3.00（標註電路板四個倒圓角）。

⌀ DIMDIAMETER (DDI) 直徑標註

點選鑽孔圓形，自動標出直徑符號 Ø3.20（標註螺栓安裝孔孔徑）。

💡 標註形式管理員 (DIMSTYLE / 快捷鍵 D)：
如果發現標註出來的數字太小（像螞蟻一樣看不清）或者箭頭太大：
輸入 D 按空白鍵 ➜ 點選「修改 (Modify)」➜ 在「文字」標籤把字高改為 2.5 mm，在「符號與箭頭」把箭頭大小改為 2.0 mm，在「主要單位」設定精度為 0.00（兩位小數），全圖尺寸立刻漂亮規整！
