AutoCAD 2024 快捷鍵大全、系統變數與地雷急救

製圖速度慢？畫面卡頓？對話視窗突然不見？指令行消失？本章彙整單手盲打高頻指令庫、修改 acad.pgp 自訂別名秘技、五大救命系統變數（FILEDIA / PICKFIRST / MBUTTONPAN）與 12 大崩潰現場秒殺急救手冊！

一、 AutoCAD 2024 常用單字母與高頻指令清單

在指令行直接鍵入字母後按空白鍵即可觸發。左手鍵盤輸入、右手滑鼠定向，是專業工程師的標準作業姿態！

⚡ 單字母神速指令

  • L = LINE (畫直線)
  • C = CIRCLE (畫圓形)
  • M = MOVE (移動物件)
  • E = ERASE (刪除物件)
  • O = OFFSET (等距偏移)
  • F = FILLET (倒圓角 / R=0接角)
  • X = EXPLODE (分解/炸開)
  • B = BLOCK (建立圖塊)
  • I = INSERT (插入圖塊)
  • H = HATCH (填充線/鋪銅)
  • S = STRETCH (綠框拉伸)
  • D = DIMSTYLE (標註形式)
  • Z = ZOOM (視圖縮放)

⚡ 雙字母高頻指令

  • PL = PLINE (聚合線走線)
  • TR = TRIM (修剪線頭)
  • EX = EXTEND (延伸線條)
  • CO = COPY (複製物件)
  • RO = ROTATE (旋轉角度)
  • MI = MIRROR (鏡射對稱)
  • SC = SCALE (比例縮放)
  • AR = ARRAY (陣列排布)
  • LA = LAYER (圖層管理員)
  • MA = MATCHPROP (性質複製)
  • DO = DONUT (實心焊盤)
  • DI = DIST (測量距離)

⚡ 標註與 Ctrl 組合神鍵

  • DLI = DIMLINEAR (線性標註)
  • DAL = DIMALIGNED (對齊標註)
  • DRA = DIMRADIUS (半徑標註)
  • DDI = DIMDIAMETER (直徑標註)
  • Ctrl+1 = 開關「性質」側邊視窗
  • Ctrl+9 = 開關「指令行 (Command)」
  • Ctrl+0 = 清理螢幕 (全螢幕最大化)
  • Ctrl+S = 儲存檔案 (強迫症必備)
  • Ctrl+Z = 復原 (Undo)
  • Ctrl+P = 出圖列印 (Plot)

二、 專業工程師的五大「救命系統變數」

AutoCAD 有數百個控制底層行為的「系統變數 (System Variables)」。新手常因為誤觸快捷鍵改動了變數，導致彈出視窗消失或滑鼠失靈，背熟這五個變數就能瞬間拯救崩潰現場：

系統變數 五大常見靈異系統變數速查
FILEDIA = 1
症狀：點「開啟舊檔」或「另存新檔」，居然沒彈出檔案瀏覽視窗，只在下方指令行要求輸入路徑！
解法：輸入 FILEDIA ➜ 輸入 1 ➜ 檔案對話方塊立刻恢復！
PICKFIRST = 1
症狀：先用滑鼠選中一條線，按下鍵盤 Delete 鍵卻完全沒反應，只能先打 E 指令才能刪除！
解法：輸入 PICKFIRST ➜ 輸入 1 ➜ 恢復「先選物件、後按指令」的現代操作習慣。
MBUTTONPAN = 1
症狀：按住滑鼠滾輪本來該平移畫布，現在按住滾輪卻彈出右鍵功能表！
解法：輸入 MBUTTONPAN ➜ 輸入 1 ➜ 按住滾輪立刻變回抓取手掌 ✋！
HIGHLIGHT = 1
症狀：滑鼠點選線條後，畫面上完全看不出有沒有選中（不會亮起虛線）！
解法：輸入 HIGHLIGHT ➜ 輸入 1 ➜ 被選中物件立刻高亮點亮！
MIRRTEXT = 0
症狀：執行鏡射 MIRROR 時，零件標記文字變成了左右相反的火星文！
解法：輸入 MIRRTEXT ➜ 輸入 0 ➜ 鏡射後文字方向依然正向易讀。

三、 新手最常崩潰的 12 大地雷與秒殺急救手冊

遇到怪異情況請對號入座，絕不需要重灌軟體或重開機：

💥 地雷 1：畫面突然一片黑茫茫空白，我剛才畫的圖紙是不是被當機刪除了？

原因：圖紙完好無損！只是滾輪滾動過快，視圖縮放到外太空去了。
🚑 秒殺解法：對著滑鼠滾輪連續快速按兩下（觸發 Zoom Extents），或在指令行輸入 Z 空白鍵 ➜ E 空白鍵，所有圖形瞬間滿版飛回螢幕正中央！

💥 地雷 2：滑鼠像卡在泥巴裡一樣一格一格跳躍，完全沒辦法平滑瞄準？

原因：誤按到了 F9 開啟了「鎖定格點 (Snap Mode)」，強制滑鼠只能沿著網格跳躍。
🚑 秒殺解法：按下鍵盤 F9 關閉，滑鼠立刻恢復如絲般順滑！

💥 地雷 3：明明肉眼看著線接上了，為什麼放大 100 倍看是分開斷裂的？

原因：沒開物件鎖點，憑肉眼點擊在雙精度浮點運算下一定會有 0.0001mm 的微小間隙，在 PCB 裡就是斷路！
🚑 秒殺解法：按下 F3 開啟物件鎖點！務必開啟「端點、中點、圓心、交點」。

💥 地雷 4：設定了 1.0mm 的超粗電路走線，畫出來看起來依然跟細毛一樣細？

原因：AutoCAD 預設關閉了線寬實體顯示。
🚑 秒殺解法：指令行輸入 LWDISPLAY ➜ 輸入 ON，粗線立刻真實渲染顯現！

💥 地雷 5：選了虛線 (DASHED) 或中心線，在畫布上看依然是一條死板的實線？

原因：全域線型比例不合適。
🚑 秒殺解法：輸入 LTSCALE ➜ 將數值改為 0.2 或 0.1 ➜ 輸入 RE (重新生成)，虛線間隔立刻清晰出現！

💥 地雷 6：下面的「指令行」不小心被叉叉關掉了，怎麼打字都沒反應？

原因：誤按關閉快捷鍵。
🚑 秒殺解法：按下鍵盤組合鍵 Ctrl + 9，指令行立刻歸位！

💥 地雷 7：填充線 (Hatch) 一直報錯「找不到有效的封閉邊界」，完全填不滿？

原因：線段交接處有微小破網。
🚑 秒殺解法：使用 FILLET（圓角）輸入 R ➜ 0，點選有缺口的兩條線，軟體自動延伸閉合！

💥 地雷 8：標註出來的尺寸數字小得像螞蟻一樣，完全看不清楚？

原因：標註樣式文字高度過小。
🚑 秒殺解法：輸入 D ➜ 點選「修改」➜ 在「文字」分頁把字高改為 2.5 或 3.0，箭頭改為 2.0！

💥 地雷 9：出圖列印 PDF 時，電路板居然被縮小了，IC 腳位插不進去！

原因：列印時勾選到了「布滿圖紙 (Fit to paper)」。
🚑 秒殺解法：取消勾選「布滿圖紙」，出圖比例手動下拉選擇 1:1（1 公釐 = 1 單位）！

💥 地雷 10：開啟老舊圖紙時，很多中文文字全部變成一個個「？？？」問號！

原因：缺乏對應的 SHX 國標工程字體檔。
🚑 秒殺解法：輸入 STYLE (ST) ➜ 將字型名稱改為通用 TrueType 字型（如「微軟正黑體」或「Arial」），點擊「套用」，所有中文問號立刻復活！
