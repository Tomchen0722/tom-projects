AutoCAD 2024 快捷鍵速查與新手 10 大地雷排除

製圖速度慢？畫面卡頓？圖紙找不到？指令行突然消失？工程師最常遇到的 10 大崩潰現場與秒殺解決法，搭配單手盲打快捷鍵清單，讓你從製圖菜鳥晉升技術高手！

一、 AutoCAD 2024 常用單字母與高頻快捷鍵清單

在指令行直接鍵入字母後按空白鍵即可觸發。左手放鍵盤、右手握滑鼠，才是專業製圖姿態！

⚡ 單字母神速指令

  • L = LINE (畫直線)
  • C = CIRCLE (畫圓形)
  • M = MOVE (移動物件)
  • E = ERASE (刪除物件)
  • O = OFFSET (等距偏移)
  • F = FILLET (倒圓角)
  • X = EXPLODE (分解/炸開)
  • B = BLOCK (建立圖塊)
  • I = INSERT (插入圖塊)
  • H = HATCH (填充線)
  • S = STRETCH (拉伸)
  • D = DIMSTYLE (標註形式)
  • Z = ZOOM (視圖縮放)

⚡ 雙字母高頻指令

  • PL = PLINE (聚合線走線)
  • TR = TRIM (修剪線頭)
  • EX = EXTEND (延伸線條)
  • CO / CP = COPY (複製物件)
  • RO = ROTATE (旋轉角度)
  • MI = MIRROR (鏡射對稱)
  • SC = SCALE (比例縮放)
  • AR = ARRAY (陣列排布)
  • LA = LAYER (圖層管理員)
  • MA = MATCHPROP (性質複製)
  • DO = DONUT (實心圓環/焊盤)
  • DI = DIST (測量距離)

⚡ 標註與 Ctrl 組合鍵

  • DLI = DIMLINEAR (線性標註)
  • DAL = DIMALIGNED (對齊標註)
  • DRA = DIMRADIUS (半徑標註)
  • DDI = DIMDIAMETER (直徑標註)
  • Ctrl+1 = 開關「性質」選項板
  • Ctrl+9 = 開關「指令行 (Command)」
  • Ctrl+0 = 清理螢幕 (全螢幕最大化)
  • Ctrl+Z = 復原 (Undo)
  • Ctrl+Y = 重做 (Redo)
  • Ctrl+P = 出圖列印 (Plot)

二、 新手最常崩潰的 10 大地雷與急救解法

學 AutoCAD 最怕遇到奇怪的卡頓和消失。遇到以下問題，請立刻對號入座：

💥 地雷 1：畫面突然一片漆黑空白，我剛才畫的圖呢？是不是當機被刪了？

原因：圖紙沒有消失！只是滑鼠滾輪不小心滑動太快，畫面縮放到太空之外，或者跑到遠離原點的角落。
🚑 秒殺解法：對著滑鼠滾輪連續快按兩下（觸發 Zoom Extents），或者在指令行輸入 Z 空白鍵 ➜ E 空白鍵，所有圖形立刻瞬間飛回螢幕中央！

💥 地雷 2：滑鼠像卡在泥巴裡一樣一頓一頓地跳動，根本沒辦法精確瞄準？

原因：你不小心按到了 F9 開啟了「鎖定格點 (Snap Mode)」，強制滑鼠只能在背後格線上跳躍！
🚑 秒殺解法：按下鍵盤 F9 將其關閉，滑鼠立刻恢復如絲般順滑！

💥 地雷 3：畫線明明用眼睛看接上了，為什麼放大 100 倍看是分開斷裂的？

原因：你沒有開啟「物件鎖點 (Object Snap)」，僅憑肉眼視覺去點擊，在 CAD 的浮點運算世界中誤差可能是 0.0001mm，導致無法封閉！
🚑 秒殺解法：按下 F3 開啟物件鎖點！在右下角 F3 圖示按滑鼠右鍵，務必勾選「端點」、「中點」、「圓心」、「交點」。

💥 地雷 4：我明明在圖層設定了 1.0mm 的超粗電路走線，為什麼畫出來依然跟細毛一樣？

原因：AutoCAD 預設關閉了線粗實體渲染以保持順暢度。
🚑 秒殺解法：在畫面右下角狀態列點擊「顯示/隱藏線粗 (LineWeight)」按鈕，或在指令行輸入 LWDISPLAY ➜ 輸入 ON ➜ 粗線立即亮麗顯現！

💥 地雷 5：設定了「虛線 (Hidden)」或「中心線 (Center)」，畫出來看起來卻像一條死板的實線？

原因：線型比例 (LineType Scale) 不匹配！虛線的點跟點之間距離太大（或太小），導致看起來像直線。
🚑 秒殺解法：輸入 LTSCALE 按空白鍵 ➜ 輸入新比例（例如 10 放大，或 0.1 縮小）➜ 虛線的虛點間隔立即出現！

💥 地雷 6：下面的「指令行」被我不小心關掉了，怎麼打字都沒反應？

原因：按到了關閉指令行快捷鍵。
🚑 秒殺解法：按下 Ctrl + 9，指令行立刻歸位！

💥 地雷 7：填充線 (Hatch) 一直跳出警告「找不到封閉邊界」，點哪裡都填不滿？

原因：邊界有肉眼看不到的微小縫隙，油漆流出去了。
🚑 秒殺解法：使用 FILLET（圓角）輸入半徑 R ➜ 0，點選有缺口的兩條邊，電腦會自動把線頭延伸並完美相交閉合！

💥 地雷 8：用滑鼠框選東西時，為什麼有時候選得到，有時候明明框到了卻沒選中？

原因：記住選取方向原則！
• 由左往右拉（藍框）：必須整隻物體 100% 完整被框在裡面才會被選中。
• 由右往左拉（綠框）：只要碰到任何一根毛邊，整條線都會被選中！

💥 地雷 9：標註出來的工程尺寸，數字小得跟跳蚤一樣，完全看不清楚？

原因：標註樣式的文字高度 (Text Height) 太小。
🚑 秒殺解法：輸入 D 按空白鍵 ➜ 點選「修改」➜ 在「文字」標籤頁把字高改為 2.5 或 3.0，在「符號與箭頭」把箭頭大小改為 2.0，確定後數字瞬間變大清晰！

💥 地雷 10：印出 PDF 或紙本時，電路板居然被縮小了，零件腳位插不進去！

原因：出圖列印時勾選到了「布滿圖紙 (Fit to paper)」，電腦為了把圖硬塞進紙張，自動縮放了 0.85 倍！
🚑 秒殺解法：在列印視窗中取消勾選「布滿圖紙」，並手動在出圖比例選擇 1:1（1 公釐 = 1 單位）！
