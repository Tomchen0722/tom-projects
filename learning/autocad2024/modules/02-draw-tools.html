UNIT 02 · DRAW PANEL COMMANDS

AutoCAD 2024 「繪製」面板全指令圖解

繪製 (Draw) 是所有幾何創意的起點。從一條最純粹的直線、帶有厚度的一體成型聚合線，到精密計算的圓形與正多邊形。每個指令都有步驟拆解與真實參數教學！

指令: LINE (快速鍵: L) 1. 線 (Line) —— 最基礎的兩點直達線段

🧑‍🏫 高中生白話秒懂： 直線就是兩點連成一線。畫出來的每條線都是「獨立的個體」，哪怕你畫了一個正方形，它依然是 4 根各自獨立的牙籤，點選其中一邊只會選到那一條。

🎯 操作三步驟：
1. 指令行輸入 L 後按 空白鍵。
2. 在畫面點擊滑鼠左鍵決定第一點（起點）。
3. 移開滑鼠點擊第二點（或鍵入長度數值如 50）按空白鍵。
4. 子選項技巧：在畫完幾條線後，輸入 C（Close 閉合）按空白鍵，自動連接回最初的起點形成封閉多邊形！按 U（Undo）可復原剛才畫錯的那一小段。
指令歷程: L ➜ 指定第一點: (點擊) ➜ 指定下一點: @50,0 ➜ 指定下一點: C (閉合)
指令: PLINE (快速鍵: PL) 2. 聚合線 (Polyline) —— 一筆畫到底的「電路走線神器」

🧑‍🏫 高中生白話秒懂： 聚合線就像用奇異筆一筆畫到底！雖然中間轉了幾十個彎，甚至混雜了直角與弧線，但整條線是連為一體的「單一物件」。最猛的是：它可以設定線寬（Width）！因此繪製 PCB 印刷電路板的「銅箔走線」100% 必須使用 PLINE！

🎯 核心特異功能：設定線寬 (Width)
在點了起點之後，指令行會提示 [圓弧(A)/半寬(H)/長度(L)/退回(U)/寬度(W)]：
• 鍵入 W 按空白鍵 ➜ 起始寬度輸入 1.0 ➜ 終止寬度輸入 1.0 ➜ 馬上畫出寬度為 1mm 的實體粗走線！
• 若起始寬度設 2.0，終止寬度設 0，就能一筆畫出漂亮的實心箭頭！
指令歷程: PL ➜ 指定起點 ➜ W ➜ 起始寬度: 1.0 ➜ 終止寬度: 1.0 ➜ 指定下一點
指令: CIRCLE (快速鍵: C) 3. 圓 (Circle) —— 螺栓孔與焊盤的基石

🧑‍🏫 高中生白話秒懂： 圓規畫圓！AutoCAD 預設是「給圓心、給半徑 (Radius)」，但工廠圖面通常標註「直徑 (Diameter, 符號 Ø)」，新手常常誤把直徑當半徑輸入，導致畫出來的孔大了一倍！

方法 A：圓心 + 半徑 (預設)
輸入 C ➜ 點選圓心 ➜ 輸入半徑值（例如 M3 螺絲孔半徑 1.6）按空白鍵。
方法 B：圓心 + 直徑 (D)
輸入 C ➜ 點選圓心 ➜ 鍵入 D 按空白鍵 ➜ 輸入直徑值 3.2 按空白鍵。
💡 考前秒殺子選項：
• 2P (兩點圓)：點選直徑的兩個端點決定圓（適合畫卡在兩條平行線中間的切圓）。
• TTR (相切、相切、半徑)：點選兩條邊線並給定半徑，電腦自動算出同時與兩條線相切的圓！
指令: RECTANG (快速鍵: REC) 4. 矩形 (Rectangle) —— 外框與晶片包裝必備

🧑‍🏫 高中生白話秒懂： 只要指定「左下角」和「右上角」兩個對角頂點，電腦立刻畫出封閉的長方形（本質也是一條封閉聚合線）。

🎯 精確給定長寬：相對座標 @寬,高
1. 輸入 REC 按空白鍵。
2. 點選左下角起點。
3. 輸入 @50,35 按空白鍵 ➜ 立刻生成長 50mm、寬 35mm 的標準 PCB 電路板外框！
4. 帶圓角的矩形：在點起點前，先鍵入 F ➜ 輸入圓角半徑 3.0 ➜ 再點起點畫框，四個角自動打磨成光滑圓弧！
指令歷程: REC ➜ F ➜ 圓角半徑: 3 ➜ 指定第一點: 0,0 ➜ 指定對角點: @50,35
指令: DONUT (快速鍵: DO) 5. 圓環 (Donut) —— 電路板實心焊點與盲孔神技

🧑‍🏫 高中生白話秒懂： 就像甜甜圈！中間是一個穿透的空心孔，外面是一圈實心填滿的銅箔。如果你把「內徑設為 0」，它就會變成一顆實心黑圓點（用來畫電路原理圖中導線相交連接的 Junction 節點！）。

🎯 繪製 PCB 貫孔焊盤參數：
• 內徑 (鑽孔穿腳孔徑)：0.9 mm
• 外徑 (銅箔外焊環徑)：2.0 mm
• 輸入完成後，滑鼠點到哪裡，實心銅箔焊盤就蓋到哪裡，連續蓋印章！
指令歷程: DO ➜ 內徑: 0.9 ➜ 外徑: 2.0 ➜ 點選焊盤中心座標
指令: HATCH (快速鍵: H) 6. 填充線 (Hatch) —— 剖面線與銅箔鋪銅 (Copper Pour)

🧑‍🏫 高中生白話秒懂： 油漆桶工具！在任何封閉的封閉區域內，灌入斜線紋理（如機械零件剖面線 ANSI31）或純色色塊（SOLID）。在電路板上，通常用來給大面積地線「鋪銅 (Ground Copper Pour)」，增強電路抗干擾能力。

⚠️ 新手常見地雷（無法填充）：
填充線的邊界必須是完全封閉的幾何區域！只要線條之間有哪怕 0.001mm 的小缺口，油漆就會漏出去，AutoCAD 會跳出紅色圓圈警示「找不到有效的封閉邊界」！解決方法：使用 FILLET（圓角 R=0）把線頭接合。
指令: POLYGON (快速鍵: POL) 7. 正多邊形 (Polygon) —— 螺帽六角形與接地符號

🧑‍🏫 高中幾何考點：內接於圓 (Inscribed) vs 外切於圓 (Circumscribed)

輸入邊數（如六角螺帽輸入 6，接地倒三角形輸入 3）➜ 指定中心點 ➜ 選擇：
• I (內接於圓)：多邊形的各個「頂點」剛好碰在假想圓的圓周上（邊在圓內）。
• C (外切於圓)：多邊形的各個「邊的中點」剛好碰在假想圓的圓周上（邊在圓外）。
