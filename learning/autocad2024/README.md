## 第一篇：對照真實畫面！軟體介面完整大解密

當您第一次啟動 AutoCAD 2024 繁體中文版時，畫面可以清晰劃分為五個主要區域：

`
┌────────────────────────────────────────────────────────┐
│ ① 頂部快速工具列 + 功能區標籤 (常用/插入/註解...)        │
├────────┬───────────────────────────────────┬───────────┤
│        │                                   │           │
│ ② 左側 │ ③ 中央大畫布 (黑色繪圖區)          │ 右上角     │
│ 「圖紙 │    十字游標 + 坐標軸 (X-Y)        │ 視圖方塊   │
│   集管 │                                   │ 與導覽列  │
│   理員」│                                   │           │
│ (建議關)│                                   │           │
├────────┴───────────────────────────────────┴───────────┤
│ ④ 指令列 (最重要！顯示「鍵入指令」，AutoCAD 的大腦)      │
├────────────────────────────────────────────────────────┤
│ ⑤ 底部狀態列 (模型/配置、正交、物件鎖點等輔助開關)         │
└────────────────────────────────────────────────────────┘
`

### 1.1 頂部：功能區標籤與常用面板（Ribbon）
* **大紅「A」圖標**：點擊它可以開新檔案、開啟舊檔、儲存、匯出與列印。
* **快速存取工具列**：在紅色 A 旁邊，包含存檔（磁碟片圖示）、復原（左彎箭頭 Ctrl+Z）、重做（右彎箭頭 Ctrl+Y）。
* **功能區標籤**：有「常用」、「插入」、「註解」、「參數式」、「檢視」、「管理」等。
  * **新手守則**：剛開始學習時，**90% 的時間只需要待在「常用」標籤**，裡面已經包含了所有最常用的指令。
* **三大核心面板**（位於「常用」標籤下）：
  1. **繪製面板**：用來無中生有建立物件，包含線條、聚合線、圓、弧、矩形、多邊形、填充線。
  2. **修改面板**：用來修改調整畫好的圖案，包含移動、複製、旋轉、修剪、延伸、圓角、陣列、鏡射。
  3. **圖層面板**：如同透明描圖紙，用來將牆壁、家具、標註尺寸分色分類管理。

### 1.2 左側：圖紙集管理員（建議新手先關閉！）
* **現狀問題**：很多新手一打開畫面，左側有一大塊深灰色面板寫著「圖紙集管理員」，霸佔了快 1/4 的繪圖空間，讓畫布變得很窄。
* **新手處理方式**：
  * 這是在大型專案管理成百上千張圖紙才用得到的進階功能。
  * **請直接點該面板標題列的「X」按鈕**，或者按下鍵盤快捷鍵 Ctrl + 4 即可關閉它！
  * 關閉後，黑色繪圖畫布瞬間變得開闊舒適。

### 1.3 中央：黑色繪圖畫布
* **十字游標（Crosshairs）**：
  * 當游標在黑色畫布上移動時，呈現十字交叉形狀，中央有個小正方形稱為「十字靶」。
  * 當十字游標處於正常十字狀態時，代表 AutoCAD 處於「待命狀態」，隨時可以接受點擊或輸入指令。
* **左下角 X-Y 軸（UCS 圖示）**：
  * 標示 X 軸（水平左右）與 Y 軸（垂直上下）的正方向。原點 (0,0) 是整個 CAD 空間的坐標起點。
* **右上角 ViewCube（視圖方塊）與導覽列**：
  * 顯示「北、東、南、西」與「上」的立方體。在 2D 平面繪圖中，保持看著「上」即可。
  * **切記**：不要隨意用滑鼠拖動它旋轉，否則畫面會變成 3D 透視，導致 2D 線條變斜！

### 1.4 下方：指令列（Command Line，新手最容易忽略的心臟）
* 畫面上有一條長條框，寫著灰白色的 **「鍵入指令」**。
* **AutoCAD 最根本的操作哲學**：
  * 您不是「單純用滑鼠畫畫」，而是「透過指令列與軟體對話」！
  * 舉例：當您輸入 L（直線）按空白鍵後，眼睛一定要看指令列，它會問：指定第一點:。
  * 當您用滑鼠點了第一點，它又會提示：指定下一點或 [退回(U)]:。
  * **只要養成「每點一下滑鼠，就看一下指令列問什麼」的習慣，自學就不可能迷路！**

### 1.5 底部：狀態列開關（右下角的實用輔助燈）
狀態列按鈕呈現**亮藍色表示「開啟」**，**灰色表示「關閉」**：
1. **顯示圖面格線（快捷鍵 F7）**：畫布上的方格底紋。
2. **正交模式（直角符號，快捷鍵 F8）**：**極度重要！** 開啟後，滑鼠游標強制只能朝向水平 0°/180° 或垂直 90°/270° 畫直線，保證線條絕不畫歪。
3. **極座標追蹤（帶角度圓圈，快捷鍵 F10）**：開啟時，滑鼠移到 30°、45°、60° 等特殊角度時會跳出虛線引導對齊。
4. **物件鎖點（方形與端點符號，快捷鍵 F3）**：**絕對必開！** 靠近線條時自動吸附「端點」、「中心點」、「中點」、「交點」，確保幾何嚴格封閉。
5. **動態輸入（快捷鍵 F12）**：讓數值輸入框直接跟隨游標顯示在畫布上，直觀方便。

## 第二篇：初學者必備的 4 大滑鼠與鍵盤肌肉記憶

| 操作動作 | 操作方式 | 核心功用與口訣 |
| :--- | :--- | :--- |
| **滾輪前推 / 後拉** | 滾動滑鼠中鍵 | **視角放大 / 縮小**：以游標所在位置為焦點進行縮放。 |
| **按住滾輪拖曳** | 按下中鍵不放（出現小手掌） | **平移畫面 (Pan)**：在畫布上遊走，移動視角而不改變圖形坐標。 |
| **滑鼠滾輪快按兩下** | 連續快速雙擊滾輪 | **全部顯示 (Zoom Extents)**：新手救命大招！如果畫著畫著找不到圖案在哪裡，快雙擊滾輪，畫過的所有圖形瞬間充滿整個螢幕！ |
| **ESC 鍵（連按 2 次）** | 鍵盤左上角 Esc | **重設取消鍵**：只要操作卡住、想中途放棄、選錯東西，連按兩次 ESC 立即回到乾淨待命狀態。 |
| **空白鍵 (Spacebar)** | 按一下長條空白鍵 | **等於 Enter 確認鍵**：在 AutoCAD 裡空白鍵 = Enter。右手滑鼠、左手大拇指按空白鍵，是專業繪圖最高效率姿勢！ |
| **選取方式區別** | 滑鼠左鍵拉框選取 | **由左向右拉（藍色框）**：必須「完全包覆」物件才會被選取。<br>**由右向左拉（綠色框）**：只要「碰到任何一點邊緣」就會被選取。 |

## 第三篇：20 個實用詳細解說範例（由淺入深、逐步教學）

### 【階段一：基本幾何與精準尺寸控制】

#### 範例 1：繪製長度剛好 100mm 的水平基準線
* **目標**：掌握直線指令、正交鎖定與精確長度輸入。
* **指令**：L（LINE 直線）
* **跟著做**：
  1. 連按兩次 ESC 回到待命狀態。
  2. 按鍵盤 F8，確認開啟「正交模式」。
  3. 鍵盤輸入 L，按 **空白鍵**。
  4. 滑鼠在畫布中央任意點一下左鍵（決定線條起點）。
  5. 將滑鼠游標朝向「右方」平拉（不必按住按鍵，拉出水平方向即可）。
  6. 直接鍵盤輸入數字 100，按 **空白鍵**。
  7. 按一下 ESC 結束指令。
  * **成果檢視**：畫布上出現了一條精準 100mm 的水平直線！

---

#### 範例 2：繪製 150 × 100 mm 的精密長方形（標準圖框）
* **目標**：學會矩形指令與 @寬,高 相對坐標輸入法。
* **指令**：REC（RECTANG 矩形）
* **跟著做**：
  1. 按 ESC，輸入 REC，按 **空白鍵**。
  2. 滑鼠左鍵在畫面任意點一下（指定矩形的第一個角點）。
  3. 鍵盤輸入 @150,100（英文半形 @，寬度 150，英文半形逗點 ,，高度 100）。
  4. 按 **空白鍵** 完成。
  * **成果檢視**：畫布上生成了一個寬 150、高 100 的完整封閉長方形。

---

#### 範例 3：繪製直徑 60mm 的圓形（軸承端蓋基座）
* **目標**：理解畫圓指令中「半徑」與「直徑」的切換邏輯。
* **指令**：C（CIRCLE 圓）
* **跟著做**：
  1. 按 ESC，輸入 C，按 **空白鍵**。
  2. 滑鼠左鍵在畫布上點一下（決定圓心位置）。
  3. 注意指令列提示：預設為指定半徑。若要輸入直徑，鍵盤輸入 D 並按 **空白鍵**。
  4. 輸入直徑數值 60，按 **空白鍵**。
  * **成果檢視**：畫出了一個外徑剛好 60mm 的標準圓形。

---

#### 範例 4：繪製同心雙層圓環（物件鎖點圓心）
* **目標**：掌握物件鎖點（F3），精確捕捉圓心。
* **指令**：C + 物件鎖點
* **跟著做**：
  1. 確保鍵盤 F3 開啟（物件鎖點開啟）。
  2. 輸入 C，按 **空白鍵**。
  3. 把滑鼠游標移到範例 3 的圓周邊界上晃一下，圓心位置會自動亮起一個綠色小圓圈標記。
  4. 將滑鼠移到該綠色圓心點一下左鍵（精準捕捉圓心）。
  5. 鍵盤輸入 D 按空白鍵，再輸入直徑數值 30 按空白鍵。
  * **成果檢視**：兩圓共用同一圓心，形成漂亮的法蘭環或機械墊圈外觀。

---

#### 範例 5：繪製帶有 45 度傾角的支架斜線（極座標角度輸入）
* **目標**：學會使用 @長度<角度 輸入任意方向斜線。
* **指令**：L（配合極座標語法）
* **跟著做**：
  1. 按 F8 關閉正交模式（或按 F10 開啟極座標）。
  2. 輸入 L，按 **空白鍵**。
  3. 在畫布上點選起點。
  4. 鍵盤輸入 @80<45（表示長度 80，小於符號 < 代表角度，朝向 45 度方向）。
  5. 按 **空白鍵**，再按 ESC 結束。
  * **成果檢視**：精確畫出一條仰角 45°、長度 80mm 的幾何斜線。

### 【階段二：修改與編輯工具神器】

#### 範例 6：向內等距複製 10mm 框線（OFFSET 偏移指令）
* **目標**：學會工程製圖中使用率第一名的「偏移」指令，做雙線或邊界框。
* **指令**：O（OFFSET 偏移）
* **跟著做**：
  1. 畫面上準備好一個矩形（如範例 2）。
  2. 輸入 O，按 **空白鍵**。
  3. 指令列提示「指定偏移距離」：輸入 10，按 **空白鍵**。
  4. 滑鼠左鍵點擊外圍的長方形。
  5. 將滑鼠游標移到長方形的「內側」，點一下左鍵。
  6. 按 ESC 結束指令。
  * **成果檢視**：原本的長方形內部多出一個完全平行且等距 10mm 的內框。

---

#### 範例 7：修剪十字交會處伸出的多餘線頭（TRIM 修剪指令）
* **目標**：清除所有多餘殘線，保持圖面俐落工整。
* **指令**：TR（TRIM 修剪）
* **跟著做**：
  1. 用 L 指令隨意畫兩條互相穿透垂直交叉的線。
  2. 輸入 TR，按 **空白鍵**。
  3. 在 AutoCAD 2024 中，滑鼠直接移到你想刪掉的那段凸出線條上。
  4. 線條會預覽變淡變灰，點擊滑鼠左鍵，該線段立即被截斷剪除！
  5. 修剪完畢後按 ESC 離開。

---

#### 範例 8：將矩形銳角倒成 R15 平滑圓角（FILLET 圓角指令）
* **目標**：消除機械與建築邊角的銳利直角。
* **指令**：F（FILLET 圓角）
* **跟著做**：
  1. 輸入 F，按 **空白鍵**。
  2. 指令列問設定：輸入 R（設定半徑 Radius），按 **空白鍵**。
  3. 輸入半徑值 15，按 **空白鍵**。
  4. 滑鼠左鍵點擊矩形的垂直邊，接著點擊相鄰的水平邊。
  * **成果檢視**：原本 90 度的尖角瞬間平滑轉化為半徑 15mm 的弧形倒角。

---

#### 範例 9：繪製對稱花瓶或紅酒杯外形（MIRROR 鏡射指令）
* **目標**：只畫一半的圖形，透過鏡射對稱完成全圖，效率翻倍。
* **指令**：MI（MIRROR 鏡射）
* **跟著做**：
  1. 在畫布左側用線條畫出半邊花瓶輪廓，右側畫一條筆直的垂直線當「中心對稱軸」。
  2. 輸入 MI，按 **空白鍵**。
  3. 用滑鼠由右向左拉綠色選取框，選中左半邊所有花瓶線條，按 **空白鍵**。
  4. 滑鼠左鍵點擊垂直對稱軸的「頂端點」，再點擊對稱軸的「底端點」。
  5. 指令列問：「是否刪除來源物件？[是(Y)/否(N)]」：直接按 **空白鍵**（預設為 N）。
  * **成果檢視**：右側立刻誕生完全 100% 精準對稱的另一半花瓶！

---

#### 範例 10：圓桌周圍均勻擺放 6 張椅子（ARRAY 環形陣列）
* **目標**：掌握圓周等角度快速分佈物件。
* **指令**：AR（ARRAY 陣列）
* **跟著做**：
  1. 用 C 指令畫一個半徑 200 的大圓（圓桌），並在大圓正上方畫一個半徑 30 的小圓（椅子）。
  2. 輸入 AR，按 **空白鍵**。
  3. 點選小圓（椅子），按 **空白鍵**。
  4. 指令列選擇陣列類型：輸入 PO（環形 Polar），按 **空白鍵**。
  5. 滑鼠點擊大圓的「圓心」。
  6. 頂部功能區會跳出「陣列建立」面版，在「項目(Items)」欄位輸入 6，按 Enter。
  7. 點選面板最右側綠色打勾「關閉陣列」。
  * **成果檢視**：6 張椅子完美、均勻地沿著圓桌排列成環狀！

### 【階段三：建築室內與工程繪圖實戰】

#### 範例 11：繪製 5m × 4m 房間與 15cm 厚度雙線外牆
* **目標**：學會建築空間放樣、雙線牆體建立與打散編輯。
* **指令**：REC + O + X（EXPLODE 分解）
* **跟著做**：
  1. 輸入 REC 按空白鍵，點擊第一點，輸入 @5000,4000 按空白鍵（公釐為單位，5米乘4米）。
  2. 輸入 O 按空白鍵，輸入牆厚 150 按空白鍵。
  3. 點擊矩形外框，游標移到內側點一下左鍵。
  4. 按 ESC。此時兩個矩形各自是一整條封閉線，無法單獨開門修剪。
  5. 鍵盤輸入 X（分解 EXPLODE），按空白鍵。
  6. 框選這兩個矩形，按 **空白鍵**。
  * **成果檢視**：雙線牆體分解為 8 條獨立線段，隨時可以用修剪指令開門開窗！

#### 範例 20：將繪製完成的圖面輸出為高解析度 A4 PDF 圖檔
* **目標**：從模型空間精確出圖，發送給客戶或施工人員列印。
* **指令**：Ctrl + P 或 PLOT（出圖列印）
* **跟著做**：
  1. 按下鍵盤 Ctrl + P，開啟「出圖 - 模型」對話視窗。
  2. **印表機 / 繪圖機**：名稱下拉選單選擇 AutoCAD PDF (General Documentation).pc3。
  3. **圖紙大小**：下拉選擇 ISO full bleed A4 (297.00 x 210.00 公釐)。
  4. **出圖區域**：在「出圖內容」下拉選擇 視窗(W)。
     - 此時視窗會自動隱藏並跳回畫布，請按住滑鼠左鍵拉出一個框，把要列印的所有圖形完整框起來！
  5. **出圖偏移**：勾選「置中出圖」。
  6. **出圖比例**：初學者建議先勾選「布滿圖紙」（進階可自訂 1:50 或 1:100）。
  7. **預覽確認**：點擊左下角「預覽(P)」按鈕，檢視畫面是否清晰置中。
  8. 確認無誤後，在預覽畫面上按滑鼠右鍵選「出圖(P)」，選擇存檔路徑即可生成漂亮的 PDF 圖檔！

## 第四篇：零基礎自學成功地圖與常見卡關解答

### 新手自學必勝三字訣
1. **看**：每做一步動作，眼睛先看指令列的提示。
2. **對**：養成隨時用 F3 物件鎖點捕捉端點與圓心，嚴禁憑肉眼感覺靠上去。
3. **退**：只要發現圖畫歪了或指令按錯，連按兩次 ESC，然後按 Ctrl + Z 復原。

### 常見卡關與除錯錦囊
* **Q1：我畫的線條怎麼不見了？螢幕上一片黑！**
  * **解答**：快速連續雙擊滑鼠中鍵（滾輪），AutoCAD 會立刻執行「全部顯示 (Zoom Extents)」，把所有你畫過的東西自動拉回畫面正中央。
* **Q2：為什麼我輸入數字後，線條長度完全不對？**
  * **解答**：請確認輸入法處於「英文半形」狀態。若輸入了全形數字或全形逗號（如 @１５０，１００），CAD 會無法解析。
* **Q3：我想剪掉線條，為什麼 TRIM 剪不掉？**
  * **解答**：TRIM 只剪得掉「有交叉交點」的多餘線段。如果是一條獨立沒有與任何線相交的線，不能用剪的，請直接點選它並按鍵盤 Delete 刪除！
