💾 VRAM
GPU 的工作桌大小

VRAM 是 AI 應用中最常被卡住的硬體限制。這篇讓你搞懂它是什麼、需要多少、不夠怎麼辦。

🪑 VRAM 是什麼

VRAM（Video RAM，視訊記憶體）是 GPU 自己專用的記憶體，獨立於電腦的主記憶體（RAM）之外。

💡 最重要的比喻

VRAM = GPU 的工作桌

你要做一個大型拼圖（AI 模型），必須把它攤開在桌上才能操作。
桌子（VRAM）太小 → 拼圖放不下 → 工作進行不了。
桌子夠大 → 同時可以放多個拼圖 → 工作更有效率。

關鍵：AI 模型執行時，必須完整放入 VRAM，放不下就報錯。

CUDA out of memory. Tried to allocate 2.00 GiB but only 1.50 GiB of VRAM is free.

這個錯誤就是 VRAM 不夠的症狀——你跑 AI 時最常遇到的錯誤。

🧮 AI 模型需要多少 VRAM？

最常見的問題：「我的 GPU 能跑這個模型嗎？」有一個粗略的速算公式：

FP16 / BF16（半精度）參數數 × 2 Bytes
INT8（量化）參數數 × 1 Byte
INT4（強力量化）參數數 × 0.5 Bytes

⚠️ 以上是純推理的最低需求。訓練時還需要存梯度、優化器狀態，VRAM 需求會是推理的 4–8 倍。

🔧 VRAM 不夠怎麼辦？4 種解法

① 量化（Quantization）

把模型權重從 FP16（16位元）降到 INT8 或 INT4，大小直接縮小 2–4 倍，VRAM 需求大幅降低。

代價：精度略有損失，但 INT8 影響通常很小。工具：llama.cpp、GPTQ、AWQ。

② 分頁推理（Paged Attention）

把模型的一部分暫時存到主記憶體（RAM），需要時才搬回 VRAM。速度會變慢但可以跑大模型。

代價：速度下降，因為 CPU↔GPU 資料傳輸是瓶頸。

③ 多 GPU

把模型拆成幾份，分散到多張 GPU 的 VRAM 上。2 張 RTX 4090 = 48GB VRAM。

代價：成本翻倍，需要 GPU 間通訊（NVLink 或 PCIe）。

④ 換小模型

用 7B 代替 70B。現代的 7B 模型（經過微調）往往比舊的 70B 更實用。

代價：能力上限較低，但對大多數應用已足夠。

💡 實務建議

一般個人用途先試量化（INT4 / INT8），通常品質足夠，VRAM 需求砍半。Ollama 預設就幫你做量化了。

💡 VRAM vs RAM：有什麼不同？

VRAM（GPU 記憶體）RAM（主記憶體）
誰使用GPU 核心CPU + 系統
速度超快（1,000 GB/s+）較慢（50–100 GB/s）
容量小（8–141 GB）大（16 GB–數 TB）
AI 模型能放嗎✅ 可以，這是正常路徑⚠️ 可以，但跑起來極慢
價格（每 GB）高（GDDR6X / HBM3）低（DDR5）
重要：模型放在 RAM 跑有多慢？
  • GPU VRAM 頻寬：~1,000 GB/s
  • CPU RAM 頻寬：~80 GB/s
  • 速度差約 12 倍——實際體感更差，因為 CPU 核心數也少
  • 結論：能用 GPU 就別用 CPU 跑模型

✅ 本章重點整理

  • VRAM = GPU 專屬記憶體，AI 模型必須完整放入
  • 速算：7B 模型 FP16 需約 14GB VRAM，INT4 量化約 4GB
  • VRAM 不夠時：量化 → 最優先，成本低品質損失小
  • 訓練比推理需要更多 VRAM（約 4–8 倍）
  • VRAM 比 RAM 快約 12 倍，能放 GPU 就別用 CPU
  • H100 有 80GB HBM3，比 RTX 4090 的 24GB GDDR6X 多 3 倍還快得多
