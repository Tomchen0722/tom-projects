🌐 為什麼要用雲端 GPU？

💡 雲端 GPU 的本質

雲端 GPU = 租用別人的電腦跑你的 AI，按小時計費。

優點：不用買硬體、可以隨時升級到最強的 GPU、不需要機房和散熱。
缺點：長期用比買貴、資料在別人的伺服器、網路傳輸有成本。

大多數 AI 公司的選擇是：開發和測試用雲端，大規模訓練視情況買或租，推理服務視流量決定。

🚨 帳單地雷：AWS 按需 H100 跑一整個月 = ~$64,000 美元。一定要設 billing alert，避免忘記關機導致帳單爆炸。真實案例：有人跑 GPU 忘關，一週帳單 $50,000。

⚡ 三種定價方式：按需 vs 預留 vs Spot

🔴 按需（On-Demand）

100%

隨時啟動，隨時停止。靈活但最貴。適合：短期測試、不確定用量時。

🟢 預留（Reserved）

~40–60%

預付 1–3 年，折扣高達 40–60%。適合：長期穩定需求，預算可預測。

🟣 Spot / Preemptible

~10–30%

用閒置資源，最便宜但可能被強制終止。適合：可中斷的訓練，要存 checkpoint。

💡 比喻

按需 = 便利商店（隨買隨用，貴）
預留 = 年費健身房（先付一年，每次便宜）
Spot = 搶便宜機票（超便宜但可能被取消，要有備案）

🛡️ 避免帳單爆炸的 10 個技巧

  • 設定 Billing Alert（AWS Budget Alarm），超過 $50 就發 Email 通知
  • 訓練完立刻停止實例，不要讓 GPU 閒置（閒置也在計費）
  • 用 Spot/Preemptible 實例，省 70–90%，訓練時每小時存一次 checkpoint
  • 測試階段用最小的 GPU（T4/A10G），確認程式沒問題再換大 GPU
  • 預估費用：在本地跑 1 個 batch，計算一個 epoch 要多久，再算總時間 × 時薪
  • 不要把資料集放在 GPU 實例的本地磁碟——實例刪掉就沒了，用 S3/GCS
  • 多人共用帳號時，每個人的實例要加 tag，知道誰在用什麼
  • Lambda Labs 和 CoreWeave 通常比 AWS/GCP 便宜 30–50%
  • 個人實驗：Vast.ai 或 RunPod 是最便宜的選擇，不需要企業合規
  • AWS 的 data transfer 費用：資料從 AWS 傳出是要收費的，大資料集注意

✅ 本章重點整理

  • 雲端 GPU 按小時計費，從 $0.35（RTX 4090）到 $32+（8×A100）
  • Spot 實例最便宜（省 70–90%），但可能被強制終止，要存 checkpoint
  • 微調 7B 模型約 US$30–50；從頭訓練大模型 = 數十萬美元
  • Lambda Labs / RunPod 通常比 AWS/GCP 便宜 30–50%
  • 個人實驗：Vast.ai 最便宜；企業合規需求：AWS / GCP
  • 務必設 Billing Alert，否則忘記關機帳單可能爆炸
