🗂️ GPU 的三個等級

💡 先搞清楚定位

消費型 GPU（RTX 系列）= 家用車，拿來跑本地 AI、遊戲、日常工作都 OK。

工作站 GPU（RTX 6000 Ada 等）= 商務 SUV，VRAM 更大，穩定性更高，企業小規模用。

資料中心 GPU（H100、A100）= 大型貨車，只為吞吐量而生，不接螢幕，跑在伺服器機架裡。

💡 AMD 現況

MI300X 的 192GB VRAM 是目前最大的單卡 VRAM，微軟 Azure 和部分雲端平台已採用。但 CUDA 生態優勢讓 NVIDIA 依然是企業 AI 的首選。

🧭 選購決策指南

根據你的需求選 GPU

❓ 你要做什麼？訓練模型還是推理（使用）？
✅ 只是推理（跑現成模型）→ 繼續往下
🔴 要訓練大模型 → 雲端 H100（別自買，太貴）
❓ 預算多少？
✅ 5 萬以內 → RTX 4090（最多 VRAM 的消費型 GPU）
✅ 3 萬以內 → RTX 4080 Super（16GB，跑 13B 沒問題）
✅ 1 萬以內 → RTX 4060 + 量化模型（8GB 搭配 INT4）
❓ 要跑多大的模型？
✅ 7B → 8GB VRAM 就夠（INT4 量化）
✅ 13B → 12–16GB VRAM（INT4/INT8）
✅ 70B → 24GB VRAM INT4，或 2 張 GPU
🔴 70B FP16 以上 → 需要 A100 / H100 或多卡

✅ 本章重點整理

  • 個人 AI 推理：RTX 4090（24GB）是消費型頂配
  • 企業 AI 訓練：H100（80GB HBM3）是 2025 年現在的主流
  • 預算有限：RTX 4060 + 量化模型，能跑 7B LLM
  • H100 比 RTX 4090 貴 15 倍，但算力快 1.5 倍、頻寬快 3.3 倍
  • AMD MI300X 192GB VRAM 是單卡最大，但生態不如 NVIDIA
  • 選 GPU 先確認：推理或訓練、VRAM 需求、預算
