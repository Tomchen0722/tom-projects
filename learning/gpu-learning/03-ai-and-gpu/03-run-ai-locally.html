🚀 在自己電腦
跑 AI 模型

實戰教學：用 Ollama 跑本地 LLM、用 Stable Diffusion 生圖。最低門檻是什麼？

🖥️ 硬體需求一覽

用途最低 GPU VRAM建議 VRAMCPU 也能跑？
LLM 7B（量化）4 GB8 GB+可以（極慢）
LLM 13B（量化）8 GB12 GB+不建議
LLM 70B（量化）24 GB48 GB+（多卡）無法
Stable Diffusion 1.54 GB8 GB可以（慢）
SDXL / Flux8 GB12–16 GB不建議
語音辨識（Whisper）2 GB4 GB可以
💡 沒有 NVIDIA GPU 怎麼辦

Apple Silicon（M1/M2/M3/M4）：用統一記憶體，可以共享 RAM，跑 LLM 效果不錯。Ollama 完整支援。

AMD GPU：Ollama 和 Stable Diffusion 有支援，但部分模型有 bug。

只有 CPU：llama.cpp 可以跑，但 7B 模型一秒只輸出 1–2 個 token，比打字還慢。

🛠️ 四大工具選擇

🦙

Ollama

最簡單的本地 LLM 工具。一行指令安裝模型並開始對話。支援 Windows / Mac / Linux。

最容易入門
🎨

Stable Diffusion WebUI

本地跑圖像生成 AI，有完整的 Web 介面。AUTOMATIC1111 版本最多人用。

需安裝 Python
🤖

LM Studio

圖形介面的本地 LLM，可以瀏覽、下載、運行模型。適合不想打指令的用戶。

GUI 操作
💬

Open WebUI

搭配 Ollama 使用的 ChatGPT 風格介面，可以在瀏覽器像用 ChatGPT 一樣使用本地模型。

需 Docker 或 npm

🦙 Ollama 快速上手（10 分鐘）

1

安裝 Ollama

到 ollama.com 下載並安裝（Windows / Mac / Linux 都有）。安裝後背景自動啟動服務。

2

下載並執行模型

# 下載並直接啟動對話（自動量化） ollama run llama3 # 下載其他模型（更小、更快） ollama run phi3 ollama run gemma2 ollama run qwen2.5 # 查看已下載的模型 ollama list
3

開始對話

執行 ollama run llama3 後，終端機出現 >>> 提示符，直接輸入問題按 Enter 就能對話。輸入 /bye 結束。

4

（選用）用 API 呼叫

# Ollama 預設在 port 11434 提供 API curl http://localhost:11434/api/generate \ -d '{"model":"llama3","prompt":"台灣最高的山是什麼"}' # Python 使用 import ollama response = ollama.chat(model='llama3', messages=[ {'role': 'user', 'content': '台灣最高的山是什麼'} ])

💡 模型下載很大：LLaMA 3 8B 約 4.7 GB，70B 約 40 GB。確保有足夠硬碟空間和穩定網路。

⚖️ 量化等級選哪個

Ollama 模型名稱後面可以加標籤選量化等級：

llama3:8b 的各量化版本（模型大小 vs 品質）

fp16
~16 GB 最佳品質
q8_0
~8 GB 幾乎無損
q6_K
~6 GB 輕微損失
q4_K_M
~4.7 GB 建議預設
q2_K
~2.9 GB 品質明顯下降
# 指定量化版本 ollama run llama3:8b-q4_K_M # 建議：4.7GB，品質/大小最平衡 ollama run llama3:8b-q8_0 # 高品質：8GB，幾乎無損

🎨 Stable Diffusion 生圖（簡介）

比 Ollama 複雜一點，但有完整的圖形介面。推薦兩種方案：

🖼️

ComfyUI（推薦）

節點式工作流，最靈活。社群活躍，有大量工作流可以直接下載使用。

git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI
pip install -r requirements.txt
python main.py
🎛️

AUTOMATIC1111 WebUI

傳統 SD WebUI，功能最齊全，上手稍難但文件超多。

git clone https://github.com/
AUTOMATIC1111/stable-diffusion-webui
cd stable-diffusion-webui
./webui.sh # Mac/Linux

⚠️ Stable Diffusion 環境設定較複雜，需要 Python 3.10、git、安裝 CUDA toolkit。遇到問題先 Google 錯誤訊息，通常都有解。

✅ 本章重點整理

  • 跑 7B LLM：最低 4GB VRAM（INT4 量化），建議 8GB
  • Ollama = 最快上手，一行指令就能跑本地 LLM
  • 量化 q4_K_M 是品質/大小最佳平衡點
  • Apple M 系列晶片用統一記憶體，跑 Ollama 效果也不錯
  • 圖像生成：ComfyUI 最靈活，AUTOMATIC1111 功能最多
  • CPU 可以跑但極慢，有 GPU 就用 GPU
