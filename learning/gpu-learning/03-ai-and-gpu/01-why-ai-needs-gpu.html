🧠 為什麼 AI 訓練
非 GPU 不可

神經網路的本質是大量矩陣乘法。GPU 就是為矩陣而生。這兩者的相遇，改變了 AI 的速度。

📐 神經網路的本質：矩陣乘法

深度學習聽起來很神秘，但數學上它就是一件事：矩陣乘以矩陣，重複幾億次。

每一層神經網路的計算，都是「輸入矩陣 × 權重矩陣 = 輸出矩陣」：

💡 比喻

矩陣乘法 = 填一個超大的 Excel 試算表，每個格子 = 上面一排數字 × 左邊一列數字的乘積總和。

GPU 可以同時計算試算表的所有格子；CPU 一格一格填。

🔄 訓練 vs 推理：兩個不同的 GPU 任務

項目 訓練（Training） 推理（Inference）
做什麼調整模型權重用已訓練的模型生成答案
計算量超大（前向+反向傳播）較小（只有前向）
VRAM 需求很大（儲存梯度）較小
時間數小時到數週毫秒到秒
誰在做AI 公司、研究機構終端用戶（你用 ChatGPT）
GPU 需求最強 GPU 叢集單張 GPU 就夠

你在自己電腦「跑 AI 模型」，做的是推理，不是訓練。訓練 GPT-4 的成本超過 1 億美元。

⏱️ GPU vs CPU 在 AI 上的速度差距

~1 個月

用 CPU 從頭訓練 GPT-2（小模型）

~1 天

用 8 張 A100 訓練同樣的 GPT-2

720×

GPU 比 CPU 快的倍數（同等算力）

為什麼差這麼多？
  • CPU：4–64 核心，序列處理矩陣行 × 列
  • GPU：16,000+ 核心，同時算矩陣的所有格子
  • Tensor Core 特化：一個指令 = 完成整個 4×4 矩陣乘法
  • HBM3 記憶體頻寬：資料餵得夠快，核心不會閒置

🔁 反向傳播：為什麼訓練更耗 GPU

訓練一個 batch 的步驟
  • ① 前向傳播：算出預測答案（1× 計算量）
  • ② 計算 Loss：看預測有多錯（少量計算）
  • ③ 反向傳播：計算每個權重的梯度（2× 計算量）
  • ④ 梯度更新：調整所有權重（額外 VRAM 存梯度）
  • ⑤ 重複百萬次直到收斂

💡 你需要記住的

訓練大模型需要的 GPU 是一般人買不起的規模。但推理（使用）一個已訓練好的模型，一張消費型 GPU 就夠了。你在自己電腦跑 LLaMA，是在做推理，不是訓練。

✅ 本章重點整理

  • 神經網路 = 大量矩陣乘法，GPU 天生擅長
  • 訓練（調整權重）比推理（產生答案）耗資源約 3 倍
  • GPU 訓練 AI 比 CPU 快數百倍
  • 訓練大模型需要數千張 GPU，推理一張就夠
  • 你在自己電腦跑模型 = 推理，不是訓練
  • Tensor Core 特化矩陣乘法，是 AI 加速的核心武器
