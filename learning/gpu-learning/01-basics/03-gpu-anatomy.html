先不用背這些，接下來一個一個解釋。

🔩 五大核心組件

① CUDA Core（CUDA 核心）

GPU 最基本的運算單元，做的事就是加法、乘法這類「浮點運算」。RTX 4090 有 16,384 個。一般程式（遊戲、影像處理）主要用到它。

💡 比喻

像一個計算機：只會算數，但一次出動一萬六千個。

RTX 4090：16,384 個 CUDA Core

② Tensor Core（張量核心）

專門為 AI 設計的加速器，從 NVIDIA Volta 架構（2017）開始加入。可以一次做「矩陣 × 矩陣」的計算，比 CUDA Core 快 8–32 倍。訓練 AI 模型主要靠它。

💡 比喻

如果 CUDA Core 是一個計算機，Tensor Core 就是一台試算表機器，可以一次算整個 Excel 表格。

RTX 4090：512 個 4th-Gen Tensor Core

③ VRAM（視訊記憶體）

GPU 專屬的記憶體，AI 模型跑起來必須整個放進 VRAM。VRAM 不夠，模型放不下，就會出錯。這是選購 GPU 最關鍵的規格之一。

💡 比喻

VRAM = GPU 的工作桌大小。桌子太小，資料放不下，只能換一張更小的書來讀（量化）。

RTX 4090：24GB GDDR6X

④ 記憶體頻寬（Memory Bandwidth）

GPU 核心和 VRAM 之間，資料流通的速度。頻寬越大，GPU 「吃」資料的速度越快。現代 AI 訓練往往是頻寬瓶頸，而不是核心算力瓶頸。

💡 比喻

記憶體頻寬 = 工廠與倉庫之間的道路寬度。核心再多，如果料送不過來，也是乾等。

RTX 4090：1,008 GB/s；H100 SXM：3,350 GB/s

⑤ PCIe 介面（連接 CPU 的通道）

GPU 插在主機板的 PCIe 插槽，透過它和 CPU 溝通、傳資料。現代是 PCIe 4.0 或 5.0。速度比 VRAM 內部頻寬慢很多，所以 CPU→GPU 的資料傳輸要盡量減少。

💡 比喻

PCIe = 辦公室走廊。GPU 工廠內部有高速輸送帶（頻寬），但走廊（PCIe）相對窄，要盡量減少進出次數。

PCIe 5.0 x16：~128 GB/s 雙向

📊 VRAM 種類比較

類型用途頻寬特點
GDDR6X消費型 GPU（RTX 40 系列）~1,000 GB/s便宜、普及
GDDR7消費型 GPU（RTX 50 系列）~1,800 GB/s新一代，更快
HBM2e資料中心 GPU（A100）2,000 GB/s高頻寬，晶粒堆疊
HBM3資料中心 GPU（H100）3,350 GB/sAI 首選，貴

🔑 重要：HBM（High Bandwidth Memory）是把記憶體晶粒直接疊在 GPU 晶片旁邊，頻寬是 GDDR 的 3 倍以上，但成本也高出很多。這是 H100 比 RTX 4090 貴 10 倍的原因之一。

📐 看懂規格表的關鍵數字

規格名稱我要看它越大越好？
CUDA Cores 數一般算力指標✅ 是
Tensor TFLOPS（FP16）AI 訓練/推理速度✅ 是
VRAM 容量（GB）能跑多大的模型✅ 是
記憶體頻寬（GB/s）資料吞吐速度✅ 是
TDP（瓦特）耗電量 / 散熱需求❌ 越小越好
PCIe 版本和 CPU 的溝通速度✅ 新的好，但影響較小
AI 應用的選購優先順序
  • 1. VRAM 容量：決定你能跑的模型大小，不夠就跑不了
  • 2. Tensor TFLOPS：決定訓練速度
  • 3. 記憶體頻寬：推理速度的關鍵
  • 4. TDP / 散熱：機器能不能承受

✅ 本章重點整理

  • CUDA Core：基本運算單元，數量越多越快
  • Tensor Core：AI 專屬加速，訓練模型靠它
  • VRAM：模型必須完整放進去，容量是硬門檻
  • 記憶體頻寬：資料傳輸速度，影響推理效能
  • HBM > GDDR 在頻寬上，但貴得多（H100 vs RTX）
  • AI 選購：先看 VRAM 容量，再看 Tensor TFLOPS
