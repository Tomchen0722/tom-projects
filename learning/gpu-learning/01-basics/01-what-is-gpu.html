🎮 GPU 是什麼？
從遊戲畫面說起

理解 GPU 最好的入口，是一格格的像素。從電玩遊戲到 ChatGPT，背後都是同一塊晶片。

🖼️ 螢幕上的每一個點，都需要計算

你現在看到的螢幕，是由幾百萬個小點組成的，每個點叫做「像素（Pixel）」。一台 1920×1080 的螢幕，有 207 萬個像素。

玩 3D 遊戲時，電腦每秒要渲染 60 張畫面，也就是說每秒要計算 207萬 × 60 = 1.24 億次像素的顏色、光影、透明度⋯⋯

💡 比喻

想像一幅巨大的彩色拼圖，有 207 萬塊，每秒你要把它重新拼 60 次，每次都要重新計算每塊的顏色。這件事，CPU 一個人做不過來。

GPU 的誕生，就是為了解決這個問題：大量重複的數學運算，同時做。

📅 GPU 的歷史：從遊戲到 AI

1990 年代

早期「顯示卡」只負責把畫面輸出到螢幕，功能非常單純。

1999 年

NVIDIA 發布 GeForce 256，首度稱之為 GPU（Graphics Processing Unit），可在晶片上做 3D 幾何計算。

2006 年

NVIDIA 推出 CUDA，讓開發者第一次可以用 GPU 做「非遊戲」的計算——科學模擬、物理運算。

2012 年

AlexNet 用 GPU 訓練深度學習模型，打破 AI 競賽紀錄，開啟了 GPU×AI 的時代。

2022–今

ChatGPT 爆紅，全球搶購 GPU，NVIDIA 市值超越 Apple，成為地球上最貴的公司。

🏭 三大 GPU 廠商

🟢

NVIDIA

市場龍頭，AI 訓練首選。RTX 系列（消費型）、H100/A100（資料中心）。CUDA 生態系統最完整。

🔴

AMD

主要競爭者，RX 系列遊戲 GPU 價格實惠。AI 領域的 ROCm 生態系統仍在追趕 NVIDIA。

🔵

Intel

Arc 系列為遊戲 GPU 新進者，Gaudi 系列主打 AI 訓練。市佔率較低但持續投入。

💡 市場現況

AI 訓練市場幾乎是 NVIDIA 獨佔（~85%+）。如果你要跑 AI，幾乎預設就是買 NVIDIA。AMD 和 Intel 在追趕中。

🔤 GPU 的全名與定義

GPU = Graphics Processing Unit（圖形處理單元）

雖然名字裡有「圖形」，但現代 GPU 早就超越了圖形的範疇。更精確的說法是：

GPU 的現代定義
  • 專門設計來做大規模平行計算的處理器
  • 有數千個小型運算核心，可以同時做數千件事
  • 特別擅長矩陣運算（這正是 AI 的核心）
  • 現在常被稱為 GPGPU（General-Purpose GPU，通用 GPU）

  • 1999 年 NVIDIA 正式創造「GPU」這個詞
  • 2012 年 GPU 遇上深度學習，改變了 AI 的發展速度
  • GPU 現在 = 大規模平行計算處理器，不只是顯示卡
  • AI 市場 GPU 幾乎是 NVIDIA 獨佔，AMD 在追趕中
