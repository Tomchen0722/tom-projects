⚖️ GPU vs CPU
一個天才 vs 一萬個工人

你的電腦裡同時有 CPU 和 GPU，但它們做的事情完全不同。搞懂這個，你就懂為什麼 AI 需要 GPU。

🧑‍🏫 最重要的一個比喻

💡 核心比喻

CPU = 一位超級天才教授：思路清晰、反應極快，可以解任何複雜問題，但一次只能做一件事。

GPU = 一萬個普通工人：每個人能力普通，但可以同時動手，把一個大任務拆成一萬份同時做完。

問題來了：計算一個 AI 模型的輸出，需要做幾億次「1 + 1 = 2」這種簡單但重複的加法。這種事情，一萬個普通工人遠比一個天才教授有效率。

🔵 CPU 的特性

  • 核心數少（4–64 個）
  • 每個核心速度極快（5GHz+）
  • 快取記憶體很大
  • 擅長複雜的邏輯判斷
  • 可以隨時切換不同任務
  • 低延遲（反應很快）

🟢 GPU 的特性

  • 核心數超多（數千至數萬）
  • 每個核心速度較慢（~2GHz）
  • 快取記憶體較小
  • 擅長大量重複的簡單計算
  • 一次執行同一種指令
  • 高吞吐量（做得多）

🤝 CPU 和 GPU 是合作關係，不是競爭

一台電腦需要 同時有 CPU 和 GPU，各司其職：

分工流程（以 AI 推理為例）
  • 1. CPU：接收你打的問題，做前處理（tokenization）
  • 2. CPU：把資料送給 GPU
  • 3. GPU：執行幾億次矩陣乘法，算出結果
  • 4. CPU：接收 GPU 的輸出，轉換成文字回傳給你

⚠️ 常見誤解：「買了強的 GPU，CPU 可以隨便買」——錯。CPU 太弱會成為瓶頸，資料餵不夠快，GPU 閒置等待。CPU 和 GPU 要搭配。

📌 什麼任務適合 GPU？什麼適合 CPU？

🔵 CPU 更適合

  • 複雜的邏輯判斷（if-else 很多）
  • 資料庫查詢
  • 作業系統排程
  • 單一序列的複雜演算法
  • 網路請求處理
  • 一般網站後端

🟢 GPU 更適合

  • 3D 遊戲渲染
  • AI 模型訓練與推理
  • 影像 / 影片處理
  • 科學數值模擬
  • 加密貨幣挖礦
  • 大規模資料分析

✅ 本章重點整理

  • CPU = 少數幾個超快核心，擅長複雜邏輯，適合序列任務
  • GPU = 數萬個較慢核心，擅長重複計算，適合平行任務
  • AI 模型 = 幾億次簡單乘法 → 天生適合 GPU
  • CPU 和 GPU 是合作關係，都需要，不能互相取代
  • CPU 太弱會拖累 GPU 效能，要均衡搭配
