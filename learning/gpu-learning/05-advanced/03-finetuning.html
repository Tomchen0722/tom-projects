🎯 微調 LLM：LoRA 與 QLoRA

用消費級 GPU 在 24 小時內微調出自己的 LLM。理解 LoRA 的數學直覺，動手做 QLoRA 完整流程。

🤔 為什麼需要微調？

通用 LLM（如 GPT-4、Llama）是泛才，什麼都懂一點。微調（Fine-tuning）是讓它成為你的領域專家。

❌ 不微調的問題

  • 回答你公司的問題時答非所問
  • 不懂公司術語、產品名稱
  • 輸出格式不符合你的需求
  • 每次都要在 prompt 裡重複說明背景

✅ 微調後能做到

  • 熟悉你的領域語言與術語
  • 固定輸出格式（JSON、表格等）
  • 學習你的寫作風格與語氣
  • 對敏感資料不需要送出 API

但完整微調一個 7B 模型需要 8 張 A100（要價約 $5 萬美元/月）。LoRA 讓你用 一張消費級 GPU 在幾小時內完成。

🔬 LoRA：低秩適應的直覺

LLM 的核心是大量矩陣（權重）。LoRA 的觀察是：你需要調整的部分，其實很低維。

📚 比喻：改課本

完整微調 = 重印整本 1000 頁的教科書（貴、慢）。LoRA = 只貼一張 10 行的勘誤貼紙（便宜、快），但閱讀時要把貼紙和原文一起看。結果不錯，成本只有 1%。

LoRA 的數學直覺

一個大矩陣 W（假設 4096×4096 = 1600 萬個參數），LoRA 把它的更新量分解為兩個小矩陣的乘積：

🔢 LoRA 分解
  • 原始矩陣 W：凍結，不更新（4096×4096 = 1600 萬參數）
  • 矩陣 A：可訓練（4096 × r，r 通常 = 16）= 65,536 參數
  • 矩陣 B：可訓練（r × 4096）= 65,536 參數
  • 推論時：W_new = W + A × B（把兩張「勘誤貼紙」合回去）
  • 參數削減：1600 萬 → 13 萬，節省 99.2%

🚀 QLoRA：更進一步

QLoRA = Quantize（量化） + LoRA。把基礎模型量化成 4-bit（省 VRAM），然後用 LoRA 加上可訓練的適配層。

方法7B 模型 VRAM品質速度適用場景
Full Fine-tuning>80 GB最佳慢企業，8×A100
LoRA (FP16)~14 GB接近 Full快RTX 3090/4090
QLoRA (INT4)~6 GB略低中RTX 3080/4070

💡 RTX 4090（24 GB VRAM）是目前消費卡微調 7B 的甜蜜點。用 QLoRA 甚至能微調 13B 模型。

🛠️ QLoRA 實戰：完整流程

1. 安裝環境

# 安裝所需套件
pip install transformers datasets peft trl bitsandbytes accelerate

# bitsandbytes：INT4 量化核心
# peft：Parameter-Efficient Fine-Tuning（LoRA 的實作）
# trl：Transformer Reinforcement Learning（含 SFT Trainer）

2. 準備資料集

# 資料格式：最常見的 Alpaca 格式
# 每筆資料包含：instruction（指令）、input（輸入）、output（期望輸出）
data = [
    {
        "instruction": "分析以下評論的情緒",
        "input": "這個產品完全達到我的期望，強烈推薦！",
        "output": "正面情緒（極度正面）：使用者對產品高度滿意，並主動推薦。"
    },
    # ... 通常需要 500-5000 筆高品質資料
]

# 轉換成模型輸入格式
def format_prompt(example):
    return f"""### 指令：
{example['instruction']}

### 輸入：
{example['input']}

### 回答：
{example['output']}</s>"""

3. 載入量化模型 + 設定 LoRA

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model

# INT4 量化設定
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_use_double_quant=True,   # 二次量化，再省一點 VRAM
    bnb_4bit_quant_type="nf4",         # NormalFloat4，比 int4 更準
    bnb_4bit_compute_dtype=torch.bfloat16
)

# 載入量化模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.2-8B-Instruct",
    quantization_config=bnb_config,
    device_map="auto"
)
tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-3.2-8B-Instruct")

# 設定 LoRA
lora_config = LoraConfig(
    r=16,              # rank：越大效果越好，但 VRAM 需求越高
    lora_alpha=32,     # scaling factor（通常 = 2r）
    target_modules=["q_proj", "v_proj"],  # 哪些層加 LoRA
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# 輸出：trainable params: 6,815,744 || all params: 8,036,614,144 || trainable%: 0.08

4. 訓練

from trl import SFTTrainer
from transformers import TrainingArguments

training_args = TrainingArguments(
    output_dir="./my-finetuned-llm",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,   # 模擬 batch_size=16
    warmup_steps=100,
    learning_rate=2e-4,
    fp16=True,
    logging_steps=10,
    save_strategy="epoch",
)

trainer = SFTTrainer(
    model=model,
    train_dataset=dataset,
    args=training_args,
    tokenizer=tokenizer,
)
trainer.train()

# 儲存 LoRA 權重（只存幾十 MB！）
model.save_pretrained("./lora-weights")
tokenizer.save_pretrained("./lora-weights")

5. 合併並推論

from peft import PeftModel

# 載入基礎模型 + LoRA 權重
base_model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.2-8B-Instruct")
model = PeftModel.from_pretrained(base_model, "./lora-weights")

# 選項：合併 LoRA 到基礎模型（推論更快，但檔案更大）
model = model.merge_and_unload()
model.save_pretrained("./merged-model")  # 可直接給 vLLM 使用

📋 微調資料準備的黃金法則

✅ 高品質資料的標準
  • 500 筆精準勝過 5000 筆雜亂——品質遠比數量重要
  • 涵蓋你的實際使用案例，不要只用示範資料
  • 輸出格式一致（都用 JSON 或都用純文字，不要混用）
  • 負面範例也要包含（告訴模型什麼是錯的）
  • 用 GPT-4 幫你生成初版資料，人工審核後再用

⚠️ 災難性遺忘（Catastrophic Forgetting）：如果只用你的領域資料訓練，模型可能忘記原本的通用能力。解法：在訓練集裡混入 10-20% 的通用對話資料（如 Open-Platypus、Alpaca）。

📌 本章重點整理

  • 微調目的：讓通用 LLM 學習你的領域語言、格式和知識
  • LoRA 原理：把大矩陣的更新量分解為兩個小矩陣乘積，省 99% 參數
  • QLoRA = 量化基礎模型（INT4）+ LoRA 適配層，6 GB VRAM 就能微調 7B
  • 關鍵超參數：r（rank，通常 16）、lora_alpha（通常 2r）、target_modules
  • 資料品質第一：500 筆好資料 > 5000 筆雜資料
  • 防止災難性遺忘：訓練集混入 10-20% 通用對話資料
  • 推薦工具鏈：Unsloth + HF PEFT + vLLM（訓練到部署一條龍）
