什麼是 CompTIA Security+?

認證介紹、考試形式、值不值得考,以及它在資安職涯地圖上的位置。

🚗 用駕照理解 Security+

想開車上路,你需要駕照——它不代表你是賽車手,但證明你懂交通規則、能安全上路。

CompTIA Security+ 就是資安界的駕照。它不代表你是頂尖駭客或資安專家,但它向雇主證明:你懂資安的基本語言、知道常見威脅、了解該怎麼防護與應變。這正是資安入門職位最需要的。

💡 三個關鍵特性:
• 入門級——資安領域最主流的第一張證照
• 廠商中立——不綁定 Cisco、微軟等特定廠牌,學的是通用觀念
• 國際通用——全球認可,不少企業與政府單位列為職務要求

📋 考試基本形式

項目內容
現行版本SY0-701
題型單選/複選題 + PBQ(情境操作題)
題數最多約 90 題
時間約 90 分鐘
計分約 100–900 分制,及格線約 750
建議先備經驗約 2 年 IT/資安相關經驗(建議,非強制)
證照效期3 年,需累積 CEU 續證
⚠️ 務必自行到官網確認。費用、題數、及格分數、報名方式 CompTIA 會調整,上面是概略架構,報考前請以 CompTIA 官方公告為準。台灣可透過授權考場(如 Pearson VUE)報名,也有線上監考選項。
💡 PBQ 是什麼?Performance-Based Questions,情境操作題。不是選 ABCD,而是給你一個模擬畫面(如設定防火牆規則、把攻擊類型拖到對應情境),要你實際操作或配對。通常出現在考卷最前面、每題花時間較久——策略是先跳過、最後回頭做,免得時間全卡在前面。

🗺️ 資安證照地圖:Security+ 在哪一站?

層級代表證照定位
IT 基礎CompTIA A+ / Network+電腦與網路基礎,Security+ 的前置基礎
資安入門Security+資安通用基礎,最主流的第一張
資安進階CySA+ / PenTest+偏維運分析、偏滲透測試的專精方向
管理層級CISSP / CISM資安管理與治理,需多年實務經驗
實戰技術OSCP高難度實作滲透測試
管理系統ISO 27001 主導稽核員組織的資安管理制度與稽核
💡 典型路徑:Network+ → Security+ → 依興趣分流:想做監控分析走 CySA+;想做攻擊測試走 PenTest+/OSCP;想做管理走 CISSP。

本學習中心也有 ISO 27001 教材——那是「組織如何建立資安管理制度」的角度,和 Security+ 的「技術人員該懂什麼」互補,兩者一起看視野會更完整。

💼 考了能做什麼工作?

🖥️

資安維運 / SOC 分析師

盯監控告警、初步判斷事件、通報處理。最常見的入門職位。

🔧

系統/網路管理員

原本做 IT 維運,加上資安能力後負責防火牆、帳號權限、修補管理。

📋

資安稽核 / 法遵

協助組織符合法規與標準,檢視制度落實情況。

🏢

MIS / 企業內部資安

中小企業常一人身兼 IT 與資安,Security+ 的廣度剛好對應。

⚠️ 誠實提醒:證照是「入場券」不是「保證書」。它能幫你通過履歷篩選、拿到面試機會,但實際錄取還是看你能不能講出實務理解。所以讀的時候要理解觀念,不要只背答案——面試官一問「你怎麼處理釣魚事件」就見真章。

🤔 我適合考嗎?

你的情況建議
IT 從業者想轉資安✅ 非常適合,是最標準的第一步
學生/應屆想進資安✅ 適合,能補足履歷、證明基礎
完全無 IT 背景⚠️ 可以,但建議先補網路基礎(如 Network+ 範圍),否則第 3、4 領域會很吃力
已有多年資安實務⚠️ 可能太基礎,可直接考慮 CySA+ 或 CISSP
只想懂資安不需證照💡 直接讀教材即可,觀念一樣有用,不一定要花錢考

📝 隨堂練習

Q1. Security+ 說是「廠商中立」的證照,這是什麼意思?有什麼好處?

Q2. PBQ 是什麼題型?考試策略上建議怎麼處理?

Q3. 一位完全沒有 IT 背景的人想直接考 Security+,可能會在哪些領域遇到困難?

▶ 看參考答案
A1. 指它不綁定特定廠牌(不是只教 Cisco 或微軟的產品),教的是通用資安觀念與原理。好處是學到的知識在任何環境都適用,不會因為換公司用不同廠牌設備就失效。
A2. PBQ 是情境操作題,要實際操作或配對而非選 ABCD。策略是先跳過、把選擇題做完再回頭處理,避免時間全卡在前面幾題。
A3. 主要是「安全架構(領域3)」與「安全維運(領域4)」——這兩塊需要網路與系統基礎(如網路分區、防火牆、通訊協定、作業系統帳號權限)。建議先補 Network+ 範圍的網路基礎。

📚 備考資源怎麼選?

市面上資源很多,重點是「教材 + 題庫 + 實作」三者搭配,只讀其中一種都不夠:

資源類型作用選擇要點
官方考試大綱(Exam Objectives)最重要——列出每個考點CompTIA 官網免費下載,當成checklist逐項打勾
教科書 / 影音課程建立完整觀念務必確認是 SY0-701 版本,舊版差異大
題庫 / 模擬考檢驗理解、熟悉題型選有詳細解析的,只給答案的沒用
實作環境把觀念變成手感用虛擬機自架小實驗室
社群/讀書會互相解惑、維持動力能把觀念講給別人聽,才是真懂
⚠️ 避開「題庫外洩」(brain dump)。網路上有些號稱「實際考題」的資源,除了違反考試協議、可能被撤銷證照外,更實際的問題是:背了也不會用。Security+ 情境題變化多,面試時一問實務就露餡。

🧪 用虛擬機自建練習環境

資安是實作學科,光看書很難有感。免費就能自己搭一個小型練習環境:

元件用途可練什麼
虛擬機軟體在一台電腦上跑多台虛擬主機網路分區、快照還原
Linux 主機當伺服器/受測目標權限管理、日誌檢視、系統強化
Windows 主機模擬企業用戶端帳號策略、事件檢視器、群組原則
封包分析工具觀察網路流量看懂 TCP 握手、明文 vs 加密的差別
弱點掃描工具掃自己的虛擬機理解 CVE/CVSS 與掃描報告怎麼看
💡 最有感的三個小實驗:
① 用封包分析工具看 HTTP vs HTTPS——親眼看到明文密碼在網路上裸奔,你就永遠記得為什麼要加密
② 在自己的虛擬機上開一個弱密碼帳號,試著暴力破解,再啟用帳號鎖定看差別
③ 故意刪掉檔案,再從備份還原——體會 RPO 的真實意義
⚠️ 只能對自己的環境做測試。掃描或攻擊他人系統(包含公司系統未經授權)在台灣可能觸犯《刑法》妨害電腦使用罪。練習一定要在自己的虛擬機或合法的線上靶場進行。

💼 資安職涯的三條路線

Security+ 之後往哪走?資安其實有很不同的三種性格路線:

🛡️

藍隊(防守)

SOC 分析師、事件應變、威脅獵捕。適合細心、耐得住監控、喜歡抽絲剝繭的人。
下一張:CySA+

⚔️

紅隊(攻擊)

滲透測試、紅隊演練。適合喜歡拆解、鑽研技術細節、有好奇心的人。
下一張:PenTest+ / OSCP

📋

治理(管理)

風險管理、稽核、法遵、ISMS 導入。適合擅長溝通、文件、跨部門協調的人。
下一張:CISSP / ISO 27001 主導稽核員

🏗️

工程(建設)

資安架構、雲端安全、DevSecOps。適合有開發或系統背景、喜歡蓋東西的人。
下一張:雲端資安認證

💡 Security+ 的價值就在這裡:它是四條路的共同起點。因為它涵蓋面廣但不深,讀完你會知道自己對哪一塊最有興趣,再往那個方向鑽。不必一開始就決定,先把地圖看完。

❌ 五個常見備考迷思

迷思實際情況
「背完名詞就會過」大量是情境題,要判斷「這個狀況該怎麼做」,死背會被變化題打敗
「要先很懂技術才能考」Security+ 是入門級,重廣度不重深度。有基本網路概念即可開始
「證照拿到就有工作」證照幫你過履歷關,但面試考的是能不能講出實務理解
「用舊版教材沒差」差很多。SY0-701 加重了雲端、零信任、自動化,舊版內容會漏考點
「刷題刷夠就好」刷題是檢驗工具不是學習工具。錯題要回頭理解原理,否則換個問法又錯
