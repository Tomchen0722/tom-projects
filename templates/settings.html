怎麼把 LINE 接上

下面步驟做完,員工就能在 LINE 裡查班表、請假、申請調班,班表發布時也會自動收到通知。

  1. 到 LINE Developers 建立一個 Provider。
  2. 在 Provider 底下建 Messaging API channel(這是官方帳號,負責發訊息)。 取得 Channel secret 與 Channel access token。
  3. 在同一個 Provider 建 LINE Login channel,在裡面新增一個 LIFF app:
    • Endpoint URL 填 {{ public_base_url }}/liff
    • Size 選 Full,Scope 勾 profile 和 openid
    取得 LIFF ID 與這個 Login channel 的 Channel ID。
  4. 把上面四個值填進專案根目錄的 .env: 
    LINE_CHANNEL_SECRET=...
LINE_CHANNEL_ACCESS_TOKEN=...
LINE_LIFF_ID=...
LINE_LOGIN_CHANNEL_ID=...
PUBLIC_BASE_URL=https://你的網址
  5. Messaging API channel 的 Webhook URL 填 {{ public_base_url }}/line/webhook, 並把 Use webhook 打開、自動回覆訊息關掉。
  6. 重開服務。員工加官方帳號好友後,在聊天室輸入 綁定 A001(自己的員工編號)就完成綁定。
本機測試時 LINE 連不到 127.0.0.1,要用 ngrok 之類的工具開一個對外的 https 網址, 再把那個網址填進 PUBLIC_BASE_URL 和 Webhook URL。
